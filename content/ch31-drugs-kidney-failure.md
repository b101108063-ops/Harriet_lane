## 導讀摘要

本章節提供<span style="color:#60a5fa">**腎功能衰竭時的藥物劑量調整**</span>的完整指引，包括：

- 劑量調整方法（延長間隔 vs. 減少劑量）
- 抗菌藥物在腎功能衰竭時的調整
- 非抗菌藥物在腎功能衰竭時的調整
- 透析對藥物清除的影響
- 常用化療藥物的腎功能調整

> ⚠️ **Critical Warning：** 本章的劑量調整建議**不適用於新生兒期**。新生兒腎功能的藥物劑量請參考 Chapter 18（新生兒學）。此外，這些調整是基於慢性腎病族群，外推到急性腎損傷可能不適用。每位患者都必須密切監測藥物中毒跡象，並在有條件時測量血清藥物濃度。

---

## I. 劑量調整方法

### A. 維持劑量調整策略

| 策略 | 說明 |
|------|------|
| **延長給藥間隔** | 保持正常劑量，但增加給藥間隔（如 Q8h → Q12h）|
| **減少劑量** | 保持正常給藥間隔，但降低每次劑量（如 100% → 50%）|
| **聯合策略** | 同時調整劑量和給藥間隔 |

### B. 透析影響

| 透析類型 | 對藥物清除的影響 |
|---------|---------------|
| **血液透析 (HD)** | 可清除大部分藥物；透析後可能需要補充劑量 |
| **腹膜透析 (PD)** | 清除較慢；部分藥物需調整劑量 |
| **連續性腎臟替代治療 (CRRT)** | 清除率較高；劑量需求因機型和血流速率而異 |

> **Clinical Pearl：** 透析患者的藥物劑量調整還需考慮殘餘腎功能、年齡、營養狀態和併發症（如腹膜炎）。

### C. eGFR 估算（兒童 Bedside CKiD 方程式）

$$\text{eGFR} = 0.413 \times \frac{\text{height (cm)}}{\text{serum creatinine (mg/dL)}}$$

> **Clinical Pearl：** 血清肌酸酐的變化**落後於**腎功能的實際變化，且在肌肉量減少或營養不良的患者可能**高估**GFR。當有疑問時，請腎臟科會診以確定準確的 eGFR 範圍。

> - 使用**一日一次高劑量**方案（而非傳統的多次給藥）
> - 每次給藥前測量**血清谷濃度**
> - 目標谷濃度：Gentamicin/Tobramycin <1 mg/L，Amikacin <5-10 mg/L

### B. 抗病毒藥物

| 藥物 | 調整原則 |
|------|---------|
| **Acyclovir** | 見上述；腎功能嚴重減退時需顯著減量 |
| **Valacyclovir** | eGFR <30：劑量減少 50-75% |
| **Ganciclovir/Valganciclovir** | 骨髓抑制風險高；強烈建議根據 eGFR 調整並監測血球計數 |
| **Oseltamivir** | eGFR 11-30：50% 劑量；HD/PD：透析後給予 |

---

### C. 抗真菌藥物

| 藥物 | 說明 |
|------|------|
| **Fluconazole** | eGFR <50：100% loading dose 後減少維持劑量；HD 可清除（透析後補充）|
| **Voriconazole** | 靜脈製劑含 SBECD（蓄積風險）；eGFR <50 避免靜脈給藥，可考慮口服 |
| **Amphotericin B** | 常規劑量；腎毒性是最顯著限制，建議監測腎功能和電解質 |
| **Flucytosine** | eGFR 10-50：50% Q12h；<10：50% Q24-48h；強烈建議血中濃度監測 |

## III. 非抗菌藥物在腎功能衰竭時的調整

| 藥物 | eGFR | 調整 |
|------|------|------|
| **Acetaminophen** | 10-50 | 100% Q6h |
| | <10 | 100% Q8h |
| **Allopurinol** | 10-50 | 50% |
| | <10 | 30% |
| **Aspirin** | ESRD | 避免（抗發炎劑量）|
| **Atenolol** | 10-50 | 50% |
| | <10 | 25-50% |
| **Carbamazepine** | <50 | 避免或嚴格監測 |
| **Digoxin** | 30-50 | 維持劑量降至 75% |
| | <30 | 維持劑量降至 50-75%；降低數位化負荷量 |
| **Fentanyl** | <30 | 75% |
| **Gabapentin** | 30-59 | 75% Q12h |
| | 15-29 | 75% Q24h |
| | <15 | 75% Q24h |
| **Levetiracetam** | <50 | 50-100% Q12h |
| **Lithium** | <50 | 避免或 25-50% Q24-48h；強烈建議血中濃度監測 |
| **Methadone** | <30 | 避免（累積毒性）|
| **Morphine** | <30 | 避免或 25-50% Q12h；代謝物（M6G）蓄積→呼吸抑制風險↑ |
| **Naproxen** | <30 | 避免 |
| **Sevelamer** | 任何水平 | 用於透析患者的高磷酸鹽血症；需隨餐服用 |
| **Spironolactone** | <50 | 避免（高鉀血症風險）|
| **Valproic Acid** | <30 | 通常無需顯著調整，但需監測 |

---

### B. 化療藥物在腎功能衰竭時的調整

| 藥物 | 說明 |
|------|------|
| **Cisplatin** | 顯著腎毒性；eGFR <60 避免或顯著減量；化療前/後水化 |
| **Carboplatin** | 根據 AUC（Calvert 公式）調整劑量，目標 AUC根據治療方案而定 |
| **Methotrexate** | 主要經膽汁排泄；腎功能衰竭時毒性增加（口服或靜脈）|
| **Cyclophosphamide/Ifosfamide** | 代謝物（acrolein）引起出血性膀胱炎；eGFR <30 需調整 |
| **Bleomycin** | 主要經腎臟清除；eGFR <30 需減量 |
| **Etoposide** | 輕度腎功能影響；可考慮減量 |
| ** Vincristine** | 主要經膽汁排泄；通常無需腎功能調整 |

> **Clinical Pearl：** **卡鉑（Carboplatin）** 的劑量應根據目標 AUC（Area Under the Curve）和腎功能計算。Calvert 公式：
> $$\text{Dose (mg)} = \text{AUC} \times (\text{CrCl} + 15)$$
> 兒童的 CrCl 應使用 Schwartz 公式估算。

---

### C. 糖尿病藥物在腎功能衰竭時

| 藥物 | 說明 |
|------|------|
| **Metformin** | <30 mL/min/1.73 m² 禁用（乳酸性酸中毒風險）|
| **Sulfonylureas** | <30 避免（作用時間延長→低血糖）|
| **Insulin** | 腎功能減退減少胰島素降解；劑量需個體化，常需減少 |
| **SGLT2 inhibitors** | <20 禁用（脫水/酮酸中毒風險）|

---

### D. 心血管藥物在腎功能衰竭時

| 藥物 | 說明 |
|------|------|
| **Digoxin** | 減少劑量；監測血中濃度（目標 0.5-0.9 ng/mL）|
| **Enalapril/Lisinopril** | <30 mL/min：起始劑量降低；追蹤血壓和腎功能/鉀 |
| **Spironolactone** | <30：避免（高鉀血症風險）|
| **Warfarin** | 通常不需調整；但腎功能減退者出血風險↑ |

## IV. 透析患者的藥物劑量

### A. 血液透析 (HD) 患者的調整原則

| 原則 | 說明 |
|------|------|
| **透析可清除的藥物** | 透析後需補充劑量（根據透析清除率和藥物特徵）|
| **透析後給藥** | 將給藥時間安排在透析後 |
| **首選長效製劑** | 減少給藥頻率 |
| **監測血中濃度** | 尤其氨基糖苷類、Vancomycin、銀翹鹼等 |
| **注意藥物輔料** | 某些製劑的輔料（如 sbecd）可能在腎功能減退時蓄積 |

> ⚠️ **Clinical Warning：** 大多數藥物在透析日給予時，清除量顯著增加（取決於藥物的分佈容積和蛋白結合率）。建議：
> - 對高透析清除率藥物：透析後補充劑量
> - 對低透析清除率藥物：可在透析前/後任何時間給藥

### B. 腹膜透析 (PD) 患者的調整原則

| 特點 | 說明 |
|------|------|
| **清除速率** | 通常低於血液透析 |
| **藥物特性** | 大分子量藥物（>500 Da）、高蛋白結合率藥物腹膜清除率低 |
| **腹膜炎的影響** | 腹膜發炎時清除率可能增加 |
| **給藥時機** | 大多數藥物可在任何時間給藥 |
| **監測** | 根據臨床反應和血中濃度調整 |

## V. 特殊臨床情境

### A. 腎功能減退時的鎮痛與鎮靜

| 藥物 | 建議 |
|------|------|
| **Acetaminophen** | 安全的首選，但總量不超過 3-4 g/day |
| **NSAIDs** | <30 eGFR：避免（急性腎損傷/高血壓惡化）|
| **Hydrocodone/Oxycodone** | eGFR <30：減量；避免嗎啡（代謝物蓄積）|
| **Fentanyl** | eGFR <30：75% 劑量；仍是首選之一 |
| **Gabapentin/Pregabalin** | 顯著需調整（見上表）|

### B. 腎功能減退時的抗癲癇藥物

| 藥物 | 建議 |
|------|------|
| **Levetiracetam** | eGFR <30：50-100% Q12h；非透析患者亦需調整 |
| **Gabapentin** | eGFR <30：75% Q12h 或更低 |
| **Lacosamide** | eGFR <30：75% Q12h（最大 300mg/day）|
| **Valproic Acid** | 通常不需顯著調整 |
| **Phenytoin** | 蛋白結合改變（尿毒症游離分數增加）；游離 phenytoin 濃度監測更準確 |

### C. 腎功能減退時的抗凝治療

| 情境 | 建議 |
|------|------|
| **普通肝素 (UFH)** | eGFR <30：使用時需謹慎；抗-Xa 監測 |
| **低分子量肝素 (LMWH)** | eGFR <30：禁用或顯著減量；抗-Xa 監測 |
| **Warfarin** | 可用但出血風險↑；INR 監測；注意維生素 K 攝入 |
| **DOACs（直接口服抗凝血劑）**| eGFR <30：禁用或僅用於特定藥物（某些 DOACs 有特定劑量調整）|
| **阿斯匹靈** | 單一抗血小板：通常安全；有心血管疾病時可用 |

> ⚠️ **Clinical Warning：** **直接口服抗凝血劑（DOACs）** 在嚴重腎功能減退（eGFR <30 mL/min/1.73 m²）的安全性和療效數據有限。請參考個別藥物的仿單並權衡風險/效益。

## VI. 藥物濃度監測

### A. 需要治療性藥物監測 (TDM) 的常見藥物

| 藥物類別 | 藥物 | 目標血中濃度 |
|---------|------|------------|
| **氨基糖苷類** | Gentamicin、Tobramycin | Peak: 5-10 mg/L（FEP）、<1 mg/L（Trough）|
| | Amikacin | Peak: 20-30 mg/L、Trough <5-10 mg/L |
| **Vancomycin** | — | Trough: 10-15 mg/L（一般感染）或 15-20 mg/L（複雜感染）|
| **抗癲癇藥物** | Phenytoin | 游離: 1-2 mg/L |
| | Phenobarbital | 10-40 mg/L |
| | Carbamazepine | 4-12 mg/L |
| | Valproic acid | 50-100 mg/L |
| | Levetiracetam | 12-46 mg/L（參考範圍）|
| **免疫抑制劑** | Cyclosporine | C0 或 C2 目標根據移植類型 |
| | Tacrolimus | C0 目標根據移植類型 |
| | Mycophenolic acid | 1-3.5 mg/L（某些方案）|
| **化療藥物** | Methotrexate | 依時間點調整（如 48h <0.1 mM）|
| | Busulfan | AUC 目標根據移植方案 |
| **其他** | Digoxin | 0.5-0.9 ng/mL |
| | Lithium | 0.6-1.2 mEq/L（急性能力）；0.6-0.9（情緒穩定）|
| | Theophylline | 5-15 mg/L |

> **Clinical Pearl：** 血中濃度的**採集時機**至關重要：
> - **Trough（谷值）**：下一次給藥前採集（評估蓄積/中毒）
> - **Peak（峰值）**：給藥後特定時間採集（評估療效/劑量不足）
> - **AUC（曲線下面積）**：多次採樣（如methotrexate）或單點模型（如carboplatin的Calvert公式）

## VII. 藥物-營養交互作用

| 情境 | 說明 |
|------|------|
| **磷結合劑** | Sevelamer、Calcium acetate：應隨餐服用；不同製劑不要混用 |
| **鐵劑** | 與磷結合劑間隔 2 小時服用；CKD 患者靜脈鐵可能更佳 |
| **維生素 D** | Calcitriol、Paricalcitol：劑量需根據鈣、磷、iPTH 調整 |
| **鋅補充** | CKD 患者可能缺乏；劑量 15-50 mg/day elemental zinc |
