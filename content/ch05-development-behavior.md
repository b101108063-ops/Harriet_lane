## 導讀摘要

本章節系統性介紹青少年醫學的核心原則：

- <span style="color:#60a5fa">**青少年發展理論**</span>：身體、心理、社會快速成長，身份認同與自主權建立
- <span style="color:#60a5fa">**保密性原則**</span>：知情同意法規、保密例外、帳單和文件注意
- <span style="color:#60a5fa">**HEEADSSS 評估**</span>：Home、Education、Eating、Activities、Drugs、Sexuality、Suicide、Safety
- <span style="color:#60a5fa">**性健康**</span>：STI 篩查指南、診斷和治療
- <span style="color:#60a5fa">** Tanner 分期**</span>：青春期發育評估
- <span style="color:#60a5fa">**心理健康**</span>：憂鬱篩查、自殺風險評估

> 📌 <span style="color:#60a5fa">**Note**</span>：青少年定義為 10-25 歲，涵蓋快速身體、心理和社會成長與發展的人生階段

---

## I. 青少年發展理論

### A. 發育階段特點

| 階段 | 年齡 | 主要任務 |
|------|------|---------|
| <span style="color:#60a5fa">**早期青少年**</span> | 10-13 歲 | 身體形象困擾、同性友誼、對父母興趣降低、情緒波動 |
| <span style="color:#60a5fa">**中期青少年**</span> | 14-16 歲 | 父母衝突高峰期、同儕順從、風險行為增加、理想化職業目標 |
| <span style="color:#60a5fa">**晚期青少年**</span> | > 17 歲 | 接受身體變化、較少同儕壓力、實際職業目標、價值觀成熟 |

### B. 發展任務

| 任務 | 早期 | 中期 | 晚期 |
|------|------|------|------|
| <span style="color:#60a5fa">**獨立性**</span> | 對父母活動興趣降低 | 與父母衝突高峰 | 重新接受父母建議 |
| <span style="color:#60a5fa">**身體形象**</span> | 對外表不確定 | 關注身體吸引力 | 接受身體變化 |
| <span style="color:#60a5fa">**同儕關係**</span> | 對同性朋友有強烈興趣 | 同儕順從高峰期 | 同儕群體較不重要 |
| <span style="color:#60a5fa">**身份認同**</span> | 興趣增加、認知能力提高 | 感覺全能、風險行為 | 現實目標、價值觀精炼 |

## II. 結構因素對青少年的影響

### A. 種族主義

| 類型 | 說明 |
|------|------|
| <span style="color:#60a5fa">**制度性**</span> | 教育、環境/地點、法律（警察暴力、少年司法系統） |
| <span style="color:#60a5fa">**個人中介**</span> | 明確/隱含偏見、人際關係 |
| <span style="color:#60a5fa">**內化**</span> | 刻板印象、刻板印象威脅 |

### B. 環境/社區差異

- 缺乏戶外空間、清潔空氣和水
- 環境毒素暴露
- 創傷和暴力暴露

### C. 生殖正義

- 地理和保險狀況限制服務獲取

## III. 保密性原則

### A. 同意法規

| 服務類型 | 允許同意的州 |
|---------|-----------|
| <span style="color:#34d399">**STI 服務（診斷和治療）**</span> | 所有 50 州 + DC |
| <span style="color:#60a5fa">**PrEP**</span> | 無州明確禁止 |
| HIV測試/治療、避孕、墮胎、精神健康/藥物使用障礙 | 各州不同 |

> 📌 <span style="color:#60a5fa">**臨床醫師角色**</span>：營造文化安全的空間，檢查自身偏見，採用以患者和家庭為中心的方法

### B. 保密例外

<span style="color:#f87171">**必須 breach 保密的情況**</span>：
- 患者有傷害自己或他人的風險
- 疑似兒童虐待或忽視
- 法定強姦

> ⚠️ <span style="color:#f87171">**Duty to Warn**</span>：對可識別的第三方發出威脅時，提供者有警告義務

### C. 保密的無意破壞

| 風險 | 解決方案 |
|------|---------|
| 保險解釋說明（EOB） | 政府資助項目（如 Title X）、當地衛生部門 |
| 開放式 notes（21st Century Cures Act） | 敏感話題保密 notes |

## IV. 青少年獨有健康維護要素

### A. HEEADSSS 評估

#### 1. H - 家庭（Home）

- 家庭構成
- 家庭動態和關係
- 近期變化
- 住房穩定性

#### 2. E - 教育/就業（Education/Employment）

- 學校表現和出勤
- 未來目標
- 課後工作或其他工作經歷
- 職業培訓計劃

#### 3. E - 飲食（Eating）

**身體形象和飲食習慣**
- 飲食障礙（見 Chapter 24）
- 肥胖和體重管理

**血脂和糖尿病篩查建議**

| 篩查項目 | 建議 |
|---------|------|
| <span style="color:#60a5fa">**膽固醇**</span> | 9-11 歲和 17-21 歲時各一次 |
| <span style="color:#60a5fa">**糖尿病**</span> | BMI ≧ 85% + 風險因素（A1c、FPG 或 OGTT） |

**食物安全**
- 兩題篩查（「有時候/經常」為陽性）：
  - 「過去 12 個月我們是否擔心食物會在買更多之前用完？」
  - 「過去 12 個月購買的食物是否不夠，我們沒有錢買更多？」

#### 4. A - 活動（Activities）

**社交媒體**
- 好處：溝通和參與
- 風險：睡眠障礙、注意力/學習受損、肥胖、憂鬱、不當內容暴露、隱私受損

**身體活動目標**：<span style="color:#34d399">**每天至少 60 分鐘中等至劇烈活動**</span>

**睡眠**
- 建議：<span style="color:#60a5fa">**8-10 小時/晚**</span>

#### 5. D - 藥物（Drugs）

**SBIRT 篩查流程**

| 工具 | 用途 |
|------|------|
| <span style="color:#60a5fa">**S2BI**</span> | 篩查青少年藥物使用 |
| <span style="color:#60a5fa">**BSTAD**</span> |菸草、酒精和其他藥物簡版篩查 |
| <span style="color:#60a5fa">**CRAFFT**</span> | 陽性篩查後識別有問題行為 |

> **CRAFFT 問題**
> - C：是否曾乘坐由處於高或使用藥物的人駕駛的**車**？
> - R：是否曾使用酒精或藥物來**放鬆**、感覺更好或**融入**？
> - A：是否曾**獨自**使用酒精/藥物？
> - F：家人或**朋友**是否告訴你應該減少喝酒或用藥？
> - F：使用酒精或藥物時是否曾**忘記**所做過的事？
> - T：使用酒精或藥物時是否曾遇到**麻煩**？
>
> **≧ 2 個「是」= 陽性篩查**

**SUD 嚴重度分級（DSM-5）**

| 症狀數 | 嚴重度 |
|--------|--------|
| 2-3 | 輕度 |
| 4-5 | 中度 |
| ≧ 6 | 重度 |

#### 6. S - 性與性別（Sexuality & Gender）

**術語定義**

| 術語 | 定義 |
|------|------|
| <span style="color:#60a5fa">**性別認同**</span> | 一個人對自身性別的內在感覺 |
| <span style="color:#60a5fa">**性別表達**</span> | 個人表達或展示性別的外在方式 |
| <span style="color:#60a5fa">**跨性別**</span> | 性別認同與出生時被指定的性別不同 |
| <span style="color:#60a5fa">**順性別**</span> | 性別認同與出生時被指定的性別相同 |
| <span style="color:#60a5fa">**性別不安**</span> | 由於性別認同與出生時被指定的性別不一致而引起的不適或困擾 |

**性別肯定干預（Table 5.4）**

| 類型 | 可逆性 | 時間 |
|------|--------|------|
| 社會性別過渡（名字、代名詞、服裝） | 可逆 | 所有年齡 |
| 法律變更（名字和性別標識） | 可逆 | 所有年齡 |
| 青春期抑制：GnRH 类似物 | 可逆 | Tanner II 期開始 |
| 激素治療：雌激素/睪酮 | 部分不可逆 | 13.5-16 歲 |
| 手術：gonadectomy、mastectomy | 不可逆 | 通常不建議直到成年 |

> 📌 <span style="color:#60a5fa">**生育力保存**</span>：性別肯定干預前應討論對未來生育力的影響

#### 7. S - 自殺/憂鬱（Suicide/Depression）

**篩查工具**
- <span style="color:#60a5fa">**PHQ-A**</span>：青少年驗證憂鬱篩查工具
- GAD-7：焦慮篩查

**風險因素**
- 憂鬱或其他心理健康問題史
- 當前或先前自殺念頭或嘗試
- 自殘行為
- 負面童年經歷（ACE）/創傷

#### 8. S - 安全（Safety）

- 創傷/ACE 史
- 在家、學校或社區感到不安全
- 霸凌
- 槍枝或其他武器
- 與警察的互動/警察暴力

**種族差異**：Black 青年與警察接觸次數是白人的近 9 倍

### B. 青春期 Tanner 分期

#### 1. 乳房發育（女性）

| 期別 | 特點 |
|------|------|
| <span style="color:#34d399">**B1**</span> | 青春期前 |
| <span style="color:#34d399">**B2**</span> | 乳房芽 |
| <span style="color:#60a5fa">**B3**</span> | 青少年平滑輪廓 |
| <span style="color:#60a5fa">**B4**</span> | 乳暈和乳頭突出高於乳房 |
| <span style="color:#60a5fa">**B5**</span> | 成人 |

#### 2. 陰毛發育（男女通用）

| 期別 | 特點 |
|------|------|
| <span style="color:#34d399">**PH1**</span> | 青春期前 |
| <span style="color:#34d399">**PH2**</span> | 稀疏、色素沉著、長、直 |
| <span style="color:#60a5fa">**PH3**</span> | 深色、較粗、捲曲 |
| <span style="color:#60a5fa">**PH4**</span> | 填充至成人分布 |
| <span style="color:#60a5fa">**PH5**</span> | 成人（男性延伸至大腿內側） |

#### 3. 男性生殖器發育

| 期別 | 睪丸容積 | 長度 |
|------|---------|------|
| <span style="color:#34d399">**G1**</span> | < 4 mL 或 | < 2.5 cm |
| <span style="color:#34d399">**G2**</span> | 4-8 mL | 2.5-3.3 cm |
| <span style="color:#60a5fa">**G3**</span> | 9-12 mL | 3.4-4 cm |
| <span style="color:#60a5fa">**G4**</span> | 15-20 mL | 4.1-4.5 cm |
| <span style="color:#60a5fa">**G5**</span> | > 20 mL | > 4.5 cm |

> 📌 <span style="color:#60a5fa">**初經時間**</span>：大多數發生在 11-15 歲；16 歲無初經為原發性閉經，需要進一步評估

#### 4. 男性生理性女乳症

| 項目 | 內容 |
|------|------|
| **發生率** | 50%（50% 單側，50% 雙側） |
| **高峰期** | Tanner 3 期，通常 2 年內消退 |
| **病因** | 雌二醇刺激乳房生長 |
| **紅旗** | 症狀持續 > 2 年、乳頭分泌物、皮膚變化、睪丸異常 |

## V. 性健康

### A. STI 篩查指南

#### 1. 全面青少年（> 13 歲）

<span style="color:#60a5fa">**CDC 建議：至少一次 Universal HIV 篩查（opt-out 方式）**</span>

#### 2. 接受陰道性交

| 情況 | 篩查建議 |
|------|---------|
| 單一終生性伴侶 | 一次性 HIV 測試；年度 gonorrhea/chlamydia NAAT |
| 有風險因素 | 增加梅毒、滴蟲病篩查；每 3 個月複查 |

#### 3. 接受肛交

| 篩查項目 | 頻率 |
|---------|------|
| HIV 測試 | 不明或曾陰性但有多性伴侶 |
| RPR（梅毒） | 年度 |
| Gonorrhea/Chlamydia NAAT（直腸拭子） | 有接受史時 |

#### 4. 口交

| 篩查 | 建議 |
|------|------|
| Gonorrhea NAAT（咽拭子） | 有接受口交史 |
| Chlamydia（咽篩查） | 不建議 |

### B. STI 診斷和治療

#### 1. 披衣菌（Chlamydia）

| 治療 | 劑量 |
|------|------|
| <span style="color:#fb923c">**Doxycycline**</span> | 100 mg PO bid × 7 天 |
| <span style="color:#fb923c">**Azithromycin**</span> | 1 g PO 單劑量（替代） |

#### 2. 淋病（Gonorrhea）

| 治療 | 劑量 |
|------|------|
| <span style="color:#fb923c">**Ceftriaxone**</span> | 500 mg IM 單劑量（< 150 kg） |
| <span style="color:#fb923c">**Ceftriaxone**</span> | 1 g IM 單劑量（> 150 kg） |

#### 3. 梅毒（Syphilis）

**早期（一期、二期、早發潛伏）**
- <span style="color:#fb923c">**Benzathine penicillin G**</span> 2.4 百萬單位 IM 單劑量

**晚期潛伏**
- <span style="color:#fb923c">**Benzathine penicillin G**</span> 7.2 百萬單位總量（每週 2.4 百萬單位 × 3 次）

#### 4. 滴蟲病（Trichomonas）

| 治療 | 劑量 |
|------|------|
| <span style="color:#fb923c">**Metronidazole**</span> | 2 g PO 單劑量 |
| <span style="color:#fb923c">**Tinidazole**</span> | 2 g PO 單劑量（替代） |

#### 5. 皰疹（HSV）

**首次發作**
- <span style="color:#fb923c">**Acyclovir**</span> 400 mg PO tid × 7-10 天
- 或 <span style="color:#fb923c">**Valacyclovir**</span> 1 g PO bid × 7-10 天

**抑制治療**
- <span style="color:#fb923c">**Acyclovir**</span> 400 mg PO bid
- 或 <span style="color:#fb923c">**Valacyclovir**</span> 500 mg-1 g PO qd

### C. 陰道分泌物鑑別

| 情況 | 病原體 | 典型表現 |
|------|--------|---------|
| <span style="color:#34d399">**正常/生理性**</span> | - | 透明/白色，無症狀 |
| <span style="color:#f87171">**細菌性陰道炎**</span> | Gardnerella、Anaerobes | 灰白色、fishy 氣味、pH > 4.5 |
| <span style="color:#60a5fa">**黴菌性陰道炎**</span> | Candida albicans | 白色、凝乳樣、癢 |
| <span style="color:#60a5fa">**滴蟲病**</span> | Trichomonas vaginalis | 黃綠色、泡沫樣、pH > 4.5 |

## VI. 心理健康

### A. 憂鬱評估

#### 1. PHQ-A（青少年憂鬱篩查）

| 症狀 | 頻率 |
|------|------|
| 興趣或樂趣減少 | |
| 情緒低落 | 1-14 天：輕度 |
| 睡眠問題 | 1-14 天：輕度 |
| 疲勞 | ≧ 14 天：建議進一步評估 |
| 食慾/體重變化 | |
| 無價值感或內疚感 | |
| 專注困難 | |
| 精神運動性激動/遲緩 | |
| 自殺意念 | |

#### 2. 自殺風險評估

**直接詢問問題**
- 「你是否曾經想過結束自己的生命？」
- 「你是否曾經有過具體計劃？」
- 「你是否曾經嘗試過？」

**保護因素**
- 家庭支持
- 宗教信仰
- 問題解決能力
- 穩定的社會支持網絡

### B. 焦慮評估

**GAD-7 篩查**
| 分數 | 嚴重度 |
|------|--------|
| 5-9 | 輕度 |
| 10-14 | 中度 |
| 15-21 | 重度 |

### C. 物質使用障礙

**藥物輔助治療（MAT）**

| 藥物 | 適應症 | 年齡批准 |
|------|--------|---------|
| <span style="color:#fb923c">**Buprenorphine**</span> | OUD | 16+（常用於更年輕） |
| <span style="color:#fb923c">**Naltrexone**</span> | OUD、Alcohol | 18+ |
| <span style="color:#fb923c">**Methadone**</span> | OUD | 18+（特殊情況下 < 18） |

## VII. 預防健康實驗室和程序

| 項目 | 建議 |
|------|------|
| <span style="color:#60a5fa">**免疫**</span> | 見 Chapter 16 |
| <span style="color:#60a5fa">**血脂**</span> | 9-11 歲和 17-21 歲時各一次 |
| <span style="color:#60a5fa">**血壓**</span> | 所有青少年年度篩查 |
| <span style="color:#60a5fa">**糖尿病**</span> | BMI ≧ 85% + 風險因素者 |
| <span style="color:#60a5fa">**子宫頸癌**</span> | < 21 歲：不篩查；21-29 歲：細胞學 alone 每 3 年 |
| <span style="color:#60a5fa">**HIV**</span> | Universal screening ≥ 15 歲 |
| <span style="color:#60a5fa">**HCV**</span> | 18+ 全面篩查；所有有注射/鼻吸藥物史者 |

## VIII. 身體檢查要點

### A. 創傷知情檢查原則

| 原則 | 說明 |
|------|------|
| <span style="color:#60a5fa">**定義**</span> | 將已知或潛在創傷史的意識融入身體檢查 |
| <span style="color:#60a5fa">**語言**</span> | 使用臨床而非通俗語言；提前描述整個檢查 |
| <span style="color:#60a5fa">**自主權**</span> | 盡可能優化患者自主權 |

### B. 青春期獨有檢查要素

| 系統 | 評估重點 |
|------|---------|
| <span style="color:#22d3ee">**甲狀腺**</span> | 大小、結節；甲狀腺功能影響青春期 |
| <span style="color:#22d3ee">**乳房**</span> | Tanner 分期；腫塊；女性纖維囊性變化；男性女乳症 |
| <span style="color:#22d3ee">**生殖器**</span> | Tanner 分期； STI 跡象；創傷證據 |
| <span style="color:#22d3ee">**皮膚**</span> | 痤瘡；非典型痣；acanthosis nigricans；自殘證據 |

### C. 脊柱側彎篩查

- <span style="color:#60a5fa">**Adams 前彎測試**</span>：顯示肋骨突出或腰部隆起時考慮脊柱側彎
- 建議篩查年齡：10-18 歲（女性 10、12 歲；男性 13-14 歲）
