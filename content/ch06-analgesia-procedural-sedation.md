# 第六章：止痛與程序鎮靜

<span style="color:#60a5fa">**Alexander James Jaksic, MD 與 Divya Madhusudhan, MD**</span>

---

## 導讀摘要

本章節系統性地介紹兒童疼痛評估與管理，包括：疼痛分類（傷害感受性、神經性）、各年齡層評估工具（新生兒NIPS、FLACC、學齡前FACES量表）、止痛藥物（非類固醇消炎藥NSAIDs、鴉片類藥物）、局部麻醉藥理學、患者自控止痛（PCA）、鴉片類藥物漸減、以及程序鎮靜的各層級（輕度、中度、深度、解離性）與常用藥物（ketamine、propofol、dexmedetomidine、benzodiazepines）。臨床重點包括：codeine禁用於兒童、ketorolac腎毒性限制在5天內、ketamine對氣管插管反射的保護作用、及時識別局部麻醉藥全身毒性（LAST）的處置流程。

## I. 疼痛的類型

### A. 定義

#### 1. 疼痛的定義

「一種與實際或潛在組織損傷相關的不愉快感官及情緒體驗。」

#### 2. 疼痛可分為傷害感受性（nociceptive）或神經性（neuropathic）

### B. 疼痛類型

| 類別 | 機制/角色 | 常見臨床特徵 |
|------|----------|-------------|
| **傷害感受性—軀體性** | 適應性（保護性）疼痛，由功能正常的疼痛接受器（傷害感受器）對熱、機械或化學刺激產生反應（發炎/組織損傷） | 刺痛、銳痛、痠痛、搏動性疼痛、擠壓感、「壓力感」；較易定位 |
| **傷害感受性—內臟性** | 來自器官的疼痛（膀胱、腸道、卵巢/睪丸） | 深度、瀰散性；定位困難；鈍痛、「啃蝕感」、痙攣性、痠痛 |
| **神經性/功能障礙性** | 適應不良性疼痛，無明確保護效益；感覺神經損傷或功能障礙所致 | 灼痛、射痛、電擊樣、「針刺」感、刺痛；患者常難以描述 |
| **神經性疼痛** | 神經損傷所致（如：神經病變、神經瘤、三叉神經痛、帶狀疱疹後神經痛）或失控的慢性傷害感受性疼痛 | 依病因而異 |
| **功能障礙性疼痛** | 無已知神經病因，與訊號處理異常相關（如：纖維肌痛、腸躁症、間質性膀胱炎） | 依病因而異 |

## II. 疼痛評估

### A. 嬰兒（Infant）

#### 1. 生理反應

- 特色為缺氧、哭泣、出汗、臉部潮紅或蒼白，以及血壓、心率、呼吸頻率增加
- 主要見於急性疼痛；持續性/慢性疼痛時可能減弱

#### 2. 行為反應

觀察哭泣特徵與持續時間、面部表情、視線追蹤、身體動作及對刺激的反應。

**新生兒嬰兒疼痛量表（NIPS）**：用於早產兒及出生後6週內足月兒的行為評估工具。

**FLACC量表**（表6.2）：量化疼痛行為，包括面部表情、腿部動作、活動、哭泣、安撫程度，分數範圍0至10。修訂版FLACC（r-FLACC）適用於認知障礙兒童。

| FLACC 疼痛評估工具 | |
|-------------------|-------------|
| **臉部（Face）** | 0：無特殊表情或微笑<br>1：偶爾鬼臉或皺眉，退出、不感興趣<br>2：頻繁至持續性皺眉，下巴顫抖，牙關緊咬 |
| **腿部（Legs）** | 0：正常姿勢或放鬆<br>1：不安、静不下來、緊張<br>2：踢腿或雙腿蜷縮 |
| **活動（Activity）** | 0：安靜躺著，正常姿勢，容易移動<br>1：蠕動、來回移動、緊張<br>2：拱背、僵硬或抽動 |
| **哭泣（Cry）** | 0：無哭泣（清醒或睡眠中）<br>1：呻吟或嗚咽，偶爾抱怨<br>2：持續哭泣、尖叫或啜泣，頻繁抱怨 |
| **安撫（Consolability）** | 0：滿足、放鬆<br>1：偶爾觸摸、擁抱或說話安慰即可放心；可分心<br>2：難以安慰或安撫 |

### B. 學齡前兒童

除生理及行為反應外，**FACES疼痛量表修訂版（FPS-R）**可用於評估3歲以上兒童的疼痛強度，方式為讓患者指出最能描述其疼痛的臉孔。

### C. 學齡兒童及青少年

評估生理及行為反應；詢問疼痛描述、位置及特質。**從7歲起，兒童可使用標準主觀疼痛評分量表，0為無疼痛，10為經歷過的最嚴重疼痛。**

### D. 有顯著神經障礙的兒童（SNI）

#### 1. SNI兒童的疼痛常被低估及治療不足

#### 2. SNI兒童的疼痛行為反應可能與無SNI兒童相似或截然不同。擁有了解兒童基線行為及對疼痛與非疼痛刺激（如飢餓）反應的一致照護者提供有意義的輸入至關重要。

| SNI兒童可觀察疼痛行為 | |
|----------------------|-------------|
| **發聲** | 哭泣、呻吟、喘氣、尖銳吸氣 |
| **面部反應** | 鬼臉、瞇眼、皺眉、咬牙/牙關緊咬 |
| **互動** | 無法治癒、退出、尋求安慰 |
| **睡眠** | 睡眠障礙、睡眠增加或減少 |
| **活動/張力** | 基線動作/張力增加、不安/坐立不安、容易驚嚇、觸摸時退縮、扭轉或轉動、姿勢（拱背/僵硬）、抗拒移動 |
| **生理/非典型特徵** | 心搏過速、顫抖、顏色變化/蒼白、淚水<br>屏息、退出/缺乏面部表情、笑聲、自我傷害行為 |

#### 3. r-FLACC量表

- 與FLACC相似，為5項目疼痛評估工具，分數範圍0至10
- 設計允許家長添加其子女特有行為，對非典型疼痛行為兒童特別有幫助

**r-FLACC量表觀察重點：**
- 觀察兒童1-2分鐘（若睡著則觀察更久），腿部/身體裸露
- 觀察活動或協助兒童翻身以評估張力和 tone；必要時啟動安撫措施

## III. 止痛藥物

### A. 兒童應避免的藥物

#### 1. 複合止痛藥

- <span style="color:#f87171">**警告**：複合鴉片類-乙醯胺酚產品（oxycodone或hydrocodone加acetaminophen）有acetaminophen毒性風險</span>
- 建議分開處方鴉片類藥物和acetaminophen

#### 2. Codeine

- <span style="color:#f87171">**不建議用於兒童**</span>
- 5%人口對codeine有超快速代謝，會轉化為morphine（活性代謝物），可能導致危險的高濃度
- <span style="color:#f87171">在扁桃腺切除術及腺樣體切除術（T&A）用於睡眠呼吸中止症後特別危險</span>
- 在新生兒幾乎無止痛效果，約10%美國人口亦然

#### 3. Meperidine

- <span style="color:#f87171">**不建議用於兒童**——有神經毒性風險（躁動、顫抖、肌陣攣、癲癇）</span>
- <span style="color:#f87171">**禁用於接受單胺氧化酶（MAO）抑制劑的患者**</span>

#### 4. Tramadol

- 鴉片類止痛藥，兼有非鴉片類接受器作用
- 可能過度代謝為活性鴉片類代謝物，導致<span style="color:#f87171">**潛在致命的呼吸抑制**</span>
- <span style="color:#f87171">2017年FDA發布最強警告反對用於兒童；屬仿單標示外使用</span>

### B. 非鴉片類止痛藥

常用於管理輕至中度非內臟源性疼痛。可單獨使用或與鴉片類藥物合併使用。

#### 1. Acetaminophen（口服/直腸/靜脈）

- 弱止痛藥，無消炎活性、血小板抑制或腸胃刺激
- <span style="color:#f87171">高劑量可能發生肝毒性</span>

#### 2. Aspirin（口服/直腸）

- 與血小板抑制和腸胃刺激相關
- <span style="color:#f87171">**避免用於兒童止痛**——有Reye症候群風險</span>

#### 3. 非類固醇消炎藥（NSAIDs）

代表藥物：Ibuprofen（口服/靜脈）、<span style="color:#fb923c">Ketorolac</span>（靜脈/肌肉/口服/鼻內）、Naproxen（口服）、Diclofenac（口服/靜脈）、Celecoxib（口服）

- <span style="color:#f87171">**6個月以下兒童極謹慎使用**——擔心不良腸胃作用及腎衰竭風險</span>
- 對<span style="color:#34d399">**鐮刀型紅血球疾病**</span>及<span style="color:#34d399">**骨骼、風濕性或發炎性病因疼痛**</span>特別有用
- 長期使用建議併用組織胺H2受體阻斷劑或質子泵抑制劑
- 其他不良反應包括血小板聚集干擾、肝炎、支氣管收縮、過敏反應、氮質血症
- <span style="color:#f87171">**嚴重腎病、脫水或心衰竭患者禁用**</span>
- <span style="color:#f87171">**Ketorolac是強效止痛藥。限制療程少於5天以最小化腎毒性**</span>

### C. 鴉片類藥物（表6.5）

透過與腦和脊髓中的μ受體結合產生止痛作用。

#### 1. 副作用

<span style="color:#f87171">**常見副作用**：瘙癢、恶心、嘔吐、便秘、尿瀦留、鎮靜、呼吸抑制、低血壓。處方鴉片類藥物時應一併開立腸道方案。

#### 2. 腎衰竭患者

| 藥物 | 建議 |
|------|------|
| **Morphine** | <span style="color:#f87171">**避免使用**——活性代謝物排泄減少可能導致呼吸抑制</span> |
| **首選** | Fentanyl、remifentanil、methadone、hydromorphone、oxycodone |

| 藥物 | 等效比值 | 起始（分鐘） | 持續（小時） | 副作用 | 備註 |
|------|---------|------------|-------------|-------|------|
| **Morphine** | 80-100 | IV：1-2 | 0.5-1 | 瘙癢、心搏過緩、劑量>5μg/kg時胸壁僵硬（所有劑量皆可能發生）；以naloxone或神經肌肉阻斷劑治療 | 對低血量、先天性心臟病或頭部外傷患者，相對較其他鴉片類藥物安全 |
| **Fentanyl** | — | IV：1-2 | 1-3 | 呼吸抑制作用遠比止痛作用長（4小時） | 最常用於短暫疼痛程序，但經皮制劑對慢性疼痛更有效 |
| **Hydromorphone** | 4-7 | IV/SQ：5-10<br>口服：30-60 | 3-4 | 比morphine較少鎮靜、恶心、瘙癢 | |
| **Methadone** | 1.5 | IV：5-10<br>IM/SQ/口服：30-60 | 4-24 | 新生兒癲癇<br>可引起顯著組織胺釋放 | 對神經性疼痛及鴉片類減量有用（獨特的NMDA阻斷機制）<br>有持續釋放劑型 |
| **Oxycodone** | — | — | IV：3-4<br>IM/SQ/口服：4-5 | | 有持續釋放劑型 |

#### 3. 長效鴉片類藥物（如持續釋放錠劑、經皮貼片、靜脈注射methadone）**不建議用於急性疼痛管理**

#### 4. 雖然鴉片類藥物對中重度疼痛至關重要，但建議審慎處方數量——研究顯示<span style="color:#f87171">**處方劑量超過50%未被消耗**</span>

### D. 局部麻醉藥

局部或皮下給藥，圍繞周邊神經（周邊阻斷）或中央（硬膜外/脊椎阻斷）。暫時阻斷鈉通道的神經傳導。

#### 1. 所有局部麻醉藥：1%溶液＝1g/100mL＝10mg/mL

#### 2. 頂層局部麻醉藥（表6.6）

| 藥物 | 成分 | 適應症 | 峰效 | 持續時間 | 注意事項 |
|------|------|--------|------|---------|---------|
| **EMLA** | Lidocaine 2.5% + Prilocaine 2.5% | 完整皮膚<br>靜脈穿刺、包皮環切術、腰椎穿刺、骨髓穿刺 | 60分鐘 | 90分鐘 | <span style="color:#f87171">**methemoglobin血症**：不用於有methemoglobin血症傾向患者（如G6PD缺乏） |
| **LMX** | 同EMLA | 同EMLA | 30分鐘 | 30分鐘 | 嬰兒<3個月：謹慎使用（最多1g安全） |
| **LET** | Lidocaine 4% + Epinephrine 0.1% + Tetracaine 0.5% | 完整皮膚<br>安全用於非完整皮膚/撕裂傷<br>可與簡單撕裂傷止血併用 | 30分鐘 | 45分鐘 | <span style="color:#f87171">**禁用於終末动脉供應區域**（如：耳廓、手指、腳趾、鼻尖、陰莖） |
| **Viscous lidocaine** | Lidocaine 2% | 黏膜（如：尿道導管放置、黏膜炎） | 10分鐘 | 30分鐘 | 避免接觸黏膜<br>不用於長牙<br>過度使用可導致危及生命的毒性 |

#### 3. 注射用局部麻醉藥（表6.7）

| 藥物 | 濃度（%） | 最大劑量（mg/kg） | 起始（分鐘） | 持續（小時） |
|------|----------|-----------------|------------|------------|
| Lidocaine | 0.5-2 | 2.5 | 0.5-4 | 0.5-2 |
| Lidocaine + epinephrine | 0.5-2 | 2.5 | 0.5-4 | 1-3 |
| Bupivacaine | 0.25-0.75 | — | 2-15 | 2-4 |
| Bupivacaine + epinephrine | 0.25-0.75 | — | 2-15 | 4-8 |

**注射技巧：**
- 使用27-30 gauge針頭
- 鹼化：每9mL lidocaine（或29mL bupivacaine）加1mL（1mEq）碳酸氫鈉
- 加熱至37-42°C可減少注射疼痛
- 慢速注射可減少疼痛

**增強效果和持續時間：**
- 添加<span style="color:#fb923c">Epinephrine</span>（5-10μg epinephrine加至1mL局部麻醉藥）以減少血管吸收
- <span style="color:#f87171">**絕不將含epinephrine的局部麻醉藥用於終末动脉供應區域**</span>

**最大容量計算：最大mL＝（最大mg/kg劑量÷體重kg）÷（%溶液×10）**

**毒性：**

<span style="color:#f87171">**CNS及心臟毒性是最大疑慮。CNS症狀先於心血管虛脫出現。**</span>

症狀進展：<span style="color:#f87171">**口腔周圍麻木/頭暈/聽覺障礙→肌肉抽動→意識喪失→癲癇→昏迷→呼吸停止→心血管虛脫**</span>

<span style="color:#f87171">**若懷疑全身毒性，聯繫麻醉科並撥打中毒控制中心（1-800-222-1222）**</span>

### E. 非藥物疼痛緩解措施

#### 1. 蔗糖用於新生兒（Sugar-Ease）

**適應症**：新生兒及嬰兒的疼痛性小程序（腳跟穿刺、靜脈穿刺、肌肉注射）。對包皮環切疼痛無效。對<span style="color:#34d399">**小於1個月嬰兒**</span>證據最強，但研究顯示12個月內有效。

**程序**：
- 程序前2分鐘，以注射器或奶嘴/安撫奶嘴將最多2mL的24%蔗糖送入嬰兒口中
- 極低出生體重嬰兒有效劑量可低至0.05-0.1mL
- 短時間內可為多個程序給予額外劑量，但1小時內不超過兩次

**禁忌**：無法適當經口進食或無法安全處理口腔分泌物的患者

#### 2. 其他方法

家長陪伴/抱持、玩具分心、兒童生活專家、引導冥想/應對技巧、虛擬實境模擬、冷熱敷

## IV. 患者自控止痛（PCA）

### A. 定義

PCA使患者能夠根據需要接收有限次數的小劑量止痛藥，伴隨或不伴隨持續（基礎）輸注。
- 6歲以下或身心障礙兒童，家屬、照護者或護士可代為按下bolus
- 醫師指定：劑量、兩次劑量間最小時間（鎖定時間）、基礎輸注速率、每小時最大劑量

### B. 適應症

- 中至重度急性或慢性疼痛
- 常見於<span style="color:#34d399">**鐮刀型紅血球疾病、術後、創傷後、燒傷、癌症**</span>
- 有助於先發制人的疼痛管理（如：傷口換藥）

### C. 給藥途徑

- IV（首選）
- 硬膜外（應由麻醉科醫師處方及管理）

### D. 藥物（表6.8）

| 藥物 | 基礎速率（μg/kg/hr） | Bolus劑量（μg/kg） | 鎖定時間（分鐘） | Bolus/小時 | 最大劑量（μg/kg/hr） |
|------|---------------------|-------------------|----------------|-----------|--------------------|
| Morphine | 10-30 | 10-30 | 6-10 | 4-6 | 100-150 |
| Hydromorphone | 3-5 | 3-5 | 6-10 | 4-6 | 15-20 |
| Fentanyl | 0.5-1 | 0.5-1 | 6-10 | 2-3 | 2-4 |

### E. 輔助劑

#### 1. 低劑量naloxone（Narcan）輸注

減少與narcotic給藥相關的瘙癢和恶心發生率

#### 2. 低劑量ketamine輸注

具有narcotic節減效果的止痛藥。對化療誘發黏膜炎、內臟疼痛和神經性疼痛特別有幫助。作用機制為<span style="color:#60a5fa">**NMDA阻斷**</span>。可與methadone合併使用或作為替代。

### F. 鴉片類PCA副作用

見「止痛藥物」章節

## V. 鴉片類藥物漸減

### A. 適應症

若患者接受頻繁鴉片類止痛藥超過<span style="color:#34d399">**5天**</span>，由於依賴發展及戒斷可能性，需要漸減時間表。

### B. 戒斷

#### 1. 症狀：見Box 18.1

#### 2. 發作時間

- Morphine的最後一劑後<span style="color:#34d399">**6-12小時**</span>
- Methadone的最後一劑後<span style="color:#34d399">**36-48小時**</span>

#### 3. 持續時間

<span style="color:#34d399">**7-14天**</span>，2-4天內達到峰值強度

### C. 漸減建議

#### 1. 轉換

所有藥物應轉換為單一等效止痛藥（見表6.5）

#### 2. PCA漸減

將藥物劑量從持續/間歇IV輸注轉換為口服基礎/bolus治療。若患者使用PCA，給予第一個口服劑量後30-60分鐘停止PCA基礎輸注。PCA bolus劑量應繼續但減少25-50%。若接下來6小時無進一步bolus劑量，應停用PCA。

#### 3. 緩慢減量

間歇性IV/口服漸減期間，每1-2天將總日劑量減少原始劑量的<span style="color:#34d399">**10%-20%**</span>

#### 4. 口服方案

若先前未做，IV劑量應在出院前1-2天轉換為等效口服給藥

#### 5. 輔助治療

**Clonidine**與鴉片類藥物合併使用可減少新生兒戒斷症候群所需的戒斷時間，副作用少。<span style="color:#fb923c">Clonidine</span>有潛在用於重症兒童鎮靜、止痛和醫源性藥物戒斷的作用，但目前報告為回溯性或小型臨床試驗，劑量有顯著異質性，需進一步研究。<span style="color:#f87171">**1歲以下兒童禁用經皮給藥**</span>。

**Dexmedetomidine**是α2-腎上腺素受體激動劑，可產生鎮靜和輕度止痛，<span style="color:#60a5fa">**極少至無呼吸抑制**</span>。作為持續輸注給藥，已顯示可減少鴉片類需求並促進鴉片類減量。

## VI. 程序鎮靜

### A. 定義

#### 1. 輕度鎮靜（抗焦慮）

目的為抗焦慮，同時維持意識

#### 2. 中度鎮靜

原稱「意識鎮靜」。受控的意識抑制狀態，氣管反射和通暢性得以維持。患者能適當回應年齡適宜的命令（如「睜開眼睛」）和輕觸。此鎮靜程度通常以低劑量鎮靜催眠藥和止痛藥組合達到。

#### 3. 深度鎮靜

受控的意識抑制狀態，氣管反射和通暢性可能無法維持，但心血管功能通常得以維持。兒童對重複或疼痛刺激會有目的性反應。<span style="color:#f87171">**臨床上，深度鎮靜對大多數疼痛性程序是必要的。**</span>可通過<span style="color:#fb923c">Propofol</span>或鎮靜催眠藥和止痛藥組合達到此程度。

#### 4. 解離性鎮靜

<span style="color:#fb923c">Ketamine</span>特有的鎮靜狀態，其特徵為深度意識抑制和止痛。氣管反射和通暢性通常得以維持；然而，過多口腔分泌物可能成為問題，偶爾導致微吸入或喉痙攣。

### B. 準備

#### 1. 禁食（NPO）

| 食物類型 | 最短禁食時間（小時） |
|---------|-------------------|
| 清液體 | 2 |
| 母乳 | 3 |
| 非人類奶、配方奶 | 6 |
| 固體 | 依手術類型 |

對於選擇性程序的適度鎮靜，兒童應遵循與全身麻醉相同的禁食指南。對於緊急/緊急鎮靜（兒童非NPO），需權衡鎮靜和可能的吸入風險與及時執行程序的益處。<span style="color:#60a5fa">**近期研究顯示液體和固體的NPO狀態與吸入可能無統計學關聯，但研究有限。**</span>

#### 2. 重點病史

**過敏史、用藥史、任何先前對麻醉或鎮靜的反應**

**氣道不良事件可能性評估**（如：缺氧血症、高碳酸血症、面罩通氣困難）：
- 機械氣道阻塞（小頜、扁桃體/腺樣體肥大、巨舌、打鼾史、噪音呼吸史、阻塞性睡眠呼吸中止症、肥胖、顱面綜合徵）
- 肺部疾病（早產史、慢性肺部疾病、氣喘）
- <span style="color:#f87171">**近期上呼吸道感染（URI）**：URI增加喉痙攣和/或支氣管痙攣風險；對於需鎮靜的選擇性程序，建議在病情緩解後等待2-4週</span>

**吸入風險**（神經肌肉疾病、食道疾病、意識狀態改變、肥胖、懷孕）

**腎/肝病**（可能延長鎮靜作用）和**心臟病**（鎮靜藥給藥可能導致血流動力學不穩定）

#### 3. 身體檢查

特別注意<span style="color:#22d3ee">**口腔開合和頸部伸展**</span>。使用<span style="color:#22d3ee">**Mallampati分類系統**</span>評估氣道困難直接喉鏡檢查和插管的可能性。

#### 4. ASA身體狀態分類

| 等級 | 描述 |
|------|------|
| **I** | 正常健康患者 |
| **II** | 輕度全身疾病的患者（如：控制中的反應性氣道疾病） |
| **III** | 重度全身疾病的患者（如：正在喘息的兒童） |
| **IV** | 對生命持續威脅的重度全身疾病患者（如：氣喘持續狀態的兒童） |
| **V** | 預期不手術無法存活的垂死患者（如：嚴重心肌病變需心臟移植的患者） |
| **VI** | 宣布腦死、器官捐贈用途的患者 |

<span style="color:#60a5fa">**I和II級患者通常是手術室外進行輕度、中度或深度鎮靜的良好候選人。**</span>

#### 5. 始終準備緊急計劃

<span style="color:#f87171">**併發症最常見於IV藥物給藥後5-10分鐘及程序完成後立即（當與程序相關的刺激移除時）。**</span>

#### 6. 人員

需要<span style="color:#60a5fa">**兩名照護者**</span>。一人執行程序，另一人監測患者鎮靜和恢復情況。

#### 7. 確保靜脈通路

程序前以生理食鹽水沖洗。皮下浸潤鎮靜藥可導致不可預測或延長的鎮靜。

#### 8. 緊急插管/氣道設備立即可用（見第1章）

#### 9. 緊急藥物

隨時備有快速順序插管和CPR緊急藥物

#### 10. 拮抗劑隨時可用（naloxone、flumazenil）

### C. 監測

#### 1. 生命徵象

獲取基線生命徵象。鎮靜期間持續監測：

| 項目 | 監測方式 |
|------|---------|
| **氧合** | 持續脈搏血氧定量，變速音和低閾值警報 |
| **循環** | 持續心電圖，至少每5分鐘評估血壓和心率 |
| **通氣** | 鎮靜期間頻繁評估呼吸頻率和氣道通暢性（直接可視化和聽診）；中度或深度鎮靜時持續潮氣末二氧化碳監測（EtCO2） |

<span style="color:#f87171">**未識別的呼吸暫停後，若未接受補充氧氣，通常在1-2分鐘內出現去飽和。補充氧氣可能進一步延遲呼吸暫停的識別。**</span>

### D. 藥理學藥劑

#### 1. 程序鎮靜目標

給藥以提供適當的止痛、鎮靜和抗焦慮程度，使程序得以進行而不需固定氣道。

#### 2. CNS、心血管和呼吸抑制可能隨時發生

<span style="color:#f87171">**當合併使用鎮靜藥物和/或鴉片類藥物，或快速給藥時更常見。**</span>始終以滴定方式達到所需鎮靜程度。

#### 3. 常見鎮靜/催眠藥劑

| 藥物類別 | 特點 |
|---------|------|
| **鎮靜抗組織胺**<br>（Diphenhydramine、Hydroxyzine） | 輕度鎮靜催眠藥，有止吐和止癢特性；無抗焦慮或止痛作用 |
| **Barbiturates** | <span style="color:#f87171">**禁用於紫質症患者**</span>；僅適合無疼痛程序；不可用flumazenil逆轉；無抗焦慮或止痛作用 |
| **Benzodiazepines** | 可用flumazenil逆轉；有抗焦慮作用；無止痛作用 |
| **鴉片類藥物** | 可用naloxone逆轉；有止痛作用；無抗焦慮作用 |
| **Ketamine** | 引起強效解離性健忘和止痛<br>眼球震顫表示可能有療效<br>發作：IV 0.5-2分；IM 5-10分；口服/直腸 20-45分<br>持續：IV 20-60分；IM 30-90分；口服/直腸 60-120+分<br><span style="color:#f87171">**CNS效應：出現聽覺、視覺和觸覺幻覺的 emergence delirium**</span><br><span style="color:#22d3ee">**心血管效應**：抑制catecholamine再攝取，導致心率、血壓、全身血管阻力、肺血管阻力增加。罕見血流動力學不穩定；但在catecholamine耗竭患者（如休克）可引起直接心肌抑制和低血壓。</span><br><span style="color:#22d3ee">**呼吸效應**：支氣管擴張（對氣喘患者有用）、分泌物增加（可致喉痙攣）、維持對缺氧的通氣反應、相對維持氣管反射<br><span style="color:#f87171">**禁忌**：高血壓和既存精神障礙</span><br>對顱內壓或眼壓升高患者安全性的爭議存在。 |
| **Propofol** | 深度鎮靜或全身麻醉<br>快速起始和短恢復（bolus給藥5-15分鐘）<br><span style="color:#f87171">**注意**：呼吸抑制、呼吸暫停、低血壓；無止痛作用 |
| **Dexmedetomidine** | α2激動劑<br>鎮靜、抗焦慮和止痛作用<br>IV：負載10分鐘後輸注<br>鼻內：可無IV通路給藥<br>相對其他IV鎮靜催眠藥起始較慢<br><span style="color:#60a5fa">**優點：低呼吸抑制風險**</span><br><span style="color:#f87171">**可引起低血壓（初始bolus）、高血壓（大劑量、多重bolus）和心搏過緩（避免用於房室結阻斷藥物患者）**</span> |

#### 4. 逆轉劑

| 藥物 | 作用 |
|------|------|
| **Naloxone** | 鴉片類拮抗劑 |
| **Flumazenil** | Benzodiazepine拮抗劑 |

### E. 出院標準

1. 患者能在不需補充氧氣的情況下維持氣道通暢；心血管功能無損害
2. 患者易於喚醒，保護性氣管反射完整（吞嚥、咳嗽、作嘔）
3. 患者能獨自說話和坐起（如年齡適宜）。幼兒或智障兒童的目標是恢復鎮靜前反應程度
4. 確保能維持足夠水分補充（患者能耐受腸道液體）

### F. 鎮靜協議範例

| 程序 | 疼痛閾值 | 建議選擇 |
|------|---------|---------|
| 非疼痛性CT/MRI/EEG/ECHO | 輕度 | Midazolam、<span style="color:#fb923c">Dexmedetomidine</span> |
| 靜脈穿刺 | 輕度 | EMLA |
| 腰椎穿刺 | 輕度 | EMLA（± midazolam）、lidocaine |
| 簡單撕裂傷（良好血管化） | 輕度 | Midazolam、LET |
| 簡單撕裂傷（非良好血管化） | 中度 | Lidocaine（局部） |
| 骨髓穿刺、關節穿刺 | 中度 | EMLA（± midazolam）；ketamine（用於不合作兒童） |
| 骨折復位、重大撕裂傷、燒傷清創、牙科 | 重度 | <span style="color:#fb923c">Ketamine</span>或fentanyl + midazolam |
| 靜脈導管置入 | 重度 | <span style="color:#fb923c">Ketamine</span>、<span style="color:#fb923c">Dexmedetomidine</span> + fentanyl<br>考慮全身麻醉 |
