# 第十章：骨科學

<span style="color:#60a5fa">**Orthopedics**</span>

---

## 導讀摘要

本章節系統性介紹兒童骨科學疾病的評估與管理。涵蓋內容包括：創傷處置原則（骨折分類、開放性骨折、軟組織損傷）、常見兒童骨折（鎖骨、肱骨近端、橈骨遠端、手部、股骨、脛骨）、生長板損傷、關節損傷（脫臼、韌帶損傷）、發育性骨骼疾病（發育性髖關節發育不良DDH、Perthes病、股骨頭骨骺滑脫SCFE、青少年脊椎側彎）、步態異常、以及骨科感染的處置（骨髓炎、化膿性關節炎）。臨床重點包括：兒童骨折的獨特考量（生長板、骨膜厚、骨塑型能力）、不同年齡的常見骨折型態、肩難測驗和Trendelenburg測驗的臨床應用、以及何時需轉介骨科專家。

## I. 創傷處置基本原則

### A. 初評估（ABCDE）

| 步驟 | 內容 |
|------|------|
| **A（氣道）** | 確認氣道通暢，頸椎保護 |
| **B（呼吸）** | 呼吸頻率、氧合 |
| **C（循環）** | 脈搏、血壓、灌注指標 |
| **D（神經狀態）** | 意識程度、運動/感覺功能 |
| **E（曝光）** | 完全暴露檢查，環境控制 |

### B. 骨折分類

#### 1. 依骨折型態

| 分類 | 說明 |
|------|------|
| **封閉性（閉合性）** | 皮膚完整 |
| **開放性** | 皮膚破損；感染風險增加 |
| **簡單性** | 單一骨折線 |
| **粉碎性** | 多碎片 |
| **移位性** | 骨折端分離 |
| **非移位性** | 骨折端對齊 |

#### 2. 依骨折線方向

| 分類 | 說明 |
|------|------|
| **橫向骨折** | 骨折線垂直於骨長軸 |
| **斜向骨折** | 骨折線斜向 |
| **螺旋骨折** | 骨折線螺旋狀——提示<span style="color:#60a5fa">**旋轉暴力**</span> |
| **壓迫骨折** | 關節面壓迫 |
| **爆裂骨折** | 關節內多碎片 |

### C. 開放性骨折處理

<span style="color:#f87171">**緊急情況——感染風險高**</span>

| 步驟 | 處置 |
|------|------|
| **1. 抗生素** | <span style="color:#fb923c">**第一代頭孢菌素**</span>（如骨折固定前）<br><span style="color:#fb923c">**氨基糖苷類**</span>（依傷口污染程度） |
| **2. 破傷風預防** | 依破傷風免疫狀態 |
| **3. 傷口冲洗** | 大量生理食鹽水（最少9L） |
| **4. 骨折固定** | 外部固定或內固定 |
| **5. 延遲傷口關閉** | 通常48-72小時後 |

<span style="color:#f87171">**開放性骨折的Gustilo-Anderson分類**：</span>

| 分類 | 傷口大小 | 軟組織損傷 | 骨損傷 |
|------|---------|-----------|--------|
| **I型** | <1 cm | 輕度 | 簡單横断/斜向 |
| **II型** | >1 cm | 中度 | 中度粉碎 |
| **IIIa型** | >10 cm | 嚴重但可覆蓋 | 嚴重粉碎 |
| **IIIb型** | >10 cm | 嚴重；骨外露 | 骨缺損；需軟組織覆蓋 |
| **IIIc型** | >10 cm | 嚴重；骨外露 | 合併<span style="color:#f87171">**血管損傷**</span> |

### D. 軟組織損傷分類

| 分類 | 說明 |
|------|------|
| **扭傷（Sprain）** | 韌帶過度伸展或部分撕裂 |
| **拉傷（Strain）** | 肌肉/肌腱過度伸展或部分撕裂 |
| **挫傷（Contusion）** | 軟組織鈍傷 |
| **脱臼（Dislocation）** | 關節面完全分離 |
| **半脱位（Subluxation）** | 關節面部分分離 |

## II. 常見兒童骨折

### A. 鎖骨骨折

#### 1. 機制

<span style="color:#60a5fa">**最常見的兒童骨折**</span>——通常為直接創傷或摔倒時手臂外展

#### 2. 治療

| 骨折類型 | 治療 |
|---------|------|
| **中段骨折（無移位）** | 吊帶固定；疼痛控制 |
| **中段骨折（輕度移位）** | 8字形繃帶或吊帶 |
| **遠端1/3骨折** | 依骨片大小和移位程度 |
| **移位明顯或皮膚受威脅** | <span style="color:#f87171">**手術修復**</span> |

<span style="color:#60a5fa">**癒合時間**：嬰兒3-4週；年長兒6-8週

### B. 肱骨近端骨折

#### 1. 機制

摔倒時手臂外展；直接肩部創傷

#### 2. 分類

| 分類 | 說明 |
|------|------|
| **乾骺端骨折** | 最常見；常無移位 |
| **外科頸骨折** | 青少年 |
| **骨骺分離** | 青春期前 |

#### 3. 治療

| 骨折類型 | 治療 |
|---------|------|
| **無移位或輕度移位** | 吊帶固定；早期活動 |
| **移位明顯（>45度或>50%移位）** | <span style="color:#fb923c">**閉合復位**</span> |
| **無法閉合復位** | 手術開放復位 |

### C. 橈骨遠端骨折（Colles骨折）

#### 1. 機制

<span style="color:#60a5fa">**最常見的手臂骨折**</span>——摔倒時手掌撐地

#### 2. 治療

| 骨折類型 | 治療 |
|---------|------|
| **無移位** | 前臂固定4-6週 |
| **背側成角（<15度）** | 封閉復位 + 固定 |
| **背側成角（>15度）或移位明顯** | <span style="color:#fb923c">**封閉復位 + 石膏或外固定**</span> |
| **關節內移位骨折** | 手術考量 |

### D. 手部骨折

#### 1. 常見手部骨折

| 骨折位置 | 說明 |
|---------|------|
| **近節指骨** | 手指骨折最常見 |
| **掌骨** | 拇指掌骨（Bennett骨折） |
| **舟狀骨** | 摔倒時手腕撐地；舟狀骨骨折可能延遲癒合 |

#### 2. 治療原則

| 原則 | 說明 |
|------|------|
| **閉合復位** | 依骨折穩定性 |
| **穩定固定** | 對不穩定骨折 |
| **早期活動** | 穩定骨折 |

### E. 股骨骨折

#### 1. 股骨幹骨折

| 年齡 | 治療 |
|------|------|
| **<6個月** | Pavlik harness或軟性固定 |
| **6個月-5歲** | <span style="color:#fb923c">**Pavlik harness（幼兒）**</span>或骨牵引 |
| **5-11歲** | 彈性髓內針（TEN）或外固定 |
| **>11歲（青春期）** | 青少年：髓內針固定 |

#### 2. 股骨近端骨折

| 骨折類型 | 說明 |
|------|------|
| **股骨頭骨骺滑脫（SCFE）** | 青少年肥胖兒童 |
| **股骨頸骨折** | 高能量創傷 |

### F. 脛骨骨折

| 骨折類型 | 說明 |
|---------|------|
| **脛骨平台骨折** | 青少年；運動創傷 |
| **脛骨幹骨折** | 螺旋骨折（扭傷）；直接創傷 |
| **Toddler's fracture** | 1-3歲；學步期兒童；螺旋骨折 |

### G. 踝部骨折

| 分類 | 說明 |
|------|------|
| **旋轉損傷** | 青少年最常見 |
| **Salter-Harris分型** | 依骨骺/生長板受侵犯程度分類 |

## III. 生長板損傷

### A. 生長板特點

<span style="color:#60a5fa">**兒童骨骼獨有——骨折治療的關鍵考量**</span>

| 特點 | 說明 |
|------|------|
| **生長板軟骨** | 骨骼縱向生長的來源 |
| **容易受傷** | 生長板是骨骼最脆弱的部分 |
| **損傷影響生長** | 依損傷嚴重程度 |

### B. Salter-Harris分類

| 分型 | 圖示 | 說明 | 預後 |
|------|------|------|------|
| **I型** | 骨折線通過生長板 | 生長板分離 | <span style="color:#34d399">**最好**</span> |
| **II型** | 骨折線通過生長板+乾骺端 | 生長板+乾骺端 | <span style="color:#34d399">**良好**</span> |
| **III型** | 骨折線通過生長板+骨骺 | 生長板+骨骺 | **尚可** |
| **IV型** | 骨折線通過生長板+骨骺+乾骺端 | 骨骺+生長板+乾骺端 | **較差** |
| **V型** | 生長板壓迫損傷 | 生長板壓迫 | <span style="color:#f87171">**最差**</span> |

<span style="color:#60a5fa">**Type V（生長板壓迫）診斷困難——常在生長停止後才確診**</span>

### C. 生長板損傷治療原則

| 原則 | 說明 |
|------|------|
| **精確復位** | 恢復解剖位置 |
| **避免過度操作** | 生長板軟骨脆弱 |
| **避免損傷血供** | 骨骺血供重要 |
| **密切追蹤** | 監測生長障礙 |

## IV. 關節損傷

### A. 脫臼

#### 1. 常見脫臼

| 關節 | 說明 |
|------|------|
| **肩關節** | 前脫臼最常見；創傷後 |
| **肘關節** | 後脫臼；常因摔倒時手臂伸展 |
| **髖關節** | <span style="color:#f87171">**創傷後髖關節脫臼是急症**</span> |
| **橈骨頭半脫位** | "Pulled elbow"；5歲以下 |

#### 2. 治療

| 脫臼類型 | 治療 |
|---------|------|
| **肩關節前脫臼** | 閉合復位+固定3-4週 |
| **肘關節後脫臼** | 閉合復位；復位後穩定性評估 |
| **髖關節脫臼** | <span style="color:#f87171">**緊急閉合/開放復位**</span>；6小時內復位 |

<span style="color:#f87171">**髖關節脫臼延遲復位會增加股骨頭缺血性壞死風險**</span>

### B. 韌帶損傷

#### 1. 膝關節韌帶

| 韌帶 | 損傷機制 | 測驗 |
|------|---------|------|
| **前十字韌帶（ACL）** | 跳躍/扭轉 | Lachman測驗、前拉測驗 |
| **後十字韌帶（PCL）** | 直接撞擊（"dashboard injury"） | 後拉測驗 |
| **內側副韌帶（MCL）** | 外翻壓力 | 外翻應力測驗 |
| **外側副韌帶（LCL）** | 內翻壓力 | 內翻應力測驗 |

#### 2. 治療

| 損傷程度 | 治療 |
|---------|------|
| **第一級（輕度拉伸）** | 保守治療；RICE原則 |
| **第二級（部分撕裂）** | 保守治療或的手術取決於穩定性 |
| **第三級（完全撕裂）** | 手術修復（依年齡和運動需求） |

## V. 發育性骨骼疾病

### A. 發育性髖關節發育不良（DDH）

#### 1. 風險因子

| 風險因子 | 說明 |
|---------|------|
| **女性** | 男:女=1:4 |
| **第一胎** | |
| **臀位分娩** | |
| **家族史** | 父母或兄姐有DDH |
| **羊水過少** | |

#### 2. 臨床發現

| 年齡 | 發現 |
|------|------|
| **新生兒** | Barlow測驗（不穩定性）、Ortolani測驗（復位感） |
| **嬰兒** | Galeazzi徵象（腿長差異）、大腿/臀褶不對稱 |
| **幼兒** | 跛行、Trendelenburg步態 |

#### 3. 診斷

| 方法 | 說明 |
|------|------|
| **理學檢查** | 仍是新生兒和嬰兒主要篩檢工具 |
| **超音波** | <span style="color:#60a5fa">**<4-6個月嬰兒首選**</span> |
| **X光** | >4-6個月 |

#### 4. 治療

| 年齡 | 治療 |
|------|------|
| **<6個月** | <span style="color:#fb923c">**Pavlik harness**</span> |
| **6-18個月** | 閉合復位 + 人字形石膏固定 |
| **>18個月** | 手術開放復位 |

### B. Legg-Calvé-Perthes病

#### 1. 定義

<span style="color:#60a5fa">**兒童特發性股骨頭缺血性壞死**</span>

| 特點 | 說明 |
|------|------|
| **年齡** | 4-10歲；高峰4-8歲 |
| **性別** | 男:女=4:1 |
| **種族** | 北歐裔較常見 |

#### 2. 臨床表現

| 表現 | 說明 |
|------|------|
| **隱匿發病的跛行** | 最常見 |
| **髖關節疼痛** | 可能放射至大腿/膝蓋 |
| **活動範圍受限** | 內旋和外展減少 |
| **疼痛步態** | 保護性步態 |

#### 3. 治療原則

| 目標 | 說明 |
|------|------|
| **緩解疼痛** | |
| **維持髖關節活動度** | |
| **促進股骨頭重塑** | 包含在股骨頭內 |
| **預防股骨頭變形** | |

| 治療方法 | 適應症 |
|---------|--------|
| **保守治療** | <6歲；輕度壞死 |
| **手術治療（截骨術）** | >8歲；廣泛壞死 |

### C. 股骨頭骨骺滑脫（SCFE）

#### 1. 定義

<span style="color:#60a5fa">**青少年股骨頭骨骺在生長板向前下方滑脫**</span>

| 特點 | 說明 |
|------|------|
| **年齡** | 10-16歲；生長快速期 |
| **性別** | 男:女=2:1 |
| **體重** | 肥胖兒童風險增加 |

#### 2. 分類

| 分類 | 說明 |
|------|------|
| **急性** | 突發疼痛和活動障礙 |
| **慢性** | 數週至數月的間歇性疼痛和跛行 |
| **慢性急性發作** | 慢性基礎上的急性惡化 |

#### 3. 臨床發現

| 發現 | 說明 |
|------|------|
| **髖關節/腹股溝/大腿/膝蓋疼痛** | 疼痛可放射至膝蓋 |
| **跛行** | |
| **外旋姿勢** | 受影響側腿 |
| **活動範圍受限** | 內旋和屈曲減少 |
| ** Drehmann徵象** | 被動內旋時強制屈曲 |

#### 4. 治療

<span style="color:#f87171">**目標：穩定骨骺、預防進一步滑脫**</span>

| 方法 | 說明 |
|------|------|
| **原位固定** | <span style="color:#fb923c">**多數病例的首選**</span>——用螺絲固定骨骺 |
| **截骨術** | 嚴重滑脫或原位固定失敗 |

<span style="color:#f87171">**SCFE是骨科急症——延遲治療增加股骨頭缺血性壞死風險**</span>

### D. 青少年脊椎側彎

#### 1. 定義

<span style="color:#60a5fa">**Cobb角>10度的脊柱側向彎曲**</span>

#### 2. 篩檢

| 方法 | 說明 |
|------|------|
| **Adam's前彎測驗** | 觀察背部不對稱 |
| ** scoliometer** | 測量旋轉角度 |
| **X光** | 站立全脊柱正側位 |

#### 3. 治療

| Cobb角 | 治療 |
|--------|------|
| **<25度** | 觀察；每6-12個月追蹤 |
| **25-40度** | <span style="color:#fb923c">**背架**</span>（在骨骼成熟前） |
| **>40-50度** | 手術（脊柱融合） |

## VI. 步態異常

### A. 常見步態異常

| 步態 | 說明 | 相關情況 |
|------|------|---------|

### B. 評估工具

| 測驗 | 目的 |
|------|------|
| **Trendelenburg測驗** | 評估髖關節外展肌功能 |
| **足尖/足跟行走** | 評估背屈/蹠屈肌 |
| **手掌握力** | 評估整體肌力 |

## VII. 骨科感染

### A. 急性血源性骨髓炎

#### 1. 病因

<span style="color:#c084fc">**最常見致病菌**：<span style="color:#fb923c">**金黃色葡萄球菌（S. aureus）**</span>

| 致病菌 | 說明 |
|--------|------|
| **金黃色葡萄球菌** | <span style="color:#c084fc">**最常見（80-90%）**</span> |
| **A群β溶血性鏈球菌** | |
| **B群鏈球菌** | 新生兒 |
| **Kingella kingae** | <3歲兒童 |
| **H. influenzae** | <5歲（越來越少見） |

#### 2. 臨床表現

| 表現 | 說明 |
|------|------|
| **發燒** | 常見 |
| **局部紅、腫、熱、痛** | 炎症四徵 |
| **不願意負重** | 下肢骨髓炎 |
| **不願意移動** | 受影響肢體 |

#### 3. 診斷

| 方法 | 說明 |
|------|------|
| **理學檢查** | 局部壓痛、活動受限 |
| **X光** | 發病10-14天後才有變化 |
| **MRI** | 早期敏感；骨髓水腫 |
| **骨骼掃描** | 早期定位感染 |
| **血液培養** | 50%陽性 |

#### 4. 治療

| 情況 | 治療 |
|------|------|
| **初期** | <span style="color:#fb923c">**靜脈抗生素**</span> 4-6週 |
| **膿液形成** | 手術引流 + IV抗生素 |
| **慢性/復發** | 手術清創 + 長期抗生素 |

### B. 化膿性關節炎

#### 1. 致病菌

| 年齡 | 常見致病菌 |
|------|-----------|
| **<3個月** | <span style="color:#c084fc">**金黃色葡萄球菌、B群鏈球菌、大腸桿菌**</span> |
| **3個月至5歲** | <span style="color:#c084fc">**金黃色葡萄球菌、A群β溶血性鏈球菌、K. kingae**</span> |
| **>5歲** | <span style="color:#c084fc">**金黃色葡萄球菌**</span> |

#### 2. 臨床表現

| 發現 | 說明 |
|------|------|
| **關節疼痛** | 被動活動時加劇 |
| **關節腫脹/積液** | 關節穿刺有膿 |
| **活動受限** | 關節囊內積液 |
| **發燒** | |

#### 3. 治療

<span style="color:#f87171">**急診——需立即處理**</span>

| 步驟 | 處置 |
|------|------|
| **1. 關節穿刺** | 診斷和引流 |
| **2. 培養和Gram染色** | 指導抗生素選擇 |
| **3. 抗生素** | <span style="color:#fb923c">**IV抗生素**</span> |
| **4. 手術引流** | 封閉性吸引或開放引流 |

<span style="color:#f87171">**延遲治療導致軟骨破壞和關節功能永久喪失**</span>

## VIII. 肌肉骨骼疾病的康復原則

### A. RICE原則

| 字母 | 處置 | 時間 |
|------|------|------|
| **R（Rest）** | 休息 | 受傷後24-72小時 |
| **I（Ice）** | 冰敷 | 15-20分鐘/次，每2-3小時 |
| **C（Compression）** | 加壓 | 彈性繃帶 |
| **E（Elevation）** | 抬高 | 高於心臟水平 |

### B. 拐杖和助行器使用

| 適應症 | 輔具 |
|--------|------|
| **單下肢承重限制** | 拐杖（腋下或前臂） |
| **雙下肢或平衡問題** | 助行器 |
| **不願意負重** | 輪椅 |

### C. 石膏和固定

| 類型 | 說明 |
|------|------|
| **短腿石膏** | 踝關節和足部骨折 |
| **長腿石膏** | 膝蓋和小腿骨折 |
| **肩部固定** | 肩關節損傷 |
| **功能性支架** | 允許早期活動 |

## IX. 何時轉介骨科

### A. 緊急轉介（24小時內）

<span style="color:#f87171">**以下情況需立即骨科會診**：</span>

| 情況 | 說明 |
|------|------|
| **開放性骨折** | |
| **脫臼未復位** | 尤其髖關節 |
| **骨筋膜室症候群** | 急性5P：疼痛、蒼白、無脈、感覺異常、癱瘓 |
| **血管損傷跡象** | 受影響肢體無脈搏或蒼白 |
| **神經損傷跡象** | 感覺或運動喪失 |
| **關節內骨折** | 需精確復位 |
| **股骨頭骨骺滑脫（SCFE）** | 骨科急症 |

| 情況 | 說明 |

| **需手術治療的骨折** | |
