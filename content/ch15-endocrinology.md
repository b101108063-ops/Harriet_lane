## 導讀摘要

本章節涵蓋<span style="color:#60a5fa">過敏性鼻炎</span>、<span style="color:#60a5fa">食物過敏</span>、<span style="color:#60a5fa">藥物過敏</span>以及<span style="color:#60a5fa">免疫缺陷疾病</span>的診斷與管理，並提供<span style="color:#60a5fa">免疫球蛋白療法</span>（IVIG、IMIG、SCIG）的臨床應用指引及免疫學參考數值。

過敏性鼻炎是兒童最常見的慢性疾病（盛行率高達40%），<span style="color:#60a5fa">鼻內皮質類固醇</span>是最有效的單一療法。食物過敏的診斷需結合病史、皮膚點刺試驗和特異性IgE檢測，<span style="color:#f87171">口服食物挑戰</span>是確診和評估是否已耐受的金標準。免疫缺陷疾病的臨床表現包括<span style="color:#f87171">反覆或伺機性感染、自體免疫疾病</span>，初步評估需測量免疫球蛋白水平和特定抗體反應。

## I. 過敏性鼻炎（Allergic Rhinitis）

### A. 流行病學與風險因素

| 項目 | 說明 |
|---|---|
| 盛行率 | 高達<span style="color:#34d399">40%</span>兒童（最常見的兒童慢性疾病） |
| 增加風險 | 過敏家族史、高社經地位、胎兒期和幼兒期暴露於菸草暴露、特應性體質史（濕疹、食物過敏） |
| 共病 | 增加復發性中耳炎、氣喘、急慢性鼻竇炎風險 |

### B. 臨床表現

| 類型 | 說明 |
|---|---|
| <span style="color:#60a5fa">季節性</span> | 依當地過敏原（花粉、黴菌）有季節性波動 |
| <span style="color:#60a5fa">常年性</span> | 整年持續，通常有季節性高峰 |

**典型症狀：**
- **鼻子：** 充血、流鼻水、鼻癢
- **眼睛：** 癢、流淚
- **鼻後滴漏：** 喉嚨痛、咳嗽

**過敏面容：** <span style="color:#22d3ee">眼下黑影</span>（allergic shiners）、口呼吸、<span style="color:#22d3ee">鼻部橫向皺褶（allergic salute）</span>、鼻黏膜蒼白腫大

### C. 藥物治療

| 藥物類別 | 代表藥物 | 建議 | 不良反應 |
|---|---|---|---|
| <span style="color:#fb923c">口服第二代抗組織胺</span> | cetirizine、levocetirizine、fexofenadine、loratadine | 輕度或間歇性症狀的首選 | 嗜睡（第二代比第一代輕微） |
| <span style="color:#fb923c">口服白三烯抑制劑</span> | montelukast | 對其他治療無效或不耐受時考慮 | <span style="color:#f87171">嚴重神經精神事件（自殺意念）</span> |
| <span style="color:#fb923c">鼻內抗組織胺</span> | azelastine、olopatadine | 急性症狀；比鼻內類固醇更快見效 | 苦味 |
| <span style="color:#fb923c">鼻內皮質類固醇</span> | fluticasone、mometasone、budesonide | **持續性或中重度症狀的首選單一療法**；對鼻充血和眼部症狀最有效 | 鼻腔刺激、出血、生長速度減緩（高劑量） |

> **過敏原避免：** 高效率微粒空氣過濾器（HEPA）、過敏原防護床墊、徹底室內清潔

## II. 食物過敏（Food Allergy）

### A. 流行病學

| 項目 | 數值 |
|---|---|
| 盛行率 | 幼兒<span style="color:#34d399">6-8%</span>；青少年<span style="color:#34d399">3-4%</span> |
| 最常見過敏原 | 牛奶、蛋、<span style="color:#c084fc">花生</span>、<span style="color:#c084fc">樹堅果</span>（腰果、核桃）、大豆、魚、貝類、小麥 |

### B. 診斷流程

```
懷疑食物過敏 → 確認對特定食物的病史
                    ↓
              是否為IgE媒介？
              /                \
            是                 否
            ↓                   ↓
      皮膚點刺試驗          Elimination diet
      或                    ＋
      特異性IgE            食物挑戰
            ↓
    結果陽性 → 嚴格避免
    結果陰性 → 恢復飲食或進行食物挑戰
```

### C. 臨床表現

| 類別 | 表現 |
|---|---|
| <span style="color:#60a5fa">IgE媒介型</span> | 蕁麻疹/血管性水腫、<span style="color:#f87171">全身性過敏反應</span>、口腔過敏症候群 |
| <span style="color:#60a5fa">非IgE媒介型</span> | 食物蛋白誘發小腸結腸炎症候群（FPIES）：嬰兒期發病，嘔吐和腹瀉（可含血），嚴重時意識障礙、脫水、低血壓 |
| <span style="color:#60a5fa">混合型</span> | 過敏性嗜伊紅性胃腸炎/食管炎（見胃腸道章節） |

### D. 治療與管理

| 處置 | 說明 |
|---|---|
| <span style="color:#f87171">過敏原避免</span> | 最重要的介入；「不能閱讀就不能吃」原則 |
| <span style="color:#f87171">過敏原行動計畫</span> | 具體過敏原列表、觀察症狀、給藥指示；確保學校可執行 |
| <span style="color:#fb923c">Epinephrine自注射器</span> | 所有高風險患者開立；兩包不應分開放置；隨時備妥 |
| <span style="color:#fb923c">抗組織胺/皮質類固醇</span> | 用於非過敏性血管性水腫/蕁麻疹 |
| <span style="color:#fb923c">Omalizumab</span> | 獲准用於慢性蕁麻疹 |

### E. 自然病史

| 過敏原 | 緩解率 |
|---|---|
| 牛奶、蛋、大豆、小麥 | 約<span style="color:#34d399">50%</span>在學齡時緩解 |
| <span style="color:#c084fc">花生、樹堅果、貝類</span> | 僅<span style="color:#34d399">10-20%</span>緩解 |

> **預防：** 4-6個月大時早期引入花生食品可顯著降低花生過敏風險（適用於高風險嬰兒：嚴重濕疹和/或蛋過敏）

## III. 藥物過敏（Drug Allergy）

### A. 基本概念

| 術語 | 定義 |
|---|---|
| <span style="color:#60a5fa">藥物過敏</span> | 免疫介導的反應 |
| <span style="color:#60a5fa">藥物不耐</span> | 非免疫性，不良藥理作用 |

> **重要數據：** 10%患者報告<span style="color:#c084fc">盤尼西林</span>過敏，但評估後約90%可耐受。

### B. 青黴素過敏評估流程

```
有藥物過敏史？
    ↓是              ↓否
有PCN過敏史？    使用適當藥物
    ↓是         （首選藥物）
患者近期使用抗組織胺？
    ↓是               ↓否
  不做皮膚測試     做PCN皮膚測試
                   （主要和次要抗原）
                        ↓
                   陽性 → 脫敏/漸進式挑戰
                   陰性 → 可使用PCN
```

### C. 管理原則

| 方法 | 適用情況 |
|---|---|
| <span style="color:#60a5fa">避免</span> | 優先選擇替代療法 |
| <span style="color:#60a5fa">脫敏（Desensitization）</span> | 進行性給予過敏性物質使免疫系統反應性降低 |
| <span style="color:#60a5fa">漸進式挑戰（Graded challenge）</span> | 漸進增加劑量至完整劑量；不修改患者對藥物的反應 |

## IV. 免疫缺陷（Immunodeficiency）

### A. 臨床表現

| 類別 | 警示表現 |
|---|---|
| <span style="color:#f87171">感染易感性↑</span> | 每年≥4次新耳部感染、≥2次嚴重鼻竇炎、≥2次肺炎、復發性組織或器官膿腫、持續鵝口瘡或皮膚黴菌感染 |
| <span style="color:#f87171">伺機性感染</span> | <span style="color:#c084fc">Pneumocystis jirovecii</span>、<span style="color:#c084fc">Mycobacterium avium</span> |
| 自體免疫/發炎 | 自體免疫溶血性貧血、免疫血小板減少、<span style="color:#22d3ee">SLE</span> |
| 複合徵候群 | Wiskott-Aldrich（血小板減少＋濕疹）；<span style="color:#22d3ee">DiGeorge</span>（先天性心臟病＋面部異形＋副甲狀腺功能低下） |

### B. 評估——免疫球蛋白和抗體

| 檢測 | 說明 |
|---|---|
| <span style="color:#60a5fa">免疫球蛋白（IgG、IgM、IgA）</span> | 評估體液免疫；IgG < <span style="color:#34d399">400 mg/dL</span>提示抗體缺乏 |
| <span style="color:#60a5fa">特定抗體測定</span> | 對T細胞依賴性蛋白抗原（如破傷風、肺炎鏈球菌接合疫苗）的抗體反應 |
| <span style="color:#60a5fa">T細胞計數（CD3、CD4、CD8）</span> | 嚴重複合免疫缺陷（SCID）篩檢 |
| <span style="color:#60a5fa">人類免疫缺乏病毒（HIV）ELISA/西方點墨法/PCR</span> | 排除愛滋病 |

### C. 特定免疫缺陷疾病

| 疾病 | 特色 |
|---|---|
| <span style="color:#60a5fa">Bruton無γ球蛋白血症（X連鎖）</span> | 男性；感染始於6-12個月（母體抗體消失後）；IgG、IgA、IgM皆極低或無；B細胞缺如 |
| <span style="color:#60a5fa">常見變異性免疫缺陷（CVID）</span> | 低IgG＋低IgA和/或IgM；反覆細菌感染；自身免疫和淋巴增生風險↑ |
| <span style="color:#60a5fa">DiGeorge症候群（22q11.2缺失）</span> | 胸腺發育不全；T細胞缺乏；心臟缺陷、面部異形、低鈣血症、副甲狀腺功能低下 |

## V. 免疫球蛋白療法

### A. 靜脈免疫球蛋白（IVIG）

| 適應症 | 劑量/說明 |
|---|---|
| 抗體缺乏替補 | 起始：<span style="color:#fb923c">400-500 mg/kg</span>每3-4週；維持trough IgG > <span style="color:#34d399">500-600 mg/dL</span> |
| ITP | 起始：<span style="color:#fb923c">400-500 mg/kg/day</span> × 2-5天；維持：每3-6週 |
| <span style="color:#60a5fa">川崎病</span> | 單次<span style="color:#fb923c">2 g/kg</span>（10-12小時輸注） |
| MIS-C | IVIG + 皮質類固醇 |
| Guillain-Barré症候群 | <span style="color:#fb923c">400 mg/kg/day</span> × 5天 |
| 慢性炎症性脫髓鞘性神經病變（CIDP） | 維持劑量 |

**不良反應：**
| 類別 | 表現 | 處理 |
|---|---|---|
| 嚴重（罕見） | 過敏性反應、血流動力學變化、呼吸困難 | 停止輸注；腎上腺素搶救 |
| 輕度常見 | 頭痛、肌肉痛、發燒、發冷、噁心、嘔吐 | 減慢輸注速率；前置用藥（皮質類固醇、抗發炎藥） |
| <span style="color:#f87171">嚴重但罕見</span> | 無膽鹼性腦膜炎、急性腎衰竭（蔗糖-containing製劑）、急性靜脈血栓 | 避免或謹慎用於高風險患者 |

### B. 皮下免疫球蛋白（SCIG）

| 特點 | 說明 |
|---|---|
| 優點 | 不需靜脈通路；家屬可自行施打；全身副作用罕見 |
| 缺點 | 較大兒童可能需要多次注射（取決於體積） |
| 局部反應 | 發紅和腫脹可預期，且通常隨每次輸注而減少 |

### C. 特異性免疫球蛋白製劑

| 製劑 | 適應症 |
|---|---|
| <span style="color:#fb923c">B型肝炎免疫球蛋白（HBIG）</span> | B型肝炎暴露後預防 |
| <span style="color:#fb923c">Varicella-zoster免疫球蛋白（VZIG）</span> | 水痘暴露後預防 |
| <span style="color:#fb923c">Rho(D)免疫球蛋白（WinRho）</span> | Rh同種免疫；ITP |
| <span style="color:#fb923c">Cytomegalovirus免疫球蛋白（CMVIG）</span> | CMV感染預防 |

## VII. 重要數值速查

| 參數 | 正常值 |
|---|---|
| 總IgE | 1-3歲：<span style="color:#34d399">< 30 IU/mL</span>；成人：<span style="color:#34d399">< 150 IU/mL</span> |
| IgG（新生兒） | 臍帶血：<span style="color:#34d399">600-1,600 mg/dL</span> |
| IgG亚類缺陷定義 | 至少一種IgG亚類 < <span style="color:#34d399">2 SD</span> |
| CH50（總溶血補體） | <span style="color:#34d399">150-250 U/mL</span> |
| IgA缺乏定義 | <span style="color:#34d399">< 7 mg/dL</span> |
| 嗜伊紅性球（過敏評估） | 計數 > <span style="color:#34d399">500 cells/μL</span> |

> **⚠️ 臨床警告**
> - <span style="color:#f87171">過敏性鼻炎</span>若不及時治療可導致鼻竇炎和中耳炎；鼻內皮質類固醇是<span style="color:#f87171">最有效的單一療法</span>
> - <span style="color:#f87171">食物過敏</span>患者有20-25%在攝取花生時可能發生全身性過敏反應；Epinephrine是唯一一線治療
> - <span style="color:#f87171">免疫缺陷</span>患者不可接种活疫苗（如MMR、Varicella）；需與免疫團隊協調
> - IVIG中的<span style="color:#fb923c">蔗糖</span>成分對<span style="color:#f87171">腎功能不全患者有腎毒性風險</span>
> - <span style="color:#fb923c">Montelukast</span>有<span style="color:#f87171">嚴重神經精神事件風險</span>（包括自殺傾向），需告知家屬
