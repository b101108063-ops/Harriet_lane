## 導讀摘要

本章節涵蓋<span style="color:#60a5fa">貧血</span>（篩檢、定義、病因、評估和管理）、<span style="color:#60a5fa">紅血球增多症</span>、<span style="color:#60a5fa">嗜中性球減少症</span>、<span style="color:#60a5fa">白血球增多症</span>以及<span style="color:#60a5fa">血小板減少症和血小板功能障礙</span>。

貧血的定義為血紅素（Hb）低於年齡調整平均值兩個標準差。評估貧血需根據<span style="color:#60a5fa">網狀紅血球生成指數</span>（評估骨髓反應）和<span style="color:#60a5fa">平均紅血球體積（MCV）</span>（區分小球性、正小球性、大球性）。<span style="color:#60a5fa">鐵缺乏性貧血</span>是最常見的營養性貧血，口服<span style="color:#fb923c">硫酸亞鐵</span>為首選治療。<span style="color:#60a5fa">鐮刀型紅血球疾病（SCD）</span>的管理包括<span style="color:#fb923c">Hydroxyurea</span>（提升HbF至>20%）、<span style="color:#fb923c">Penicillin</span>預防（5歲以下）、<a>紅血球交換輸血</a>（用於中風、急性胸腔症候群）以及每年篩檢計畫。

血小板減少的定義為血小板計數 <span style="color:#34d399">150,000/mL</span>。臨床顯著出血風險在血小板 > 30,000/mL時較低，但<span style="color:#f87171">血小板 < 10,000/mL時嚴重出血（顱內出血、血尿、吐血）風險大增</span>。

## I. 貧血（Anemia）

### A. 貧血篩檢

| 建議 | 說明 |
|---|---|
| 首次篩檢時機 | <span style="color:#34d399">9-12個月</span>，6個月後複查 |
| 高風險族群（每年篩檢） | 早產或低出生體重、鉛暴露、4個月後未補充鐵的純母乳嬰兒、鐵強化穀物或富鐵食物攝取不足、餵養問題、生長不良、營養不足 |

### B. 貧血定義

**定義：** 血紅素（Hb）低於年齡調整平均值<span style="color:#34d399">2個標準差</span>

**年齡特異性血紅素參考值（部分）：**
| 年齡 | Hb正常範圍（g/dL） |
|---|---|
| 出生時（臍帶血） | 16.5 ± 3.0 |
| 1週 | 17.5 ± 3.0 |
| 1個月 | 14.0 ± 3.0 |
| 3-6個月 | 11.5 ± 2.0 |
| 6個月至2歲 | 12.0 ± 1.5 |
| 2-6歲 | 12.0 ± 1.5 |
| 6-12歲 | 13.0 ± 1.5 |
| 12-18歲（男） | 14.5 ± 2.0 |
| 12-18歲（女） | 13.5 ± 1.5 |

### C. 貧血評估——網狀紅血球生成指數和MCV

| MCV | 網狀紅血球生成指數高（>2.5） | 網狀紅血球生成指數低（<2.5） |
|---|---|---|
| <span style="color:#60a5fa">小球性（MCV低）</span> | 急性出血、溶血 | 鐵缺乏性貧血、地中海貧血（特徵：RDW正常）、慢性疾病性貧血 |
| <span style="color:#60a5fa">正小球性（MCV正常）</span> | 網狀紅血球↑的溶血或恢復期 | 慢性疾病性貧血、腎功能衰竭、內分泌功能低下 |
| <span name="macrocytic">大球性（MCV高）</span> | 維生素B12/葉酸缺乏 | 再生不良性貧血、骨髓衰竭 |

**Mentzer指數 = MCV / RBC計數**
- > 13：<span style="color:#60a5fa">鐵缺乏性貧血（IDA）</span>
- < 13：<span style="color:#60a5fa">地中海貧血特質</span>

## II. 非溶血性貧血

### A. 鐵缺乏性貧血（IDA）

| 項目 | 內容 |
|---|---|
| 病因 | 攝取不足、營養不良、<span style="color:#22d3ee">胃腸道出血</span>、月經週期、<span style="color:#c084fc">乳糜瀉、H. pylori、發炎性腸病</span>相關吸收不良 |
| 實驗室特徵 | 血清鐵蛋白↓（最早下降）、TIBC↑、運鐵蛋白受體↑、MCHC↓、RDW↑ |
| 治療 | <span style="color:#fb923c">口服硫酸亞鐵（首選）</span>——4週內Hb應增加1 g/dL；不能口服或吸收不良時考慮<span style="color:#fb923c">靜脈鐵劑</span> |

### B. 慢性疾病性貧血

| 病因 | 特色 |
|---|---|
| 慢性感染/發炎 | <span style="color:#c084fc">紅斑性狼瘡（SLE）</span>、<span style="color:#22d3ee">青少年特發性關節炎（JIA）</span>、IBD、血管炎 |
| 腎病 | 紅血球生成素生成受損 |
| 內分泌疾病 | 甲狀腺功能減退/亢進、腦下垂體機能減退 |

### C. 再生不良性貧血

| 類型 | 特點 |
|---|---|
| <span style="color:#60a5fa">純紅血球再生不良</span> | 骨髓紅血球系缺如；自體免疫疾病；常見於Parvovirus B19、<span style="color:#c084fc">EBV、CMV</span>感染 |
| <span style="color:#60a5fa">再生不良性貧血</span> | 全血球減少；骨髓低細胞性；嚴重型：ANC <500、 platelet <20,000、網狀紅血球 <60,000 |

### D. 遺傳性貧血

| 疾病 | 特色 |
|---|---|
| <span style="color:#60a5fa">Diamond-Blackfan貧血</span> | 紅血球系再生不良（30-47%有先天性異常：身材矮小、顎裂、拇指異常、心臟/腎臟異常） |
| <span style="color:#60a5fa">Fanconi貧血</span> | 全血球減少；橈骨和拇指異常；腎臟異常；CNS發育不良；生長遲緩；皮膚色素變化（咖啡牛奶斑） |

## III. 溶血性貧血

### A. 外因性溶血性貧血

| 類型 | 特點 |
|---|---|
| <span style="color:#60a5fa">微血管病性溶血性貧血（MAHA）</span> | 紅血球在微血栓中被剪切；見於：<span style="color:#22d3ee">HUS、TTP、DIC</span>；血片見<span style="color:#22d3ee">裂紅血球（schistocytes）</span> |
| <span style="color:#60a5fa">自體免疫溶血性貧血（AIHA）</span> | 溫式（IgG）→皮質類固醇為一線；冷式（IgM）→避免寒冷 |
| <span style="color:#60a5fa">藥物相關AIHA</span> | <span style="color:#fb923c">penicillins、cephalosporins</span>、quinine/quinidine等 |

### B. 內因性溶血性貧血

#### 1. 紅血球膜缺陷

| 疾病 | 特點 |
|---|---|
| <span style="color:#60a5fa">遺傳性球形紅血球症</span> | 紅血球膜蛋白缺陷導致<span style="color:#22d3ee">球形紅血球（spherocytes）</span>；主要為AD； osmotic fragility或EMA flow cytometry確診 |
| <span style="color:#60a5fa">遺傳性橢圓形紅血球症</span> | 通常AD；血片見橢圓形紅血球 |

#### 2. 紅血球酶缺陷

| 疾病 | 特點 |
|---|---|
| <span style="color:#60a5fa">G6PD缺乏症</span> | X染色體隱性；氧化壓力（感染、<span style="color:#c084fc">蠶豆</span>、藥物）觸發溶血；血片見<span style="color:#22d3ee">咬細胞（bite cells）和Heinz bodies</span> |
| <span style="color:#60a5fa">丙酮酸激酶（PK）缺乏症</span> | AR；慢性溶血；紅血球PK活性測定確診 |

## IV. 鐮刀型紅血球疾病（SCD）

### A. 分類與特徵

| 基因型 | 臨床嚴重程度 |
|---|---|
| <span style="color:#60a5fa">HbSS（鐮刀型紅血球貧血）</span> | 最嚴重 |
| <span style="color:#60a5fa">HbSβ⁰-地中海貧血</span> | 嚴重 |
| HbSC / HbSβ⁺ | 通常較輕 |

### B. SCD常見併發症

| 併發症 | 表現 | 處置 |
|---|---|---|
| <span style="color:#f87171">發燒</span> | >38.3°C（101°F） | 血培養、CXR；住院：<span style="color:#fb923c">Ceftriaxone</span>（+<span style="color:#fb923c">Vancomycin</span>如有腦膜炎跡象） |
| <span style="color:#f87171">血管阻塞危機（VOC）</span> | 2歲以下：手腳炎（dactylitis）；2歲以上：局部/多處疼痛 | 門診：NSAIDs、類阿片；住院：IV<span style="color:#fb923c">morphine/hydromorphone</span>；PCA；<span style="color:#fb923c">Ketamine</span>（對類阿片反應不佳時） |
| <span style="color:#f87171">急性胸腔症候群（ACS）</span> | 發燒、咳嗽、胸痛、呼吸窘迫、缺氧＋新肺部浸潤 | 住院；IV<span style="color:#fb923c">cephalosporin</span>＋<span style="color:#fb923c">口服巨環內酯</span>；氧氣；激勵肺活量計 |
| <span style="color:#f87171">脾臟滯留危機</span> | 急性脾腫大、Hb較基準下降≥2 g/dL | 住院；IV液體；簡單輸血（謹慎容量） |
| <span style="color:#f87171">再生不良危機</span> | 通常由<span style="color:#c084fc">Parvovirus B19</span>引起；Hb↓、網狀紅血球↓ | 紅血球輸注（如需要） |
| <span style="color:#f87171">中風</span> | 局灶性神經學徵象 | 紅血球交換輸血（優於簡單輸血）；TCD >200 cm/sec 或有中風史者需慢性輸血 |

### C. SCD健康維護

| 項目 | 建議 |
|---|---|
| <span style="color:#fb923c">Penicillin</span> | 5歲以下HbSS/HbSβ⁰每天兩次 |
| <span style="color:#fb923c">Hydroxyurea</span> | HbSS或HbSβ⁰ > 9個月可考慮；目標：HbF > <span style="color:#34d399">20%</span> |
| 肺炎鏈球菌疫苗 | 13價接合疫苗（常規時程）＋23價多醣疫苗（2歲） |
| 腦膜炎球菌疫苗 | MenACWY（2、4、6、12個月）；2歲以上2劑系列 |
| 經顱都卜勒超聲（TCD） | 2-16歲每年篩檢（HbSS/HbSβ⁰） |
| 眼科 | 10歲起每年評估視網膜病變 |

## V. 地中海貧血（Thalassemia）

### A. α-地中海貧血分類

| 基因型 | 名稱 | 臨床表現 |
|---|---|---|
| α-/αα | 靜默帶因者 | 無貧血；Hb電泳通常正常 |
| α-/α- 或 αα/-- | α-地中海貧血特質 | 輕度小球性（±輕度貧血） |
| α-/-- | HbH病（β4） | 輕至中度貧血；新生兒篩檢見較高Hb Barts，隨後為HbH |
| --/-- | Hb Barts/胎兒水腫 | Hb Barts（γ4）無法攜氧；<span style="color:#f87171">通常胎內或新生兒期死亡</span> |

### B. β-地中海貧血分類

| 類型 | Hb電泳 | 表現 |
|---|---|---|
| <span style="color:#60a5fa">β⁰/β⁰（β0/β0）</span> | 無 HbA，HbF↑，HbA2↑ | 重型（Cooley貧血）：出生6個月內發病，需規則輸血 |
| β⁺/β⁺ 或 β⁰/β⁺ | HbA↓，HbF↑，HbA2↑ | 中間型：Hb 7-10 g/dL |
| β/β⁺ 或 β/β⁰ | 輕度↓ HbA，↑ HbA2 | 特質/輕型：輕度無症狀貧血 |

### C. 地中海貧血治療

| 項目 | 建議 |
|---|---|
| 輸血 | 維持 Hb > <span style="color:#34d399">9-10.5 g/dL</span>；避免過度輸血至 Hb > 14-15 g/dL（高黏滯度風險） |
| 鐵離子過載 | 規則輸血10-20次或Ferritin > <span style="color:#34d399">1000 mg/L</span>時開始整合治療（<span style="color:#fb923c">deferasirox</span>或<span style="color:#fb923c">deferoxamine</span>） |
| 根治 | 骨髓移植（目前唯一根治方法） |

## VI. 嗜中性球減少症（Neutropenia）

**定義：** ANC（絕對嗜中性球計數）<span style="color:#34d399">1500/mL</span>；嚴重嗜中性球減少：ANC <span style="color:#34d399">500/mL</span>

| 病因類別 | 常見原因 |
|---|---|
| 感染 | <span style="color:#c084fc">EBV、CMV、Parvovirus B19、HHV-6、HIV</span>、病毒性肝炎、傷寒、布氏桿菌病 |
| 藥物 | <span style="color:#fb923c">Sulfasalazine、clozapine、TMP/SMX</span>、thionamides |
| 自體免疫 | 原發性自體免疫嗜中性球減少（常見於5-15個月）、<span style="color:#22d3ee">SLE</span> |
| 先天性 | 嚴重先天性嗜中性球減少（ELANE突變）、<span style="color:#22d3ee">Kostmann症候群</span>（HAX1）、週期性嗜中性球減少 |

**G-CSF（Filgrastim）適應症：**
- 持續使用：嚴重先天性嗜中性球減少、週期性嗜中性球減少、<span style="color:#22d3ee">Shwachman-Diamond症候群</span>
- 間歇使用：危及生命的感染或感染病史

## VII. 血小板減少症（Thrombocytopenia）

**定義：** 血小板計數 <span style="color:#34d399">150,000/mL</span>

**出血風險：**
| 血小板計數 | 風險 |
|---|---|
| > 30,000/mL | 臨床上顯著出血不太可能（無其他複雜因素） |
| < 10,000/mL | <span style="color:#f87171">嚴重出血（顱內出血、的血尿、吐血、黑便）風險大增</span> |

### A. 免疫性血小板減少性紫癜（ITP）

| 項目 | 內容 |
|---|---|
| 病理 | 免疫介導的循環血小板破壞 |
| 表現 | 健康兒童，輕度創傷或近期輕度疾病後突然瘀傷或出血；單獨血小板減少（< 100,000/mL） |
| 血片特徵 | 血小板減少伴大血小板（網狀血小板↑） |
| 治療 | 輕度：觀察；中重度：<span style="color:#fb923c">皮質類固醇</span>、<span style="color:#fb923c">IVIG</span>、<span style="color:#fb923c">抗-D免疫球蛋白（WinRho）</span>（Rh+且有脾臟的ITP患者）；慢性：<span style="color:#fb923c">Rituximab</span>、<span style="color:#fb923c"> thrombopoietin receptor agonists</span> |

### B. 先天性血小板疾病

| 疾病 | 特色 |
|---|---|
| <span style="color:#60a5fa">Wiskott-Aldrich症候群</span> | X染色體隱性；血小板減少＋濕疹＋免疫缺陷 |
| <span style="color:#60a5fa">Bernard-Soulier症候群</span> | GPIb-IX-V缺陷；大血小板；出血時間延長 |
| <span style="color:#60a5fa">Glanzmann thrombasthenia</span> | GPIIb/IIIa缺陷；正常血小板數目但功能缺陷 |

> **⚠️ 臨床警告**
> - SCD患者發燒需<span style="color:#f87171">立即評估</span>——感染是主要死因
> - SCD的<span style="color:#f87171">急性胸腔症候群</span>可迅速進展，需積極處理
> - ITP的<span style="color:#f87171">自發性顱內出血風險極低</span>（<0.5%），過度治療需避免
> - 血小板減少伴大血小板提示<span style="color:#60a5fa">破壞性進程（如ITP）</span>；小血小板提示<span style="color:#60a5fa">生成缺陷</span>
> - <span style="color:#f87171">G6PD缺乏症</span>患者需終身避免氧化觸發物（蠶豆、某些藥物）
> - <span style="color:#60a5fa">輕度貧血（如Hb 9-10 g/dL）</span>在6個月至2歲兒童可能為生理性，若無症狀可觀察
