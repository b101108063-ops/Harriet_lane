## 導讀摘要

本章節涵蓋遺傳學與代謝疾病的核心內容，包括：遺傳疾病分類（染色體、單基因、mitochondrial）、常見遺傳症候群（Down、Klinefelter、Turner、Williams、Noonan、Marfan、Neurofibromatosis、Fragile X）、遺傳諮詢與家族史評估、先天代謝異常（PKU、MCAD、Galactosemia、Methylmalonic/Propionic acidemia）、新生兒篩檢、遺傳檢測方法（染色體核型、陣列 CGH、FISH、單基因檢測、全外顯子定序）、先天異常的評估與處理。臨床重點包括：常見基因疾病特徵、先天代謝異常的急性表現、何時懷疑代謝疾病。

## I. 遺傳疾病分類

### A. 染色體異常

| 疾病 | 染色體 | 臨床上特徵 |
|------|--------|------------|
| **Down 症候群（Trisomy 21）** | 47,XX,+21 或 47,XY,+21 | 智能障礙、上斜瞼裂、 Brushfield spots、atrial/ventricular septal defect、 atlantoaxial instability、duodenal atresia |
| **Klinefelter 症候群** | 47,XXY | 男、睪丸小、無精子、高促性腺激素性功能減退、gynecomastia |
| ** Turner 症候群** | 45,X（或其他 X 染色體異常）| 女、身材矮小、卵巢發育不良、盾狀胸、頸蹼、心臟主動脈狹窄、淋巴水腫 |
| **47,XYY** | 47,XYY | 男、身高高、智能正常或輕度障礙、行為問題 |
| **5p- 缺失（Cri-du-chat）** | 5p15.2 缺失 | 貓哭聲（小哭聲）、小頭畸形、智能障礙 |

### B. 單基因疾病

| 疾病 | 遺傳方式 | 臨床特徵 |
|------|---------|---------|
| **Marfan 症候群** | AD | 主動脈根部擴張、晶狀體脫位、蜘蛛腳樣指（arachnodactyly） |
| **Neurofibromatosis 1** | AD | Caf-au-lait spots、neurofibromas、optic pathway gliomas |
| **Fragile X 症候群** | X 連鎖 | 智力障礙、大耳/睪丸、行為問題（ASD 樣） |
| **Rett 症候群** | X 連鎖顯性 | 女、退化性、失去手部功能、智能障礙 |
| **Osteogenesis imperfecta** | AD/AR | 骨質脆弱反覆骨折、藍色鞏膜、聽力損失 |

## II. 常見遺傳症候群

### A. Down 症候群（Trisomy 21）

| 系統 | 常見特徵 |
|------|---------|
| **心臟** | AV canal defect（最常見）、VSD、ASD、PDA |
| **胃腸道** | Duodenal atresia（聖誕樹徵）、Hirschsprung病、Celiac disease |
| **骨骼** | Atlantoaxial instability（頸椎 1-2 不穩定） |
| **眼科** | 斜視、白內障、refractive errors |
| **甲狀腺** | 甲狀腺機能減退（~15-20%）|
| **血液** | 急性淋巴性白血病（ALL）風險增加 10-20 倍 |
| **智力** | 輕至中度智能障礙 |

> 📌 <span style="color:#60a5fa">**Atlantoaxial instability**：有頸椎不穩定癥狀（頸部疼痛、步態改變）的患者需限制接觸性運動

### B. Turner 症候群（45,X）

| 系統 | 表現 |
|------|------|
| **生長** | 身材矮小（未治療最終身高~143 cm）|
| **心臟** | 主動脈狹窄（~30%）、Bicuspid aortic valve |
| **腎臟** | 馬蹄腎、收集系統異常 |
| **生殖** | 卵巢功能減退（原發性無月經）、需要激素替代 |
| **學習** | 視覺-空間建構困難（其餘智力正常）|

**治療**：
- 身材矮小：<span style="color:#fb923c">**GH 治療**</span>（5-9 μg/kg/day）
- 激素替代：<span style="color:#fb923c">**Estrogen**</span>（11-12 歲開始）

### C. Williams 症候群（7q11.23 缺失）

| 特徵 | 說明 |
|------|------|
| **心血管** | SVAS（Supravalvular aortic stenosis）、肺动脉狹窄 |
| **外貌** | 小精靈樣面部特徵（elfin facies）、寬嘴、厚唇 |
| **發育** | 輕度智能障礙、極強社交能力、語言早發 |
| **其他** | 嬰兒期高血鈣、腹部絞痛 |

### D. Noonan 症候群

| 特徵 | 說明 |
|------|------|
| **外表** | 低位耳、頸蹼、眼瞼下垂、胸部畸形（漏斗胸/雞胸）|
| **心臟** | 肺动脉瓣狹窄（~50%）、HCM、ASD |
| **生長** | 身材矮小 |
| **血液** | 凝血因子缺乏、血小板減少 |

### E. Marfan 症候群（FBN1 基因）

| 系統 | 表現 |
|------|------|
| **心血管** | <span style="color:#f87171">**主動脈根部擴張/夾層分離**</span>（主要死因）、二尖瓣脫垂 |
| **眼睛** | 晶狀體脫位（上內方，ectopia lentis）|
| **骨骼** | 蜘蛛腳樣指、胸部畸形、脊柱側彎、關節過動 |
| **其他** | 氣胸、二尖瓣脫垂、主動脈剝離 |

> ⚠️ <span style="color:#f87171">**診斷標準**：GHENT 標準（心臟-眼睛-骨骼-家族史-基因檢測）

### F. Neurofibromatosis Type 1（NF1，17q11.2）

| 診斷標準（≥ 2 項） | 說明 |
|--------------------|------|
| ≥6 café-au-lait spots | >5 mm（青春期前），>15 mm（青春期後）|
| ≥2 neurofibromas 或 1 plexiform neurofibroma | |
| 腋下或腹股溝斑點 | |
| Optic pathway glioma | |
| ≥2 Lisch nodules（虹膜哈佛小體）| |
| 骨骼病變 | 蝶骨發育不良、長骨皮質變薄 |
| 一等親有 NF1 | |

## III. 先天代謝異常

### A. 何時懷疑代謝疾病

| 警示徵兆 | 說明 |
|---------|------|
| 無法解釋的嚴重新生兒期疾病 | 敗血症樣但無感染證據 |
| 酸中毒 | 陰離子間隙增加 |
| 低血糖 | 特別是與酮尿相關 |
| 特殊氣味 | 楓糖漿味（MSUD）、汗腳味（isovaleric acidemia）|
| 發育/生長退步 | 認知退化 |
| 無法解釋的家族史 | 早期死亡、手足有類似疾病 |

### B. 新生兒篩檢（SCID 以外的常見項目）

| 疾病 | 檢測 | 臨床意義 |
|------|------|---------|
| **PKU** | Phenylalanine ↑ | 智能障礙（未治療）；需低 Phe 飲食 |
| **MCAD 缺乏症** | C8-C10 acylcarnitine ↑ | 空腹時低血糖/昏迷 |
| **Galactosemia** | Galactose-1-phosphate uridyltransferase ↓ | 餵奶後嘔吐、腹瀉、黃疸、白內障 |
| **Sickle cell disease** | HbS | 疼痛危機、膿毒症 |
| **Biotinidase 缺乏** | Biotinidase ↓ | 癲癇、肌張力低、聽力/視力損失 |
| **Congenital adrenal hyperplasia** | 17-OHP ↑ | 鹽類流失、低血壓危機 |

### C. 苯酮尿症（PKU）

| 項目 | 內容 |
|------|------|
| **原因** | Phenylalanine hydroxylase 缺乏 → Phe 堆積 |
| **症狀（未治療）** | 智能障礙、癲癇、發育遲緩、，毛髮/皮膚色素減少 |
| **治療** | <span style="color:#60a5fa">**終生低 Phe 飲食**</span>；特殊配方奶粉；Phe-free amino acid supplements |
| **監測** | 血中 Phe 水平維持 2-6 mg/dL |
| **孕婦 PKU** | 高 Phe 可致畸（心臟缺損、生長遲緩）|

### D. MCAD 缺乏症（Medium-Chain Acyl-CoA Dehydrogenase）

| 項目 | 內容 |
|------|------|
| **機制** | 脂肪 β-氧化缺陷 → 空腹時無法產生酮體 |
| **觸發** | 長時間禁食、腸胃炎期間 |
| **表現** | 低血糖、無酮性酮尿、意識改變、嘔吐、昏迷 |
| **治療/預防** | 避免長時間禁食；空腹時補充碳水化合物；左旋肉鹼 |

### E. 先天性甲狀腺機能減退（CH）

| 項目 | 內容 |
|------|------|
| **發生率** | 1:2000-4000 |
| **新生兒篩檢** | TSH（出生 24-48 小時）|
| **原因** | 甲狀腺發育不全（85%）、甲狀腺激素合成障礙、甲狀腺抗體（母親）|
| **治療** | <span style="color:#fb923c">**Levothyroxine**</span>（見內分泌章）|

## IV. 遺傳檢測方法

| 檢測 | 適用情況 | 解析度 |
|------|---------|--------|
| **染色體核型** | 染色體數目異常、易位、倒位 | 5-10 Mb |
| **FISH（螢光原位雜交）** | 微缺失/重複症候群（ cri-du-chat、Williams、SMN） | 100kb-1Mb |
| **陣列 CGH（aCGH）** | 不明原因的發育遲緩/先天異常；版圖不平衡 | 50-200kb |
| **單基因檢測** | 已知家族基因突變 |
| **基因組合檢測（Gene panel）** | 多個候選基因 |
| **全外顯子定序（WES）** | 高度異質性疾病；罕見疾病 |
| **全基因組定序（WGS）** | 極罕見疾病（研究用）|
| **甲基化分析** | Prader-Willi/Angelman、Fragile X |

## V. 先天異常的評估

### A. Dysmorphic Features（獨特外觀特徵）

| 評估重點 | 說明 |
|---------|------|
| **生長參數** | 身高、體重、頭圍、身高百多分位 |
| **頭面部** | 眼、耳、口、鼻、下頜大小與對稱性 |
| **身體檢查** | 頸部、胸廓、脊柱、四肢、手足比例 |
| **皮膚** | 色素沈著（café-au-lait）、血管瘤、脂肪瘤 |
| **測量** | 眼距（ interpupillary distance）、耳長、手長 |

### B. 先天結構異常

| 系統 | 常見相關症候群 |
|------|--------------|
| **心臟** | 22q11.2 缺失（Trisomy 21、William、Noonan） |
| **腎臟** |Branchio-oto-renal 症候群、VACTERL關聯 |
| **骨骼** | VACTERL、Klippel-Feil |
| **中樞神經系統** | Holoprosencephaly（前腦分裂障礙） |

### C. 家族史的三大核心問題

1. **家族中是否有嚴重殘疾或早期死亡的成員？**
2. **家族中是否有發展遲緩、學習困難、或自閉症類群障礙的成員？**
3. **家族中是否有心臟、癲癇、聽力損失、或視力損失的成員？**

## VI. 遺傳諮詢

| 情境 | 說明 |
|------|------|
| **自體顯性（AD）** | 父母一方受影響：每胎 50% 風險；父母正常：可能新突變（~85%） |
| **自體隱性（AR）** | 父母均為帶因者：每胎 25% 風險 |
| **X 連鎖顯性（XLD）** | 男性受影響者的女兒都會受影響；男性很少存活 |
| **X 連鎖隱性（XLR）** | 男性：50% 女兒為帶因者；男性受影響者的兄弟有 50% 風險 |
| **染色體** | 除非有家族性平衡易位，否則通常為新發生 |
