## I. 固態腫瘤

### A. 腦瘤（Brain Tumors）

> **Clinical Pearl：** 腦瘤是兒童**最常見的實體瘤**，也是兒童癌症死亡的**首要原因**。

#### 1. 常見類型

| 腫瘤類型 | 年齡好發 | 位置 | 組織學 |
|---------|---------|------|--------|
| **Medulloblastoma** | 3-8 歲 | 後顱窩（小腦）| 胚胎性 |
| **Pilocytic astrocytoma** | 5-15 歲 | 小腦、視覺通路 | 低惡性 |
| **Diffuse intrinsic pontine glioma (DIPG)** | 5-9 歲 | 橋腦（腦幹）| 瀰漫性中線膠質瘤 |
| **Craniopharyngioma** | 5-14 歲 | 蝶鞍/鞍上 | 良性但具侵襲性 |
| **Ependymoma** | <5 歲 | 後顱窩、脊髓 | 室管膜 |
| **High-grade glioma** | 任何年齡 | 大腦半球、腦幹 | 惡性膠質瘤 |

#### 2. 臨床表徵

| 症狀 | 原因 |
|------|------|
| **顱內壓升高** | 頭痛（晨間加劇）、嘔吐、視乳頭水腫 |
| **共濟失調** | 小腦腫瘤 |
| **腦神經缺損** | 腦幹/顱底腫瘤 |
| **視野缺損** | 視交叉/下視丘腫瘤 |
| **生長障礙** | 蝶鞍腫瘤影響生長激素 |
| **性早熟/性發育延遲** | 下視丘-垂體軸受影響 |

#### 3. 治療原則

| 腫瘤類型 | 主要治療 |
|---------|---------|
| **Low-grade glioma (LGG)** | 手術切除 ± 化療（視情況）；BRAF 突變可使用 MEK 抑制劑 |
| **Medulloblastoma** | 手術 + 化療 + 放射治療（全腦/全脊椎）|
| **DIPG** | 單純放射治療（預後惡劣，中位生存期 9-11 個月）|
| **Ependymoma** | 手術切除為主，放化療輔助 |
| **Craniopharyngioma** | 手術切除（經顱或經蝶竇）；復發可考慮射頻或博來黴素囊內注射 |

### B. 神經母細胞瘤 (Neuroblastoma)

| 特徵 | 內容 |
|------|------|
| 起源 | 交感神經系統的胚胎性腫瘤（腎上腺髓質、交感神經節）|
| 發病年齡 | <5 歲（75% <2 歲）|
| 占比 | 所有兒童癌症的 ~7% |
| 表現 | 腹部腫塊（最常見）、眼眶瘀青（眼眶蜂窩組織炎樣）、高血壓、轉移 |

#### 分期（INSS）

| 分期 | 定義 |
|------|------|
| 1 期 | 腫瘤局限，完全切除 |
| 2A/2B 期 | 局部腫瘤，未完全切除/同側淋巴結侵犯 |
| 3 期 | 無法切除的單側腫瘤伴對側淋巴結侵犯 |
| 4 期 | 遠處轉移（骨、骨髓、肝、遠端淋巴結）|
| 4S 期 | <1 歲，侷限性原發腫瘤，但有肝/皮膚/骨髓轉移（特異型）|

#### 預後因子

| 良好預後因子 | 不良預後因子 |
|-------------|-------------|
| Age <18 個月 | Age >18 個月 |
| 低風險分期（1, 2, 4S）| 高風險分期（3, 4）|
| MYCN 未放大 | **MYCN 放大**（~20% 患者）|
| 良好的分化程度 | 未分化/低分化 |
| 超二倍體 | 異倍體 |

#### 治療

| 分期 | 治療 |
|------|------|
| 1 期 | 手術切除，五年生存率 >90% |
| 2A/2B 期 | 手術 ± 化療 |
| 3-4 期 | 多模式治療：誘導化療 → 手術 → 鞏固化療 ± 放射治療 |
| 4S 期 | 自限性，部分可自行消退；需要時化療 |
| 高風險 | 誘導化療 → 手術 → 鞏固化療 + 自體造血細胞移植 ± 免疫治療（Dinutuximab）|

### C. 威姆氏瘤 (Nephroblastoma, Wilms Tumor)

| 特徵 | 內容 |
|------|------|
| 起源 | 腎臟胚基細胞 |
| 發病年齡 | 2-5 歲 |
| 占比 | 所有兒童癌症的 ~5% |
| 表現 | 無痛性腹部腫塊（常被父母觸摸發現）、血尿、高血壓 |

#### 分期（NWTS）

| 分期 | 定義 |
|------|------|
| 1 期 | 腫瘤局限於腎臟，可完全切除 |
| 2 期 | 腫瘤超出腎臟但可切除 |
| 3 期 | 殘留的非血源性腹腔內轉移 |
| 4 期 | 遠處轉移（肺、肝、骨、腦）|
| 5 期 | 雙側腎臟腫瘤 |

#### 組織學分類

| 分型 | 預後 |
|------|------|
| **有利組織學 (Favorable)** | 良好（~90% 五年生存率）|
| **不利組織學 (Anaplastic)** | 較差（需更強化治療）|

#### 治療

| 分期 | 治療 |
|------|------|
| 1-2 期 | 手術 + 化療（vincristine + actinomycin D）|
| 3-4 期 | 手術 + 化療（VAD + doxorubicin）± 放射治療 |
| 雙側（5期）| 腎保留手術 + 化療 |

---

### D. 肝臟腫瘤

#### 1. 肝母細胞瘤 (Hepatoblastoma)

| 特徵 | 內容 |
|------|------|
| 發病年齡 | <3 歲（75% <2 歲）|
| 標誌物 | **AFP 升高**（90% 患者）|
| 治療 | 手術切除為主（若可切除）；不可切除者先化療（cisplatin + doxorubicin）|

#### 2. 肝細胞癌 (Hepatocellular Carcinoma)

| 特徵 | 內容 |
|------|------|
| 發病年齡 | 較大兒童/青少年 |
| 相關 | 慢性 HBV 感染、纖維層狀肝細胞癌、先天性肝病 |
| 標誌物 | AFP 可升高 |
| 治療 | 手術切除（主要治療）；化療反應不佳 |

### E. 淋巴瘤

#### 1. Hodgkin Lymphoma

| 特徵 | 內容 |
|------|------|
| 發病年齡 | 青少年（10-19 歲）|
| 病理 | Reed-Sternberg 細胞（CD15+, CD30+）|
| 表現 | 頸部無痛性淋巴結腫大；B 症狀：發燒、盜汗、體重減輕 |
| 分期 | Ann Arbor（Cotswolds 修改版）|

**治療：**
| 分期 | 治療 |
|------|------|
| Early (I-IIA) | ABVD × 2-4 cycles + 受侵犯區域放射治療 (ISRT) |
| Advanced (IIB-IV) | ABVD × 6 cycles ± 放射治療 |

#### 2. Non-Hodgkin Lymphoma

| 亞型 | 發病年齡 | 侵犯位置 | 治療 |
|------|---------|---------|------|
| **Burkitt lymphoma** | 兒童/青少年 | 腹部（回盲部）、顱底、睪丸 | 短期高強度化療（CODOX-M/IVAC）|
| **Lymphoblastic** | 兒童 | 前縱隔、淋巴結、骨髓 | ALL 型化療（BFM 方案）|
| **Anaplastic large cell** | 青少年 | 淋巴結、皮膚、骨 | 化療（ALCL99 方案）|

### F. 肉瘤 (Sarcomas)

#### 1. 橫紋肌肉瘤 (Rhabdomyosarcoma)

| 特徵 | 內容 |
|------|------|
| 起源 | 間葉細胞/骨骼肌前驅細胞 |
| 發病年齡 | 2-5 歲及 15-19 歲雙峰 |
| 好發位置 | 頭頸部（35%）、泌尿生殖道（25%）、四肢（20%）|

**組織學分類：**
| 類型 | 預後 |
|------|------|
| **Embryonal**（最常見）| 較好 |
| **Alveolar** | 較差（常伴有 PAX3-FOXO1 或 PAX7-FOXO1 融合基因）|

**治療：** 手術 + 化療（Vincristine、Actinomycin D、Cyclophosphamide [VAC]）± 放射治療

#### 2. 骨肉瘤 (Osteosarcoma)

| 特徵 | 內容 |
|------|------|
| 發病年齡 | 青少年（10-20 歲）|
| 好發位置 | 股骨遠端、脛骨近端（膝關節周圍）|
| 表現 | 局部疼痛、腫脹、病理性骨折 |
| 治療 | 手術切除（新輔助化療後）+ 化療（Cisplatin + Doxorubicin + 高劑量 Methotrexate）|

#### 3. 尤因氏肉瘤 (Ewing Sarcoma)

| 特徵 | 內容 |
|------|------|
| 發病年齡 | 10-20 歲 |
| 好發位置 | 骨盆、長骨、肋骨 |
| 特色 | 對放射治療敏感 |
| 治療 | 多模式：Vincristine、Actinomycin D、Cyclophosphamide (VAC) + Ifosfamide/Etoposide |

---

### G. 視網膜母細胞瘤 (Retinoblastoma)

| 特徵 | 內容 |
|------|------|
| 起源 | 視網膜神經上皮細胞 |
| 發病年齡 | <3 歲（常見於嬰兒）|
| 表現 | 白瞳症（leukocoria）、斜視、葡萄膜炎 |
| 基因 | **RB1 基因突變**（可為遺傳性或散發性）|

**分類（ICRB）：**
| 分期 | 內容 |
|------|------|
| Group A | 腫瘤 ≤3mm |
| Group B | 腫瘤 >3mm 或黃斑部/後極部 |
| Group C | 視網膜下播散 |
| Group D | 玻璃體種植 |
| Group E | 無法挽救的眼睛（侵犯脈絡膜、眼前房、玻璃體出血、青光眼）|

**治療：**
| 分期 | 治療 |
|------|------|
| 早期（Group A-C）| 局部治療（雷射、冷凍、塗敷性化療）|
| 晚期（Group D-E）| 全身性化療 ± 局部治療；眼球摘出（必要時）|
| 雙側性疾病 | 雙側化療 + 眼保留策略 |

---

### H. 朗格漢斯細胞組織球增生症 (Langerhans Cell Histiocytosis, LCH)

| 特徵 | 內容 |
|------|------|
| 病理 | 朗格漢斯細胞（樹突細胞）克隆性增殖 |
| 表現 | 從單一骨病變到彌漫性器官侵犯 |
| 評估 | BRAF V600E 突變（~50% 患者）— 可靶向治療 |

**治療分層：**

| 類型 | 治療 |
|------|------|
| **單系統 LCH** | 單一骨病變：刮除/類固醇局部注射；多發骨病變：全身化療（vinblastine ± prednisone）|
| **多系統 LCH（有危險器官侵犯）**| 全身化療（vinblastine + prednisone）；難治性可考慮 BRAF/MEK 抑制劑 |

## II. 化療藥物

### A. 化療藥物分類

| 類別 | 藥物 | 機制 | 主要毒性 |
|------|------|------|---------|
| ** Alkylating agents** | Cyclophosphamide, Ifosfamide | DNA 交叉連結 | 骨髓抑制、出血性膀胱炎、不孕 |
| **Platinum analogs** | Cisplatin, Carboplatin | DNA 結合 | 腎毒性、耳毒性、神經毒性 |
| **Anthracyclines** | Doxorubicin, Daunorubicin | DNA 嵌入、自由基 | 心臟毒性（劑量相關）、骨髓抑制 |
| **Antimetabolites** | Methotrexate, 6-MP, Cytarabine | 核苷酸類似物 | 骨髓抑制、黏膜炎、肝毒性 |
| **Vinca alkaloids** | Vincristine, Vinblastine | 抑制微小管 | 神經毒性（劑量限制）、便秘 |
| **Epipodophyllotoxins** | Etoposide | Topoisomerase II 抑制 | 骨髓抑制、繼發性白血病 |
| **Camptothecins** | Irinotecan, Topotecan | Topoisomerase I 抑制 | 腹瀉、骨髓抑制 |
| **Taxanes** | Paclitaxel | 穩定微小管 | 過敏反應、神經病變 |

### B. 化療常見毒性管理

| 毒性 | 預防/處理 |
|------|---------|
| **骨髓抑制** | 化療後 7-14 天最低點；生長因子支持（G-CSF）；感染預防 |
| **噁心/嘔吐** | 5-HT3 抑制劑、NK1 受體抑制劑、dexamethasone |
| **黏膜炎** | 口腔護理、冰敷（cryotherapy）、疼痛控制、營養支持 |
| **腹瀉** | Irinotecan 相關：atropine、Loperamide |
| **心臟毒性** | Doxorubicin：終生累積劑量限制（<550 mg/m²）；MUGA scan 監測 |
| **腎毒性/耳毒性** | Cisplatin：水化、鹼化；鉀/鎂補充；聽力監測 |
| **神經毒性** | Vincristine：劑量調整；神經病變對症處理 |
| **出血性膀胱炎** | Cyclophosphamide/Ifosfamide：MESNA（泌尿防護）；水化 |
| **肝靜脈阻塞性疾病 (VOD)** | Busulfan/化療後：defibrotide |
| **化療外滲** | 立即停止、局部注射透明質酸酶、冷/熱敷（根據藥物）|
| **腫瘤溶解綜合徵 (TLS)** | 水化、Allopurinol/Rasburicase、監測電解質 |

> ⚠️ **Clinical Warning：化療藥物外滲緊急處理**
> - **Vincristine/ Vinblastine（鹼性）：** 冷敷
> - **Doxorubicin（鹼性）：** 冷敷
> - **Cisplatin（鹼性）：** 冷敷
> - **Mechlorethamine（鹼性）：** 冷敷

## III. 支持性照護

### A. 感染預防與管理

| 情境 | 建議 |
|------|------|
| **發燒 + 中性球減少（FN）**| 緊急評估 + 經驗性廣效抗生素（涵蓋 Gram-negative + Pseudomonas）|
| **PJP 預防** | TMP-SMX  prophylaxis（化療期間、劑量和支持性照護劑量）|
| **真菌預防** | Fluconazole（針對念珠菌）或 Voriconazole（針對麯菌）|
| **病毒預防** | Acyclovir/Valacyclovir（HSV、VZV）|

### B. 疼痛管理

- 藥物：嗎啡氫氧化物、Hydromorphone、Fentanyl（按劑量滴定）
- 輔助：加巴噴丁類（Gabapentin、Pregabalin）用於神經病變
- 非藥物：冰敷、分散注意力、放鬆訓練

### C. 營養支持

- 化療期間高熱量、高蛋白飲食
- 口腔黏膜炎期間：軟食、流質
- 嚴重厭食：鼻胃管餵養或全靜脈營養（TPN）

## IV. 癌症存活者長期追蹤 (Long-Term Follow-Up)

### A. 常見後期效應 (Late Effects)

| 系統 | 後續效應 | 篩檢建議 |
|------|---------|---------|
| **心臟** | 心肌病變（anthracyclines）、冠狀動脈疾病（放射治療）| 超聲心動圖（MUGA）、心電圖；每 1-5 年 |
| **內分泌** | 甲狀腺功能減退、生長障礙、不孕、性早熟/發育延遲 | 甲狀腺功能、IGF-1/GH、骨齡 |
| **骨骼** | 骨壞死、骨質疏鬆、脊柱側彎 | DXA、骨骼檢查 |
| **神經** | 認知障礙（化療/放射）、神經病變 | 神經心理測試 |
| **腎臟** | 腎功能減退（Cisplatin）| 腎功能、cystatin C |
| **視覺/聽力** | 白內障（皮質類固醇）、聽力損失（Cisplatin）| 聽力圖、眼科檢查 |
| **二次惡性腫瘤** | 治療相關性白血病（etopside）、實體瘤（放射區域）| 定期理學檢查 |

### B. 懷孕與遺傳諮詢

- <span style="color:#fb923c">**烷化劑**</span>（Cyclophosphamide）和<span style="color:#fb923c">**亞硝基尿素**</span>對卵巢/睪丸毒性最高
- 建議癌症康復者在嘗試懷孕前進行生育諮詢
- 遺傳性癌症綜合徵（Li-Fraumeni、RB1）患者需進行基因諮詢

## V. 免疫治療與靶向治療

| 治療類型 | 藥物 | 適應症 |
|---------|------|-------|
| **Anti-GD2 單株抗體** | Dinutuximab | 高風險神經母細胞瘤（與GM-CSF、IL-2、Isotretinoin 聯合）|
| **CD19 CAR-T** | Tisagenlecleucel | 復發/難治性 B-ALL |
| **CD22 ADC** | Inotuzumab ozogamicin | 復發/難治性 B-ALL |
| **BRAF V600E 抑制劑** | Dabrafenib + Trametinib | BRAF V600E 突變的膠質瘤 |
| **MEK 抑制劑** | Trametinib、Cobimetinib | 低惡性膠質瘤（NF1 或 BRAF 突變）|
| **ALK 抑制劑** | Crizotinib | ALK 突變的發炎性肌纖維母細胞瘤 |
| **免疫檢查點抑制劑** | Pembrolizumab（PD-1 抑制劑）| MSI-H/dMMR 腫瘤 |
| **mTOR 抑制劑** | Everolimus | 腎血管平滑肌脂肪瘤（結節性硬化症）|
