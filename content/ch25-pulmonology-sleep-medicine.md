> **章節導讀摘要**
> 本章涵蓋兒童胸腔科與睡眠醫學的核心知識，含肺氣體交換評估（血氧監測、血氣分析）、肺功能檢查（PFT/Spirometry）、氣喘階梯治療、病毒性細支氣管炎、支氣管肺發育不良（BPD）、囊腫纖維化（CF）及阻塞性睡眠呼吸中止症（OSAS）。重点在於掌握兒童常見呼吸道疾病的診斷要點與治療階梯，涵蓋从急性處置到慢性長期照護的連續性照護概念。

---

## I. 肺氣體交換評估（Evaluation of Pulmonary Gas Exchange）

### A. 脈搏血氧測定（Pulse Oximetry）

- 非侵入性，經由周邊血液中<span style="color:#c084fc">氧合血紅素</span>與<span style="color:#c084fc">去氧血紅素</span>的光吸收特性間接測量<span style="color:#34d399">SaO₂（血氧飽和度）</span>
- **限制**：
  - 僅測量血氧飽和度，無法反映<span style="color:#60a5fa">組織氧氣輸送</span>
  - 對高氧不敏感
  - **數值偏高**：<span style="color:#c084fc">碳氧血紅素（Carboxyhemoglobin）</span> > 1-2%
  - **數值偏低**：<span style="color:#c084fc">甲基血紅素（Methemoglobin）</span> > 1%、靜脈注射染料、指甲油
  - **不可靠**：體溫過低、低血容量、休克、水腫、運動偽影

### B. 潮氣末二氧化碳（End-Tidal CO₂, ETCO₂）

- 以紅外線或質譜法測量呼出氣體中<span style="color:#34d399">CO₂濃度</span>
- <span style="color:#34d399">ETCO₂</span>與<span style="color:#34d399">PaCO₂</span>相關（健康者差距約<span style="color:#34d399">5 mmHg</span>以內）
- 用途：確認氣管內管位置、監測機械通氣、評估CPR效果、睡眠多導圖（Polysomnography）

### C. 血氣分析（Blood Gases）

| 類型 | 重點 |
|------|------|
| <span style="color:#60a5fa">动脉血气（ABG）</span> | 最準確：測PaO₂（氧合）、PaCO₂（通氣）、pH、HCO₃⁻ |
| <span style="color:#60a5fa">靜脈血气（VBG）</span> | PvCO₂較PaCO₂高<span style="color:#34d399">6-8 mmHg</span>，靜脈pH略低 |
| <span style="color:#60a5fa">毛細血管血气（CBG）</span> | pH相關性最佳，PCO₂中等，PO₂最差 |

### D. 酸鹼失衡分析

先判定原發障礙（代謝性或呼吸性），再計算預期代償反應評估混合障礙。

## II. 肺功能檢查（Pulmonary Function Tests, PFT）

### A. 尖峰呼氣流速（Peak Expiratory Flow Rate, PEFR）

- 最大流速，由深吸氣後用力呼出測得
- 用於追蹤<span style="color:#f87171">氣喘</span>病程與治療反應，與個人最佳值及正常預測值比較
- 限制：依賴用力程度，幼童難以可靠執行

### B. 最大吸氣壓與呼氣壓（MIP/MEP）

- <span style="color:#34d399">MIP（最大吸氣壓）</span>：各年齡約<span style="color:#34d399">80-120 cm H₂O</span>，低值可能需呼吸支持
- <span style="color:#34d399">MEP（最大呼氣壓）</span>：隨年齡增加，男性較高；低值與咳嗽效能降低有關

### C. 肺量計檢查（Spirometry，適用 ≥6 歲）

**重要數值定義**：
- <span style="color:#60a5fa">FVC（用力肺活量）</span>：最大吸氣後用力呼出的最大氣量
- <span style="color:#60a5fa">FEV₁（第一秒用力呼氣容積）</span>：FVC動作中第一秒呼出的氣量

**判讀對照表**：

| 檢查項目 | 阻塞型（如氣喘、CF） | 限制型（如間質纖維化、脊柱側彎） |
|----------|----------------------|----------------------------------|
| FVC | 正常或降低 | 降低 |
| FEV₁ | 降低 | 降低 |
| FEV₁/FVC | **降低** | 正常或降低 |
| FEF₂₅₋₇₅ | 降低 | 正常或降低 |
| TLC | 正常或增加 | **降低** |
| RV | **增加** | 降低 |
| RV/TLC | **增加** | 正常 |

## III. 氣喘（Asthma）

### A. 定義

<span style="color:#f87171">慢性氣道炎症疾病</span>，特徵為<span style="color:#60a5fa">氣道平滑肌可逆性收縮</span>、黏液分泌增加及水腫，導致氣道阻塞與氣體滯留。臨床表現為反覆喘鳴、呼吸困難、胸悶及咳嗽。炎症導致對多種刺激（病毒感染、冷空氣、運動、情緒、過敏原、污染物）的<span style="color:#60a5fa">氣道高反應性</span>。

### B. 臨床表現

- 咳嗽、呼吸功增加（呼吸急促、輔助肌使用）、喘鳴、<span style="color:#34d399">低氧血症</span>
- 無喘鳴音可能表示嚴重支氣管痙攣導致氣流極低
- 影像學：支氣管周圍增厚、肺過度充氣、斑塊性肺膨脹不全

### C. 治療（2020 NAEPP 階梯治療指南）

#### 治療階梯（以年齡分組）

**0-4歲（間歇性）：** PRN SABA；持續性：Step 2起每日低劑量<span style="color:#fb923c">ICS</span> + PRN SABA；Step 3以上考慮<span style="color:#fb923c">ICS-formoterol</span>單吸入器（SMART therapy）

**5-11歲：** Step 1 PRN SABA；Step 2 每日低劑量<span style="color:#fb923c">ICS</span> + SABA；Step 3 <span style="color:#fb923c">ICS-formoterol</span>（每日+PRN）；Step 4 中劑量<span style="color:#fb923c">ICS-formoterol</span>；Step 5-6 高劑量<span style="color:#fb923c">ICS-LABA</span> + 考虑<span style="color:#fb923c">Omalizumab</span>

**≥12歲：** Step 3-4 首選<span style="color:#fb923c">ICS-formoterol</span>（SMART）；Step 5 可加用<span style="color:#fb923c">LAMA</span>；Step 6 高劑量<span style="color:#fb923c">ICS-LABA</span> + 口服皮質類固醇 + <span style="color:#fb923c">生物製劑</span>

**藥物類別關鍵字**：
- <span style="color:#fb923c">SABA</span>（短效β₂ agonist）：緩解急性症狀
- <span style="color:#fb923c">ICS</span>（吸入性皮質類固醇）：抗發炎基石
- <span style="color:#fb923c">LABA</span>（長效β₂ agonist）：不可單獨使用
- <span style="color:#fb923c">LAMA</span>（長效毒蕈鹼拮抗劑）
- <span style="color:#fb923c">LTRA</span>（白三烯受體拮抗劑，如Montelukast；2020年FDA發出黑框警告）
- <span style="color:#60a5fa">FeNO</span>：過敏性氣道炎症生物標記

**嚴重度分類（根據症狀頻率 + 肺功能）**：

| 嚴重度 | 症狀頻率 | 夜間症狀 | FEV₁ |
|--------|----------|----------|------|
| 間歇性 | ≤2天/週 | ≤2次/月 | >80% |
| 輕度持續 | >2天/週但非每日 | 3-4次/月 | >80% |
| 中度持續 | 每日 | >1次/週 | 60-80% |
| 重度持續 | 全天 | 常常7次/週 | <60% |

### D. 預防惡化

- 確保流感及<span style="color:#c084fc">COVID-19</span>疫苗最新
- 制定個人氣喘行動計劃
- 識別並避免過敏原觸發（室內過敏原緩解策略；若無特定過敏原 sensitization，則不建議常規實施）
- 定期臨床評估：症狀控制、吸入器技術、藥物遵從性

## IV. 細支氣管炎（Bronchiolitis）

### A. 定義

- 嬰兒及<span style="color:#34d399">≤2歲幼兒</span>常見的下呼吸道感染
- 特徵：急性炎症、水腫、氣道上皮壞死 → 黏液分泌增加、支氣管痙攣
- 主要病原：<span style="color:#c084fc">RSV（呼吸道融合病毒）</span>，亦可為<span style="color:#c084fc">人類鼻病毒、，副流感病毒、腺病毒、肺炎黴漿菌、人類 metapneumovirus</span>

### B. 臨床表現

- 鼻炎、咳嗽 → 進展至呼吸急促、喘鳴、濕囉音、輔助肌使用、鼻翼搧動
- 可見短暫性呼吸中止
- 影像學：肺過度充氣、肺膨脹不全
- **常規不建議做影像學及病毒檢測**

### C. 治療

以<span style="color:#60a5fa">支持性治療</span>為主：
- 評估重症風險因素：年齡 < 12週、早產、先天性心肺疾病、免疫缺陷
- **不建議**常規給予：<span style="color:#fb923c">Albuterol</span>、<span style="color:#fb923c">Epinephrine</span>、<span style="color:#fb923c">全身性皮質類固醇</span>或胸腔物理治療
- <span style="color:#fb923c">高張生理食鹽水（Nebulized hypertonic saline）</span>：住院病人可考慮，急診不建議
- 血氧 > <span style="color:#34d399">90%</span>可不給予氧氣補充
- 無法口服補液者：鼻胃管或靜脈輸液
- 深度抽吸不建議（可能延長住院）
- <span style="color:#fb923c">Palivizumab</span>（RSV免疫預防）用於高風險嬰兒（見第16章）

## V. 支氣管肺發育不良（Bronchopulmonary Dysplasia, BPD）

### A. 定義

- 又稱<span style="color:#f87171">早產兒慢性肺疾病</span>
- 出生後因氣道炎症、高氧、低氧或機械通氣損傷，導致肺泡、氣道及血管發育受阻
- 診斷：早產兒出生後<span style="color:#34d399">≥28天</span>仍需 >21% 氧氣補充
- 風險因素：早產、IUGR、母嬰吸菸、產前感染、機械通氣

### B. 臨床表現

- 持續呼吸道症狀、氣道高反應性、疾病期間需氧氣補充
- 部分患者呼吸疾病可持續至成年

### C. 診斷（嚴重度分級）

| 嚴重度 | 標準 |
|--------|------|
| 輕度 | 室房空氣下無需支持 |
| 中度 | 需 <30% 氧氣 |
| 重度 | 需 >30% 氧氣及/或正壓 |

- 出生<span style="color:#34d399">GA < 32週</span>：於<span style="color:#34d399">36週胎齡</span>或出院時評估（取其較早者）
- 出生<span style="color:#34d399">GA > 32週</span>：於出生後<span style="color:#34d399">28-56天</span>或出院時評估

### D. 治療

- <span style="color:#fb923c">支氣管擴張劑</span>、<span style="color:#fb923c">皮質類固醇</span>、<span style="color:#fb923c">氧氣治療</span>、<span style="color:#fb923c">利尿劑</span>；嚴重者氣管切開術及長期機械通氣
- RSV 預防（見第16章）
- 併發症監測：肺/全身性高血壓、電解質異常、腎鈣化症、神經發育/生長遲緩、睡眠呼吸障礙、吸入性肺炎

## VI. 囊腫纖維化（Cystic Fibrosis, CF）

### A. 定義

<span style="color:#f87171">自體隱性遺傳疾病</span>，<span style="color:#c084fc">CFTR基因突變</span>導致<span style="color:#60a5fa">氯離子通道功能缺陷</span>，影響氣道、胰管、膽道、腸道、輸精管及汗腺，造成進行性阻塞性肺病及胰臟外分泌不足

### B. 臨床表現（系統性）

| 系統 | 表現 |
|------|------|
| 肺 | <span style="color:#f87171">支氣管擴張</span>、支氣管炎、肺炎、肺膨脹不全、<span style="color:#f87171">咳血</span>、<span style="color:#f87171">氣胸</span>、過敏性支氣管肺麴菌病（ABPA） |
| 胰臟 | 胰酶不足、糖尿病 |
| 胃腸 | <span style="color:#f87171">胎糞腸阻塞（Meconium ileus）</span>、直腸脫垂、腸套疊、阻塞性黃疸 |
| 肝 | 脂肪肝、門脈高壓、膽道硬化 |
| 生殖 | 男性無輸精管（不孕）、女性相對正常生育力 |
| 其他 | 生長遲緩、維生素A/D/E/K缺乏、<span style="color:#f87171">杵狀指</span>、骨關節病變 |

### C. 診斷

1. **新生兒篩檢（NBS）**：血液免疫反應性胰蛋白酶原（IRT）及/或<span style="color:#c084fc">CFTR基因突變</span>分析
2. **汗液氯離子測試（Gold standard）**：定量毛果芸香鹼離子電滲透法定量；<span style="color:#34d399">≥60 mmol/L</span>確診
3. **基因分析**：>2500種CFTR突變；若常規篩檢未發現突變則做基因定序
4. 完整病史、家族史及理學檢查

### D. 治療（CF Foundation認證中心）

**肺臟方面**：
- 氣道清除治療：手動/機械震動、姿勢引流、高頻胸壁震盪、震動PEP手持裝置
- <span style="color:#fb923c">Dornase alfa（重組人DNA酶）</span>、<span style="color:#fb923c">吸入性高張生理食鹽水</span>
- 慢性<span style="color:#c084fc">綠膿桿菌（P. aeruginosa）</span>感染：<span style="color:#fb923c">吸入性抗生素</span>、<span style="color:#fb923c">Azithromycin</span>
- <span style="color:#fb923c">CFTR調節劑</span>（適用特定突變）：
  - <span style="color:#fb923c">Kalydeco（Ivacaftor）</span>：CFTR增強劑，≥4月，97種特定突變
  - <span style="color:#fb923c">Orkambi（Lumacaftor/Ivacaftor）</span>：≥2歲，F508del純合子
  - <span style="color:#fb923c">Symdeko（Tezacaftor/Ivacaftor）</span>：≥6歲
  - <span style="color:#fb923c">Trikafta（Elexacaftor/Tezacaftor/Ivacaftor）</span>：≥6歲，至少一個F508del突變
- 急性惡化：<span style="color:#c084fc">P. aeruginosa</span>、<span style="color:#c084fc">金黃色葡萄球菌（S. aureus）</span> → IV抗生素
- ABPA：<span style="color:#fb923c">口服皮質類固醇</span> + <span style="color:#fb923c">抗真菌藥</span>
- 末期：肺移植

**胰外分泌**：
- <span style="color:#fb923c">胰酶替代治療（PERT）</span>飯前服用
- 脂溶性維生素A、D、E、K補充
- 維持<span style="color:#34d399">BMI ≥第50百分位</span>
- 監測CF相關糖尿病及肝病

**預後**：中位存活年齡已超過<span style="color:#34d399">48歲</span>

## VII. 阻塞性睡眠呼吸中止症（OSAS）

### A. 定義

睡眠期間呼吸障礙，特徵為<span style="color:#f87171">慢性部分上呼吸道阻塞</span>及/或間歇性完全阻塞，導致睡眠時通氣中斷及睡眠結構異常

### B. 臨床表現

| 時間 | 症狀 |
|------|------|
| 夜間 | 習慣性打鼾±呼吸暫停、呼吸功增加、夢遊、遺尿、盜汗 |
| 白天 | 注意力不集中、學習問題、行為問題（幼童很少主訴嗜睡） |

- 長期併發症：神經認知障礙、行為問題、生長遲緩、心臟功能障礙、肺/全身性高血壓
- 風險因素：腺樣體/扁桃腺肥大、肥胖、家族史、顱面畸形、喉部異常、早產、鼻/咽部炎症、神經肌肉疾病

### C. 診斷

- 所有兒童應常規篩檢打鼾
- 若規律打鼾且有症狀，應做<span style="color:#60a5fa">睡眠多導圖（Polysomnography）</span>
- **Polysomnography確診標準**（滿足其一）：
  - AHI（呼吸中止-低通氣指數）≥<span style="color:#34d399">1次/小時</span>
  - <span style="color:#34d399">PaCO₂ > 50 mmHg</span>超過25%睡眠時間 + 打鼾、矛盾胸腹運動或鼻壓波形平坦
- 嚴重度：AHI 1-5（輕度）、5-10（中度）、>10（重度）

### D. 治療

| 治療方式 | 適用情況 |
|----------|----------|
| <span style="color:#fb923c">腺樣體扁桃體切除術（Adenotonsillectomy）</span> | 第一線治療，尤其有腺樣體/扁桃腺肥大者；術後需重新評估 |
| 觀察等待（最多6個月） | 輕度/中度且健康之兒童 + 支持性照護（睡眠衛生、鹽水噴鼻、過敏治療） |
| <span style="color:#fb923c">CPAP（持續正壓呼吸器）</span> | 手術未進行或術後仍持續者 |
| 減重 | 過重或肥胖患者 |
| <span style="color:#fb923c">鼻內皮質類固醇</span>、<span style="color:#fb923c">Montelukast</span> | 輕度OSAS |
| 快速上頜骨擴張（RME）| 特定顱面特徵兒童 |
| 顱面手術、氣管切開術 | 嚴重先天性顱面異常患者 |

## VIII. 嬰兒與兒童睡眠（Infant and Child Sleep）

### A. 睡眠時間建議

| 年齡組 | 每日建議睡眠時間（含午睡） |
|--------|--------------------------|
| 嬰兒（4-12月） | <span style="color:#34d399">12-16 小時</span> |
| 幼兒（1-2歲） | <span style="color:#34d399">11-14 小時</span> |
| 學齡前（3-5歲） | <span style="color:#34d399">10-13 小時</span> |
| 學齡兒童（6-12歲） | <span style="color:#34d399">9-12 小時</span> |
| 青少年（13-18歲） | <span style="color:#34d399">8-10 小時</span> |

- 慢性睡眠不足與肥胖、憂鬱、高血壓、糖尿病及學業表現不佳風險增加有關

### B. 睡眠相關嬰兒死亡（Sleep-Related Infant Death）

**定義**：
- <span style="color:#60a5fa">SUID（睡眠相關嬰兒死亡）</span>：觀察或未觀察之睡眠期間發生的不明原因嬰兒死亡
- <span style="color:#f87171">SIDS（嬰兒猝死症）</span>：經完整調查後仍無法解釋的死因

**流行病學**：
- 2020年SUID發生率：每10萬活產<span style="color:#34d399">92.9例</span>
- 高峰年齡：<span style="color:#34d399">1-4月</span>，90%發生於<6月

**安全睡眠建議（AAP 2016）**：
- 嬰兒每次睡眠採<span style="color:#60a5fa">仰睡</span>至1歲
- 使用<span style="color:#60a5fa">堅實床墊</span>，無軟物品或鬆散寢具
- 與嬰兒同房不同床（至少前6個月，理想為1年）
- 避免過熱及頭部覆蓋
- 孕期及產後避免酒精、毒品、菸草暴露
- 建議：規律產檢、母乳餵養、疫苗、睡前提供安撫奶嘴
- **不建議**使用家庭心肺監護器作為降低SIDS風險的策略

### C. 常見兒童睡眠障礙（線上內容摘要）

| 障礙 | 特點 |
|------|------|
| <span style="color:#f87171">失眠（Insomnia）</span> | 入睡/維持睡眠困難；幼童常見行為性失眠（抗拒就寢、夜醒）；處理：設定界線、睡眠衛生 |
| 夜間恐懼 | 正常發展現象，認知發展相關；給予安慰物品；需與焦慮症區分 |
| 夢魘 | 6-10歲高峰；減少壓力、避免可怕影像、充足睡眠 |
| <span style="color:#f87171">延遲睡眠相位症候群</span> | 晝夜節律持續延遲；青少年常見；治療：行為治療、光照療法、褪黑激素 |
| <span style="color:#f87171">異睡症（Parasomnias）</span> | 包含夢遊、夜驚、意識模糊覺醒；4-6歲發病，通常青春期後消失；保持安全、避免誘發因素 |

## IX. 短暫無法解釋的事件（Brief Resolved Unexplained Event, BRUE）

### A. 定義

原稱ALTE（明顯危及生命的事件），指年齡<span style="color:#34d399"><1歲</span>的嬰兒出現短暫（<1分鐘）且已緩解的發作，觀察者報告至少有以下之一：
- 發紺或蒼白
- 呼吸暫停、減少或不規則
- 張力明顯改變（高或低張力）
- 意識狀態改變

### B. 鑑別診斷

包括<span style="color:#f87171">胃食道逆流（GER）</span>、<span style="color:#f87171">癲癇</span>、非意外創傷、<span style="color:#f87171">心律不整</span>、先天代謝異常、下呼吸道感染。若可找到解釋則不屬BRUE。

### C. 風險分層與管理

**低風險標準**（全部滿足）：
- 年齡 > 60天；GA ≥ 32週且受孕後年齡 ≥ 45週；無需CPR；發作 < 1分鐘；首次發作；無令人擔憂的病史或理學發現

**低風險處置**：家屬衛教、CPR訓練資源、急診短暫觀察（持續血氧監測）、心電圖、百日咳檢測；一般不需進一步檢查

**高風險**：需個別化評估及管理
