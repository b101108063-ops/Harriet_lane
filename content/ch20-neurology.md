## 導讀摘要

本章節涵蓋兒科中毒與毒理學的緊急處置。重點包括：

- **常見中毒物質**（藥物、家用化學品、環境毒素）的毒性與治療
- **中毒緊急處理原則**（支持性治療、解毒劑、血液透析）
- **特定解毒劑**的適應症與使用方法
- **藥物過量**的處理流程

| 毒素類別 | 常見物質 | 關鍵解毒劑 |
|-----------|----------|------------|
| 鎮靜劑 | 苯二氮平類、酒精 | Flumazenil |
| 鴉片類 | 海洛因、嗎啡、芬尼 | Naloxone |
| 農藥 | 有機磷、氨基甲酸鹽 | Atropine、Pralidoxime |
| 重金屬 | 鉛、汞、砷 | 螯合劑 |
| 一氧化碳 | 汽車廢氣、暖爐 | 100% 氧氣、高壓氧 |

## I. 中毒緊急處理原則

### A. 初始 Stabilization（ABCD 評估）

| 步驟 | 內容 |
|------|------|
| **A（Airway）** | 確保呼吸道通暢，考慮保護性氣管內管 |
| **B（Breathing）** | 評估呼吸，給予氧氣，必要時插管 |
| **C（Circulation）** | 監測血壓、心率，建立靜脈通路 |
| **D（Drugs/Decontamination）** | 解毒劑、清洗 |

> **⚠️ 臨床警告**：意識改變患者應早期插管以保護呼吸道

### B. 去污染

#### 1. 皮膚暴露

| 步驟 | 說明 |
|------|------|
| **移除污染衣物** | 脫掉所有被污染衣物 |
| **清水冲洗** | 至少 15-20 分鐘 |
| **懷疑腐蝕物** | 延長冲洗時間 |

#### 2. 眼睛暴露

| 步驟 | 說明 |
|------|------|
| **清水冲洗** | 使用生理食鹽水或清水 |
| **時間** | 至少 15-20 分鐘 |
| **pH 檢測** | 冲洗後測量 |

#### 3. 攝入

| 情況 | 處理 |
|------|------|
| **腐蝕性物質** | 不催吐，考慮早期內視鏡 |
| **碳氫化合物** | 不催吐，風險高 |
| **一般物質** | 考慮活性碳（特定情況） |

### C. 增加毒物排除

| 方法 | 適應症 |
|------|--------|
| **鹼化尿液** | 水楊酸鹽（尿液 pH > 7.5） |
| **血液透析** | 甲醇、乙二醇、鋰、嚴重水楊酸鹽 |
| **換血** | 嚴重一氧化碳中毒 |
| **NAC（活性炭血液透析）** | 嚴重中毒（特定中心） |

## II. 常見藥物中毒

### A. 鎮痛劑

#### 1. 普拿疼（Acetaminophen）

| 毒性參數 | 數值 |
|----------|------|
| **潛在中毒劑量** | > 150 mg/kg（單次攝入） |
| **治療閾值** | 攝入後 4 小時 > 150 μg/mL |
| **解毒劑** | N-acetylcysteine（NAC） |

##### 中毒進程

| 時間 | 臨床階段 |
|------|----------|
| **0-24 小時** | 無症狀或輕微（噁心、嘔吐） |
| **24-72 小時** | 肝毒性（AST/ALT 升高） |
| **72-96 小時** | 肝壞死、腎衰竭 |
| **4 天至 2 週** | 康復或進行性肝衰竭 |

##### NAC 治療方案

| 途徑 | 方案 |
|------|------|
| **口服** | 140 mg/kg 初始，然後 70 mg/kg q4h 共 17 劑 |
| **靜脈** | 150 mg/kg 初始（1 小時），然後 50 mg/kg（4 小時），然後 100 mg/kg（16 小時） |

> **💡 Clinical Pearl**：NAC 在中毒 8 小時內使用效果最佳，但 24 小時後仍有益處

#### 2. 水楊酸鹽（Aspirin）

| 毒性參數 | 數值 |
|----------|------|
| **中毒劑量** | > 150 mg/kg |
| **嚴重中毒** | > 300 mg/kg 或血清濃度 > 100 mg/dL |

##### 臨床表徵

| 早期 | 晚期 |
|------|------|
| 耳鳴、噁心、嘔吐 | 意識障礙 |
| 出汗、心搏過速 | 癲癇 |
| 呼吸過快 | 肺水腫 |

##### 治療

| 方法 | 說明 |
|------|------|
| **鹼化尿液** | 目標尿液 pH 7.5-8.0 |
| **血液透析** | 嚴重中毒（血清 > 100 mg/dL） |

### B. 抗抑鬱藥

#### 1. 三環抗抑鬱藥（TCA）中毒

| 毒性特徵 | 說明 |
|----------|------|
| **機轉** | 抗膽鹼 + 心臟毒性 + 癲癇 |
| **QRS 延長** | > 100 ms 為嚴重毒性指標 |

##### 臨床表徵

| 抗膽鹼作用 | 心臟作用 | CNS 作用 |
|------------|----------|----------|
| 瞳孔放大 | 心律不整 | 意識障礙 |
| 口乾 | QT 延長 | 癲癇 |
| 尿滞留 | 低血壓 | 昏迷 |

##### 治療

| 方法 | 劑量 |
|------|------|
| **碳酸氫鈉** | 1-2 mEq/kg IV（鹼化血液） |
| **Benzodiazepine** | 癲癇發作時 |
| **心律不整** | 考慮臨時起搏器 |

#### 2. SSRI 中毒

| 毒性 | 說明 |
|------|------|
| **血清張力障礙反應** | 肌肉僵硬、體溫過高 |
| **5-羥色胺症候群** | 躁動、出汗、心搏過快 |

### C. 鴉片類藥物

| 臨床表徵 | 說明 |
|----------|------|
| **Classic triad** | 針狀瞳孔、呼吸抑制、意識障礙 |
| **低血壓** | 常見 |
| **癲癇** | 建議檢查其他藥物（propoxyphene、tramado） |

#### Naloxone 治療

| 製劑 | 劑量 |
|------|------|
| **幼兒** | 0.1 mg/kg IV（最大 2 mg） |
| **成人** | 0.4-2 mg IV（可重複） |

> **⚠️ 臨床警告**：Naloxone 作用時間短（30-90 分鐘），需注意再發性呼吸抑制

## III. 農藥與殺蟲劑中毒

### A. 有機磷中毒

| 機轉 | 膽鹼酯酶抑制 → 乙醯膽鹼積累 |
|------|--------------------------------|

#### 膽鹼酯酶危機（Cholinergic Toxidrome）

| 症狀類型 | 表現 |
|----------|------|
| **Muscarinic（DOSSI）** | Diarrhea, Oversalivation, Sweating, Salivation, Lacrimation, Urination |
| **Nicotinic** | 肌肉顫動、痙攣、無力 |
| **CNS** | 意識障礙、癲癇 |

#### 治療

| 解毒劑 | 初始劑量 |
|--------|----------|
| **Atropine** | 0.05 mg/kg IV（最小 0.1 mg，可重複） |
| **Pralidoxime（2-PAM）** | 20-50 mg/kg IV（最大 1-2 g） |

> **🔵 重要關鍵字**：Atropine 應給予直到無 excess secretions，再持續一段時間

### B. 氨基甲酸鹽中毒

| 特徵 | 說明 |
|------|------|
| **差異** | 症狀通常較輕 |
| **治療** | Atropine（不用 2-PAM） |

## IV. 家用與環境毒素

### A. 腐蝕性物質

| 物質 | 說明 |
|------|------|
| **強酸** | 硫酸、鹽酸、磷酸 |
| **強鹼** | 氫氧化鈉（通渠劑）、氫氧化鉀 |
| **漂白劑** | 次氯酸鈉（通常腐蝕性較低） |

#### 臨床表徵

| 急性 | 慢性 |
|------|------|
| 口腔/咽喉疼痛 | 食道狹窄 |
| 流口水 | 吞嚥困難 |
| 嘔吐 |  |

#### 治療

| 步驟 | 說明 |
|------|------|
| **不催吐** | 再次暴露風險 |
| **不中和** | 產熱可能加重傷害 |
| **早期內視鏡** | 24 小時內評估損傷程度 |

### B. 碳氫化合物

| 物質 | 說明 |
|------|------|
| **石油蒸餾物** | 汽油、煤油、礦物油 |
| **松節油** | 取代甲苯、二甲苯 |

#### 毒性

| 途徑 | 毒性 |
|------|------|
| **吸入** | 肺炎、化學性肺炎 |
| **攝入** | 嘔吐（嘔吐風險 > 吸入風險） |

#### 治療

> **⚠️ 臨床警告**：石油蒸餾物不應催吐，避免吸入性肺炎

### C. 一氧化碳（CO）中毒

| 參數 | 數值 |
|------|------|
| **正常HbCO** | < 5%（非吸煙者） |
| **中毒濃度** | 症狀多在 > 10% |
| **嚴重中毒** | > 25-30% 或有症狀 |

#### 臨床表徵

| 輕度 | 中度 | 重度 |
|------|------|------|
| 頭痛 | 意識混亂 | 昏迷 |
| 頭暈 | 胸痛 | 癲癇 |
| 噁心 | 心律不整 | 心肌缺血 |

#### 治療

| 方法 | 適應症 |
|------|--------|
| **100% 氧氣** | 所有患者 |
| **高壓氧（HBO）** | HbCO > 25%，昏迷，神經學症狀，孕婦 |

## V. 重金屬中毒

### A. 鉛中毒

| 參數 | 數值 |
|------|------|
| **參考血中濃度** | < 5 μg/dL |
| **升高** | 5-14 μg/dL |
| **中度中毒** | 15-44 μg/dL |
| **重度中毒** | > 45 μg/dL |

#### 臨床表徵

| 急性 | 慢性 |
|------|------|
| 腹絞痛 | 發育遲緩 |
| 腦病（嚴重） | 認知功能受損 |
| 溶血性貧血 | 感覺神經病變 |

#### 治療

| 血鉛濃度 | 治療 |
|----------|------|
| **< 45 μg/dL** | 移除鉛來源、營養干預 |
| **45-69 μg/dL** | 口服螯合劑（Succimer/DMSA） |
| **≥ 70 μg/dL** | 靜脈螯合劑（EDTA） |

### B. 其他重金屬

| 重金屬 | 來源 | 螯合劑 |
|--------|------|--------|
| **汞** | 溫度計、牙科填充物 | DMSA、DMPS |
| **砷** | 殺蟲劑、工業 | BAL、DMSA |
| **鐵** | 補充劑過量 | 去鐵胺（Deferoxamine） |

## VI. 物質濫用

### A. 酒精中毒

| 參數 | 數值 |
|------|------|
| **中毒血中濃度** | > 50 mg/dL |
| **明顯中毒** | > 150 mg/dL |
| **嚴重中毒（兒童）** | > 300 mg/dL 可致命 |

#### 臨床表徵

| 血中濃度 | 臨床 |
|----------|------|
| 50-100 mg/dL | 欣快、協調障礙 |
| 100-200 mg/dL | 言語不清、嘔吐 |
| 200-300 mg/dL | 意識障礙 |
| > 300 mg/dL | 昏迷、呼吸抑制 |

#### 治療

| 方法 | 說明 |
|------|------|
| **支持性治療** | 確保呼吸道、靜脈輸液 |
| **血糖監測** | 預防低血糖 |
| **血液透析** | 嚴重中毒（特定情況） |

### B. 迷幻藥物

| 藥物 | 臨床表徵 | 治療 |
|------|----------|------|
| **大麻** | 瞳孔縮小、心搏過速、幻覺 | 支持性 |
| **甲基安非他命** | 瞳孔放大、過動、體溫過高 | Benzodiazepine |
| **快樂丸（MDMA）** | 體溫過高、血壓升高、5-羥色胺症候群 | 積極冷卻 |

## IX. Clinical Pearl & Warning

> **💡 Clinical Pearl**
> - 普拿疼中毒早期無症狀，攝入後 4 小時應測量血中濃度
> - 有機磷中毒 Atropine 劑量要足夠，直到分泌物減少
> - 碳氫化合物中毒不催吐，因為嘔吐風險大於攝入風險

> **⚠️ Clinical Warning**
> - TCA 中毒 QRS > 100 ms 是心律不整和癲癇的高風險指標
> - 兒童鐵中毒即使血中濃度在「正常範圍」也可能嚴重
> - 一氧化碳中毒所有患者都應給予 100% 氧氣，高壓氧可預防延遲性神經學後遺症
