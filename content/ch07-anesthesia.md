# 第七章：麻醉

<span style="color:#60a5fa">**Alexander Tang, MD 與 James Ting, MD**</span>

---

## 導讀摘要

本章節涵蓋小兒麻醉的核心內容，包括：術前評估（禁食指南、ASA分級、氣道評估）、全身麻醉誘導與維持、局部與區域麻醉技術（硬膜外、脊椎、周邊神經阻斷）、麻醉藥理學（誘導藥物如propofol、ketamine、sevoflurane、維持藥物）、術後疼痛管理、惡性高熱識別與治療、以及常見麻醉併發症的處置。臨床重點包括：NPO指南、困難氣道辨識、Mallampati分類、區域麻醉適應症與禁忌、以及對有先天性心臟病兒童的麻醉特殊考量。

---

## I. 術前評估

### A. 病史

#### 1. 全身麻醉和/或鎮靜的先前反應

- <span style="color:#f87171">**惡性高熱個人或家族史**</span>
- <span style="color:#f87171">**膽鹼酯酶（pseudocholinesterase）缺乏或還原型分解**</span>
- 困難氣道/插管史
- 術後噁心嘔吐（PONV）史

#### 2. 現有病史

| 系統 | 評估重點 |
|------|---------|
| **氣道** | 小頜、張口受限、睡眠呼吸中止、鼻塞 |
| **心臟** | 先天性心臟病、心律不整、心肌病變 |
| **肺部** | 氣喘、慢性肺疾病、近期上呼吸道感染 |
| **神經** | 癲癇、神經肌肉疾病、顱內壓升高 |
| **血液** | 凝血病變、鐮刀型紅血球疾病 |
| **內分泌** | 糖尿病、甲狀腺疾病、腎上腺功能不全 |

#### 3. 用藥史

- 抗凝血劑
- <span style="color:#fb923c">**單胺氧化酶抑制劑（MAOIs）**</span>
- <span style="color:#fb923c">**甲狀腺藥物**</span>
- 類固醇
- 草藥補充品（如：銀杏、大蒜、聖約翰草）

#### 4. 過敏史

- 藥物過敏（尤其<span style="color:#fb923c">**抗生素、麻醉藥物**</span>）
- 乳膠過敏
- 食物過敏

### B. 身體檢查

#### 1. 氣道評估

| 評估項目 | 異常發現 |
|---------|---------|
| **Mallampati分類** | III-IV級提示困難氣道 |
| **張口度** | <3cm可能困難 |
| **牙齒** | 假牙、暴牙、牙齒鬆動 |
| **顱頸活動度** | 頸椎活動受限（類風濕關節炎、創傷） |
| **下頜大小** | 小頜/Retrognathia |
| **舌頭大小** | 巨舌症 |

#### 2. 心肺檢查

- 生命徵象（含血壓）
- 心雜音
- 肺部聽診
- 肝脾大小

### C. 禁食指南（表7.1）

| 食物類型 | 最短禁食（小時） |
|---------|---------------|
| **清液體** | 2 |
| **母乳** | 4 |
| **配方奶/非人類奶** | 6 |
| **固體** | 8 |

<span style="color:#60a5fa">**緊急程序：即使患者非NPO，也應進行鎮靜/麻醉，但需權衡吸入風險。**</span>

### D. ASA身體狀態分類

| 等級 | 定義 | 麻醉風險 |
|------|------|---------|
| **I** | 正常健康 | 極低 |
| **II** | 輕度全身疾病，無功能受限 | 低 |
| **III** | 重度全身疾病，有功能受限 | 中等 |
| **IV** | 重度全身疾病，持續威脅生命 | 高 |
| **V** | 垂死患者，手術為最後手段 | 極高 |

## II. 全身麻醉

### A. 誘導

#### 1. 靜脈誘導（IV）

常用藥物：

| 藥物 | 劑量 | 備註 |
|------|------|------|
| **Propofol** | 2-3 mg/kg | 快速誘導；可能低血壓 |
| **Thiopental** | 3-5 mg/kg | 長效；現在少用 |
| **Ketamine** | 1-2 mg/kg IV | <span style="color:#22d3ee">**支氣管擴張；血行動力學穩定**</span>；可能增加分泌物 |

#### 2. 吸入誘導

| 藥物 | 特性 |
|------|------|
| **Sevoflurane** | <span style="color:#60a5fa">**首選**</span>——快速誘導、恢復快、氣道刺激性低 |
| **Desflurane** | 快速；但氣道刺激性強 |
| **Halothane** | 可用於吸入誘導；但肝毒性風險 |

#### 3. 肌肉誘導（IM）

<span style="color:#fb923c">**Ketamine**</span> 4-5 mg/kg + <span style="color:#fb923c">**Atropine**</span> 0.02 mg/kg（減少分泌物）

### B. 氣道管理

#### 1. 面罩通氣

- 確認足夠的密封
- 正確的頭部位置（嗅姿勢）
- 口腔/鼻腔吸引必要時

#### 2. 喉罩（LMA）

<span style="color:#60a5fa">**適用於不需要氣管內管的程序**</span>

| 優點 | 限制 |
|------|------|
| 放置簡單 | <span style="color:#f87171">**誤吸風險高**</span> |
| 避免喉鏡 | 氣道阻塞風險 |
| 血流動力學穩定 | 不適用於特定手術 |

#### 3. 氣管內管（ETT）

<span style="color:#f87171">**適應症**：胃飽和、意識障礙、困難氣道、特定手術

| 管徑選擇 | |
|----------|----------|
| **早產兒** | 2.5-3.0 mm ID |
| **足月新生兒** | 3.0-3.5 mm ID |
| **兒童** | （年齡÷4）+ 4 mm（公式） |

### C. 維持

| 藥物 | 特性 |
|------|------|
| **Sevoflurane** | 最常用；快速恢復 |
| **Desflurane** | 最低血溶性；但氣道刺激性 |
| **Isoflurane** | 血流動力學穩定 |
| **Propofol輸注** | TIVA（靜脈麻醉） |

<span style="color:#f87171">**注意**：所有鹵化麻醉劑與<span style="color:#c084fc">**惡性高熱**</span>相關。

### D. 肌肉鬆弛劑

| 藥物 | 劑量（mg/kg） | 作用時間 | 逆轉 |
|------|--------------|---------|------|
| **Rocuronium** | 0.6-1.2 | 30-45分 | <span style="color:#fb923c">**Neostigmine + Glycopyrrolate**</span> |
| **Vecuronium** | 0.1-0.15 | 25-40分 | <span style="color:#fb923c">**Neostigmine + Glycopyrrolate**</span> |
| **Cisatracurium** | 0.1-0.15 | 25-40分 | <span style="color:#fb923c">**Neostigmine + Glycopyrrolate**</span> |
| **Succinylcholine** | 1-2 | 6-10分 | 不需（自行代謝） |

<span style="color:#f87171">**Succinylcholine禁忌症**：高血鉀、燒傷後、顱內壓升高、<span style="color:#c084fc">**惡性高熱**</span>史、肌肉病變

## III. 區域麻醉

### A. 硬膜外麻醉

#### 1. 適應症

- 下腹部手術
- 下肢手術
- <span style="color:#60a5fa">**術後疼痛管理**</span>

#### 2. 常用藥物

| 藥物 | 濃度 | 劑量 |
|------|------|------|
| **Lidocaine** | 1-2% | 4-5 mg/kg |
| **Bupivacaine** | 0.125-0.5% | 2-3 mg/kg |
| **Ropivacaine** | 0.1-0.2% | 2-3 mg/kg |

<span style="color:#fb923c">**加用Fentanyl**</span>（1-2 μg/kg）可增強止痛效果

### B. 脊椎麻醉（蛛網膜下腔）

#### 1. 適應症

- 下腹部、下肢、會陰手術
- 區域麻醉禁忌時的全身麻醉替代

#### 2. 常用藥物

| 藥物 | 劑量（mg/kg） | 持續時間 |
|------|--------------|---------|
| **Bupivacaine** | 0.3-0.5 | 60-90分 |
| **Tetracaine** | 0.3-0.5 | 90-120分 |

### C. 周邊神經阻斷

| 阻斷類型 | 適應症 |
|---------|-------|
| **股神經（Femoral）** | 大腿、膝蓋手術 |
| **坐骨神經（Sciatic）** | 小腿、腳手術 |
| **臂神經叢（Brachial plexus）** | 上肢手術 |

## IV. 麻醉藥理學

### A. 誘導藥物

| 藥物 | 機制 | 劑量 | 副作用 |
|------|------|------|-------|
| **Propofol** | GABA-A激動 | 2-3 mg/kg IV | <span style="color:#f87171">**低血壓**</span>、呼吸抑制 |
| **Ketamine** | NMDA拮抗 | 1-2 mg/kg IV | <span style="color:#22d3ee">**血行動力學興奮**</span>、Emergence delirium |
| **Thiopental** | GABA-A激動 | 3-5 mg/kg IV | <span style="color:#f87171">**蓄積**</span>、靜脈刺激 |

### B. 吸入麻醉劑

| 藥物 | MAC（%） | 血溶性 | 特性 |
|------|---------|--------|------|
| **Sevoflurane** | 2.5 | 低 | <span style="color:#60a5fa">**首選**</span>；快速誘導/恢復 |
| **Desflurane** | 7 | 極低 | 氣道刺激性 |
| **Isoflurane** | 1.5 | 中等 | 血流動力學穩定 |

### C. 鴉片類藥物

| 藥物 | 劑量 | 作用時間 |
|------|------|---------|
| **Fentanyl** | 1-5 μg/kg | 30-60分 |
| **Morphine** | 0.05-0.1 mg/kg | 2-4小時 |
| **Hydromorphone** | 0.02-0.05 mg/kg | 2-3小時 |

### D. 苯二氮平類

| 藥物 | 劑量 | 逆轉 |
|------|------|------|
| **Midazolam** | 0.05-0.1 mg/kg IV | <span style="color:#fb923c">**Flumazenil**</span> |
| **Lorazepam** | 0.05-0.1 mg/kg IV | — |

## V. 特殊考量

### A. 先天性心臟病兒童

| 分流方向 | 麻醉考量 |
|---------|---------|
| **左向右分流** | 避免增加肺血管阻力（PVR）的因素 |
| **右向左分流** | 避免增加全身血管阻力（SVR）的因素；防止氣泡 |
| **** | 根據心臟病類型個體化麻醉計畫 |

### B. 氣喘兒童

- <span style="color:#fb923c">**Ketamine**</span>是誘導的良好選擇（支氣管擴張）
- 避免<span style="color:#fb923c">**β-阻斷劑**</span>
- 備有<span style="color:#fb923c">**沙丁胺醇（Albuterol）**</span>

### C. 鐮刀型紅血球疾病

- 維持正常體溫
- 維持足夠水合
- 避免<span style="color:#f87171">**低血氧**</span>
- 避免<span style="color:#f87171">**酸中毒**</span>

## VI. 惡性高熱

### A. 識別

<span style="color:#f87171">**早期徵象**：</span>

- <span style="color:#f87171">**無法解釋的心搏過速**</span>
- <span style="color:#f87171">**CO2產生增加**</span>
- <span style="color:#f87171">**體溫快速升高**</span>（不一定早期出現）
- <span style="color:#f87171">**肌肉僵直**</span>
- <span style="color:#f87171">**代謝性酸中毒**</span>
- <span style="color:#f87171">**高血鉀**</span>

### B. 治療

| 步驟 | 處置 |
|------|------|
| **1. 停止誘發藥物** | 立即停用所有鹵化麻醉劑和Succinylcholine |
| **2. 100% O2** | 高流量純氧 |
| **3. Dantrolene** | <span style="color:#fb923c">**Dantrolene 2.5 mg/kg IV**</span>，必要時重複至最大10 mg/kg |
| **4. 降溫** | 冰毯、冷液體冲洗 |
| **5. 處理併發症** | 高血鉀、酸中毒、心律不整 |

<span style="color:#60a5fa">**Dantrolene是特異性治療**，需立即給藥。</span>

## VII. 術後管理

### A. 術後噁心嘔吐（PONV）

| 風險因素 | 預防/治療 |
|---------|---------|
| 眼科手術 | <span style="color:#fb923c">**Ondansetron**</span> 0.1 mg/kg |
| 斜視手術 | <span style="color:#fb923c">**Dexamethasone**</span> 0.1 mg/kg |
| 長時間手術 | <span style="color:#fb923c">**Metoclopramide**</span> 0.1 mg/kg |

### B. 術後疼痛管理

見第六章：止痛與程序鎮靜

### C. 蘇醒延遲

| 原因 | 評估 |
|------|------|
| 麻醉藥殘留 | 考慮<span style="color:#fb923c">**Flumazenil**</span>或<span style="color:#fb923c">**Naloxone**</span> |
| 低體溫 | 保暖 |
| 低血糖 | 血糖檢測 |
| 神經肌肉阻斷 | 考虑逆轉 |
