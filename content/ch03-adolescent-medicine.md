## 導讀摘要

本章節系統性介紹毒理學緊急情況的處理原則：

- <span style="color:#60a5fa">**中毒初始評估**</span>：病史蒐集、實驗室檢查、毒理學鑑別
- <span style="color:#60a5fa">**Toxidromes（中毒症候群）**</span>：Anticholinergic、Cholinergic、Opioid、Sympathomimetic、Sedative/hypnotic、Serotonergic
- <span style="color:#60a5fa">**常見攝入物處理**</span>：Acetaminophen、水楊酸鹽、鐵、鉛、benzodiazepines、TCAs
- <span style="color:#60a5fa">**去污染技術**</span>：活性炭、全腸道灌洗、血液透析
- <span style="color:#60a5fa">**解毒劑**</span>：N-acetylcysteine、Flumazenil、Naloxone、Fomepizole

> ⚠️ <span style="color:#f87171">**Clinical Warning**</span>：疑似中毒時，請聯繫當地毒物控制中心：**1-800-222-1222**

---

## I. 初始評估

### A. 病史

#### 1. 接觸病史

從目擊者和/或密切接觸者獲取：途徑、時間、接觸次數（急性、慢性或重複攝入）、先前治療或去污染措施

#### 2. 物質識別與數量

- 嘗試識別確切的物質名稱，包括產品名稱、活性成分、可能污染物、到期日、濃度和劑量
- 估計容器中缺少的液體量或藥片數量
- 毒物中心可協助藥片識別

#### 3. 環境資訊

- 家中或車庫可及的物品、打開的容器、灑出的藥片
- 正在服用藥物的家庭成員、其他照護者、草藥或其他補充藥物

### B. 實驗室檢查

#### 1. 心電圖（ECG）

- 多种药物可引起心電圖變化，包括 QTc 和 QRS 延長

#### 2. 血液檢查

| 檢查 | 臨床意義 |
|------|---------|
| 靜脈血氣、血糖、血清電解質 | 基本篩查 |
| 個別藥物水平（如acetaminophen、阿斯匹靈、乙醇） | 急性未知攝入的一般篩查 |
| <span style="color:#f87171">**Acetaminophen 水平**</span> | 自殺攝入必須檢測 |

#### 3. 尿液毒理學篩查

- 基本篩查包括：安非他命、古柯鹼、類鴉片、PCP、THC
- <span style="color:#f87171">**陽性結果僅為推定，需用氣相層析/質譜確認**</span>

## II. Toxidromes（中毒症候群）

### A. Anticholinergic 症候群

| 特徵 | 描述 |
|------|------|
| **記憶口訣** | "Mad as a hatter, red as a beet, blind as a bat, hot as a hare, dry as a bone" |
| **體溫** | ↑ |
| **心率** | ↑ |
| **呼吸** | 正常/↑ |
| **血壓** | ↑/正常 |
| **瞳孔** | <span style="color:#f87171">**放大**</span> |
| **皮膚** | 乾燥、潮紅 |
| **精神狀態** | 譫妄、精神病、偏執 |
| **其他** | 尿瀦留、腸鳴音減少、口渴 |

**病原藥物**：Antihistamines、Atropine、Antipsychotics、Phenothiazines、Scopolamine、TCAs

### B. Cholinergic 症候群

| 特徵 | 描述 |
|------|------|
| **記憶口訣** | "SLUDGE, Killer Bs" |
| **SLUDGE** | Salivation、Lacrimation、Urination、Defecation、Gastrointestinal distress、Emesis |
| **Killer Bs** | Bronchospasm、Bronchorrhea、Bradycardia |
| **瞳孔** | <span style="color:#60a5fa">**縮小（Constricted）**</span> |
| **皮膚** | 出汗 |
| **精神狀態** | 抑鬱、困惑 |

**病原藥物**：Organophosphates、Pesticides、Nerve agents、Tobacco、Liquid nicotine

### C. Opioid 症候群

| 特徵 | 描述 |
|------|------|
| **意識** | 鎮靜 |
| **呼吸** | <span style="color:#f87171">**↓（呼吸抑制）**</span> |
| **瞳孔** | <span style="color:#60a5fa">**縮小**</span> |
| **腸鳴音** | 減少 |

**病原藥物**：Morphine、Fentanyl、Oxycodone、Methadone

### D. Sympathomimetic 症候群

| 特徵 | 描述 |
|------|------|
| **心率** | ↑ |
| **血壓** | ↑ |
| **瞳孔** | <span style="color:#f87171">**放大**</span> |
| **皮膚** | 出汗 |
| **精神狀態** | 激動 |
| **其他** | 冠狀血管痙攣風險 |

**病原藥物**：Amphetamines、Cocaine

### E. Serotonergic 症候群

| 特徵 | 描述 |
|------|------|
| **精神狀態** | 混淆 |
| **自主神經** | 不穩定（體溫、心率、血壓波動） |
| **神經肌肉** | 顫抖、肌肉僵硬、反射亢進、下肢陣攣 |

**病原藥物**：SSRIs、SNRIs、MAOIs、Trazodone、Dextromethorphan、LSD、TCAs、MDMA

> 📌 <span style="color:#60a5fa">**Clinical Pearl**</span>：早期識別 toxidrome 可指導經驗性治療和進一步評估

## III. 常見攝入物與解毒劑

### A. Acetaminophen 過量

#### 1. Napqi 代謝物具有肝毒性

#### 2. 四階段中毒

| 階段 | 時間 | 症狀 |
|------|------|------|
| <span style="color:#60a5fa">**第一階段**</span> | 0-24 小時 | 非特異性症狀：噁心、不適、嘔吐 |
| <span style="color:#60a5fa">**第二階段**</span> | 24-72 小時 | 右上腹疼痛、肝腫大、轉氨酶升高 |
| <span style="color:#f87171">**第三階段**</span> | 72-96 小時 | 肝衰竭證據（PT↑、乳酸↑、磷酸鹽↓、腎衰竭、腦病） |
| <span style="color:#60a5fa">**第四階段**</span> | 4天-2週 | 康復或死亡 |

#### 3. 治療標準

- 血清 acetaminophen 高於 Rumack-Matthew 列線圖上的可能毒性線
- 已知攝入 > 200 mg/kg 或 10 g（取較小值）

#### 4. 解毒劑：N-Acetylcysteine (NAC)

| 給藥途徑 | 劑量 |
|---------|------|
| <span style="color:#fb923c">**口服**</span> | 負荷劑量：140 mg/kg（最大 15 g）；然後 70 mg/kg Q4h |
| <span style="color:#fb923c">**靜脈**</span> | 負荷：150 mg/kg over 60 分鐘；然後 50 mg/kg over 4 小時；然後 100 mg/kg over 16 小時 |

> 📌 <span style="color:#60a5fa">**Rumack-Matthew 列線圖**</span>：僅對單次急性攝入有效，在攝入後 4 小時前無法評估毒性

### B. 水楊酸鹽（Salicylates）

**症狀**：胃腸道不適、耳鳴、 tachypnea、過度換氣、過熱、頭暈、嗜睡、構音障礙、癲癇發作、昏迷、腦水腫

**解毒劑**：
- <span style="color:#fb923c">**Sodium bicarbonate**</span>：1-2 mEq/kg IV，然後鹼化血液
- 目標血清 pH：<span style="color:#34d399">**7.45-7.55**</span>
- 考慮血液透析

### C. 酒精中毒

**乙醇**：
- 症狀：低血糖（幼兒）、CNS 抑制、昏迷
- 支援治療

**甲醇/Ethylene glycol**：
- 症狀：類似乙醇；甲醇有視力問題；ethylene glycol 有腎衰竭/低鈣血症
- <span style="color:#f87171">**陰離子間隙代謝性酸中毒伴隨滲透壓間隙**</span>
- **解毒劑**：
  - <span style="color:#fb923c">**Fomepizole**</span>（首選）
  - <span style="color:#fb923c">**Ethanol**</span>（二線）
  - 考慮透析

### D. 鐵中毒

**症狀**：嘔吐、腹瀉、低血壓、嗜睡、陰離子間隙代謝性酸中毒、心源性休克、腎衰竭

**解毒劑**：<span style="color:#fb923c">**Deferoxamine**</span>

### E. 鉛中毒

#### 1. 定義
CDC 定義參考水平為 <span style="color:#60a5fa">**3.5 μg/dL**</span>

#### 2. 血鉛水平與症狀

| 血鉛水平 | 症狀 |
|---------|------|
| <span style="color:#60a5fa">**≧ 40 μg/dL**</span> | 易怒、嘔吐、腹痛、便秘、厭食 |
| <span style="color:#f87171">**≧ 70 μg/dL**</span> | 嗜睡、癲癇發作、昏迷 |

#### 3. 整合治療

| 血鉛水平 | 治療 |
|---------|------|
| 3.5-19 μg/dL | 環境暴露評估、減少暴露建議 |
| 20-44 μg/dL | 如上 + 鐵水平、CBC、腹部 X 光 |
| 45-69 μg/dL | 口服整合治療：<span style="color:#fb923c">**Succimer**</span> |
| ≧ 70 μg/dL | 住院整合治療：<span style="color:#fb923c">**Succimer + Edetate calcium disodium**</span> |

> ⚠️ <span style="color:#f87171">**Warning**</span>：不要將 edetate disodium 與 edetate calcium disodium 混淆；後者是正確的鉛中毒治療藥物

### F. Benzodiazepines

**解毒劑**：<span style="color:#fb923c">**Flumazenil**</span>

> ⚠️ <span style="color:#f87171">**注意**</span>：可能在有潛在癲癇傾向患者中誘發癲癇

### G. Tricyclic Antidepressants (TCAs)

**症狀**：Tachycardia、癲癇發作、譫妄、QRS 增寬（可能導致心室心律不整）、低血壓

**解毒劑**：
- <span style="color:#fb923c">**Sodium bicarbonate**</span>：QRS > 100 ms 時

### H. 類鴉片

**解毒劑**：<span style="color:#fb923c">**Naloxone**</span>

| 劑量 | 給藥途徑 |
|------|---------|
| 全逆轉：0.1 mg/kg（最大 2 mg） | IV/IO/IM/SUBQ |
| 1-2 mg | IN（使用完整塗藥器） |

> 📌 <span style="color:#60a5fa">**Clinical Pearl**</span>：Naloxone 作用時間短（20-90 分鐘），可能需要多次給藥

## IV. 去污染技術

### A. 活性炭

| 要點 | 說明 |
|------|------|
| **時機** | 攝入後 1 小時內最有效；延遲給藥對緩釋製劑可能有益 |
| **禁忌** | 未保護氣道、腐蝕性攝入、腸道被打斷、誤吸風險 |
| **不被吸收** | 鐵、醇類、鋰 |

### B. 全腸道灌洗

**適應症**：不能被活性炭結合的物質（鐵、含鉛異物、緩釋致命產品、藥物包裝）

**溶液**：Polyethylene glycol 電解質

**速率**：
| 年齡 | 速率 |
|------|------|
| 9 月-6 歲 | 500 mL/hr |
| 6-12 歲 | 1000 mL/hr |
| > 12 歲 | 1500-2000 mL/hr |

### C. 血液透析/血液灌流

**可能需要加強移除治療的情況**：
- <span style="color:#f87171">**水楊酸鹽、鋰、甲醇、ethylene glycol、丙戊酸、氨茶鹼**</span>

## V. 一般治療原則

### A. 癲癇發作

- <span style="color:#f87171">**一線**：Benzodiazepines</span>
- 二線：Barbiturates 或 Propofol
- <span style="color:#f87171">**Phenytoin 在毒素誘發癲癇中無作用**</span>

### B. 嚴重中毒和頑固性心肺衰竭

- 可能是 <span style="color:#60a5fa">**ECMO**</span> 的候選者，因為毒性作用是短暫的

### C. 意識改變

| 評估 | 內容 |
|------|------|
| D - 藥物 | Opiates、Sympathomimetics、Anticholinergics |
| I - 感染 | 敗血症、腦膜炎、腦炎 |
| M - 代謝 | 低血糖、電解質異常、尿毒症 |
| S - 結構 | 佔位性病變、中風 |

### D. 體溫異常

| 類型 | 常見原因 |
|------|---------|
| <span style="color:#f87171">**體溫過低**</span> | 酒精、β-受體阻斷劑、巴比妥鹽、類鴉片 |
| <span style="color:#f87171">**體溫過高**</span> | Anticholinergics、SSRis、MAIOs、擬交感神經藥物 |

## VI. 常見中毒實驗室診斷輔助

### A. 生命徵象異常與可能的毒物

| 生命徵象 | 可能毒物 |
|---------|---------|
| <span style="color:#f87171">**Bradycardia**</span> | β-受體阻斷劑、Ca channel blockers、Clonidine、Digoxin、Opioids |
| <span style="color:#60a5fa">**Tachycardia**</span> | Anticholinergics、Cocaine、Amphetamines、TCAs |
| <span style="color:#f87171">**Hypotension**</span> | TCAs、β-受體阻斷劑、Ca channel blockers、Opioids |
| <span style="color:#60a5fa">**Hypertension**</span> | Cocaine、Amphetamines、PCP、TCAs |

### B. 神經系統徵象與毒物

| 徵象 | 可能毒物 |
|------|---------|
| <span style="color:#60a5fa">**瞳孔縮小**</span> | Opioids、Organophosphates、Nicotine |
| <span style="color:#f87171">**瞳孔放大**</span> | Anticholinergics、Sympathomimetics、Cocaine |
| <span style="color:#60a5fa">**Nystagmus**</span> | Phenytoin、PCP、Barbiturates |
| <span style="color:#f87171">**癲癇發作**</span> | Isoniazid、TCAs、Bupropion、Lithium、Sympathomimetics |

### C. 特殊氣味

| 氣味 | 可能物質 |
|------|---------|
| 丙酮 | Isopropyl alcohol、Salicylates |
| 酒精 | Ethanol |
| 苦杏仁 | Cyanide |
| 大蒜 | Organophosphates、Arsenic |
| 冬青油 | Salicylates |
