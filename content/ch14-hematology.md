## 導讀摘要

本章節涵蓋小兒血液學的核心內容，包括：貧血（篩檢、評估與治療）、溶血性貧血（遺傳性球形紅血球症、G6PD 缺乏症、鐮刀型紅血球疾病）、凝血疾病（血友病、von Willebrand 病、維生素K缺乏）、血小板減少、免疫性血小板減少性紫斑（ITP）、血栓形成、新生兒血液學（生理性貧血、母胎嵌合）、造血系統疾病及化療原則。臨床重點包括：缺鐵性貧血的治療、鐮刀型紅血球疾病的急性併發症（疼痛危機、急性胸症候群、敗血症）、血友病的因子替代治療、ITP 的治療。

## I. 貧血（Anemia）

### A. 定義

<span style="color:#60a5fa">**貧血：血紅蛋白或紅血球比容積低於同年齡平均值 2 個標準差以上**</span>

### B. 年齡層血紅蛋白正常值

| 年齡 | Hb (g/dL) | MCV (fL) |
|------|-----------|-----------|
| 足月新生兒（臍帶血）| 14.5-22.5 | 95-115 |
| 1-3 個月 | 9.5-14.0 | 85-100 |
| 6 個月-2 歲 | 11.0-14.0 | 70-86 |
| 2-6 歲 | 11.5-14.5 | 77-95 |
| 6-12 歲 | 11.5-15.5 | 78-98 |
| 12-18 歲（男）| 13.0-16.0 | 78-100 |
| 12-18 歲（女）| 12.0-16.0 | 78-100 |

### C. 貧血的評估方法（Mentzler Index）

| 計算公式 | 結果判讀 |
|---------|---------|
| **MCV ÷ RBC** | >13：缺鐵性貧血（IDA）|
| | <13：海洋性貧血特徵 |

### D. 網狀紅血球指數（Reticulocyte Index）

| 數值 | 意義 |
|------|------|
| **>2%** | 紅血球生成正常的反應（如溶血、出血）|
| **<2%** | 低增生的貧血（生成不足）|

## II. 缺鐵性貧血（Iron Deficiency Anemia, IDA）

### A. 原因

- 鐵攝取不足（純母乳餵養而未補充鐵、偏食）
- 鐵吸收不良（Celiac 病、幽門螺旋桿菌感染）
- 慢性出血（牛奶蛋白過敏、潰痗性結腸炎）
- 早產（出生時鐵儲存不足）

### B. 治療

| 病情 | 治療 |
|------|------|
| **輕度（Hb 10-11 g/dL）** | <span style="color:#fb923c">**口服硫酸亞鐵 3-6 mg/kg/day Fe**</span> 分 2-3 次 |
| **中至重度（Hb < 10 g/dL）** | 同上，或考虑輸血（若有症狀）|
| **重度（Hb < 7 g/dL）或有心症狀** | <span style="color:#fb923c">**輸血（RBC 10-15 mL/kg）**</span> |

> 📌 治療後 1-2 週：自覺改善，Hb 應開始上升；完全恢復需 6-8 週；需繼續補充鐵劑直到 Hb 正常後 2-3 個月以補足儲存

### C. 預防

| 族群 | 建議 |
|------|------|
| **足月母乳餵養嬰兒** | 4 個月起每天補充 1 mg/kg 鐵直到攝入富鐵食物 |
| **早產兒** | 2 週起每天 2-4 mg/kg 鐵 |
| **所有嬰兒** | 6 個月起引入富鐵副食品（肉泥、鐵強化穀類）|

## III. 溶血性貧血（Hemolytic Anemia）

### A. 鑑別診斷流程

MCV 正常 + 網狀紅血球 ↑ + LDH ↑ + 游離胆紅素 ↑ + 觸珠蛋白 ↓

### B. 遺傳性球形紅血球症（Hereditary Spherocytosis）

| 項目 | 內容 |
|------|------|
| **遺傳** | AD；紅血球骨架蛋白（spectrin、ankyrin、protein 3）缺陷 |
| **實驗室發現** | MCHC ↑（>36 g/dL）、球形紅血球、網狀紅血球↑ |
| **治療** | 葉酸（1 mg/day）；嚴重者切脾（>10-12 歲）；嚴重貧血需輸血 |
| **圍手術期** | 肺炎球菌、腦膜炎球菌、流感嗜血桿菌疫苗 |

### C. G6PD 缺乏症

| 項目 | 內容 |
|------|------|
| **遺傳** | X 連鎖隱性；非洲、地中海、中東、亞洲常見 |
| **觸發因素** | 氧化壓力：感染、磺胺類、dapson、nitrofurantoin、萘（樟腦丸）、豆類 |
| **急性發作** | 溶血危機：黃疸、貧血、血紅素尿、腰痛 |
| **實驗室** | G6PD 酶活性↓；急性期後才準確（網狀紅血球階段結果偏高）|
| **治療** | 移除觸發因素；輸血（嚴重時）；補充葉酸 |

### D. 鐮刀型紅血球疾病（Sickle Cell Disease, SCD）

#### 1. 病因

- <span style="color:#c084fc">**HbS 基因突變**</span>（第6個密碼子Glu→Val）
- 純合子（HbSS）= Sickle cell anemia
- 雜合子（HbAS）= Sickle cell trait（無症狀）

#### 2. 急性併發症

| 併發症 | 表現 | 治療 |
|--------|------|------|
| **疼痛危機（疼痛危機）** | 骨骼/關節疼痛；可以是 mild 到 severe | 水分補充、<span style="color:#fb923c">**NSAIDs、opioids**</span> |
| **急性胸症候群（ACS）** | 胸痛、呼吸困難、發燒、缺氧 | <span style="color:#fb923c">**Exchange transfusion 或簡單輸血**</span>；住院 |
| **敗血症** | 發燒、症狀性菌血症（尤其 <span style="color:#c084fc">**S. pneumoniae**</span>、<span style="color:#c084fc">**H. influenzae**</span>） | <span style="color:#fb923c">**Ceftriaxone**</span> 立。即住院 |
| **脾臟扣押危機** | 左上腹痛、休克、嚴重貧血 | 輸血、住院 |
| **中風** | 突然神經缺陷 | <span style="color:#fb923c">**Exchange transfusion**</span> |

#### 3. 長期管理

| 治療 | 劑量/說明 |
|------|-----------|
| <span style="color:#fb923c">**Hydroxyurea**</span> | 增加 HbF；建議所有 HbSS 患者 |
| <span style="color:#fb923c">**Penicillin V**</span> | < 5 歲：125 mg bid；> 5 歲：250 mg bid；持續到 5 歲或更久 |
| <span style="color:#fb923c">**Vaccines**</span> | 肺炎球菌、腦膜炎球菌、流感疫苗 |
| **輸血** | 選擇性（慢性貧血、目標 Hb > 9-10）|

## IV. 凝血疾病

### A. 血友病（Hemophilia）

#### 1. 血友病 A（Factor VIII 缺乏）

| 項目 | 內容 |
|------|------|
| **遺傳** | X 連鎖隱性；男受影響 |
| **出血類型** | 關節（膝、肘、踝）、肌肉、深部組織、顱內（罕见但危及生命）|
| **實驗室** | aPTT ↑、正常 PT、血小板正常、Factor VIII ↓ |
| **嚴重度** | Severe（<1%）→ 中度（1-5%）→ 輕度（5-40%）|

#### 2. 治療

| 治療類型 | 藥物 |
|---------|------|
| **On-demand** | <span style="color:#fb923c">**Recombinant Factor VIII**</span> 劑量視體重和受影響因子水平 |
| **預防性** | 每周 3-4 次输注重組 Factor VIII（25-50 U/kg）|
| **Tranexamic acid** | 口腔出血時可作為輔助 |
| **Desmopressin (DDAVP)** | 輕度血友病 A（提升內源性 Factor VIII）|

> 📌 <span style="color:#60a5fa">**預防性因子替代**</span> 可減少關節損傷和出血頻率

### B. von Willebrand 病（vWD）

| 項目 | 內容 |
|------|------|
| **遺傳** | AD（多數類型 1）；最常見的遺傳性凝血病 |
| **表現** | 黏膜出血（鼻出血、牙銀）、月經過多 |
| **實驗室** | vWF Ag ↓、vWF activity（Ristocetin cofactor）↓、可能 Factor VIII ↓ |
| **治療** | <span style="color:#fb923c">**Desmopressin（DDAVP）**</span>（類型 1）；<span style="color:#fb923c">**vWF/Factor VIII concentrate（Humate-P）**</span>（嚴重時）|

### C. 維生素K缺乏

| 項目 | 內容 |
|------|------|
| **原因** | 吸收不良（膽道閉鎖、瀉泄）、長期抗生素、母親抗癲癇藥（苯妥英）|
| **出血** | 出生後 1 週內（早發）、遲發（2-12 週，純母乳餵養）|
| **實驗室** | PT ↑↑、aPTT ↑；Factor II、VII、IX、X ↓ |
| **治療** | <span style="color:#fb923c">**維生素 K1（Phytonadione）**</span> 1-2 mg IM/SC；嚴重時 FF P |

## V. 血小板減少（Thrombocytopenia）

### A. 免疫性血小板減少性紫斑（ITP）

| 項目 | 內容 |
|------|------|
| **原因** | 自體免疫——抗血小板抗體導致血小板破壞 |
| **表現** | 瘀點、紫斑、黏膜出血（鼻出血、牙銀出血）|
| **實驗室** | Platelets < 100,000；其他細胞系正常；骨髓檢查（若不典型）|
| **治療** | |

| 病情 | 治療 |
|------|------|
| **輕度（血小板 >30k，無出血）** | 觀察 |
| **中至重度（有出血）** | <span style="color:#fb923c">**Prednisone 2-4 mg/kg/day**</span> 或 <span style="color:#fb923c">**IVIG 0.8-1 g/kg**</span> |
| **危及生命（< 10k 或 嚴重出出血）** | <span style="color:#fb923c">**Methylprednisolone**</span> + IVIG + platelet transfusion |
| **慢性 ITP（>12 個月）** | <span style="color:#fb923c">**Rituximab**</span>、Splenectomy（最後手段）|

> ⚠️ ITP 兒童應避免 Aspirin 和 NSAIDs（增加出血風險）

### B. 新生兒血小板減少

| 原因 | 說明 |
|------|------|
| **免疫性（NAIT）** | 母體抗血小板抗體穿過胎盤；最嚴重型 < 30k |
| **敗血症** | 彌散性血管內凝固（DIC）|
| **先天性（Kasabach-Merritt）** | 血管瘤消耗血小板 |

## VI. 血栓形成（Thrombosis）

### A. 小兒血栓風險因素

- 中央靜脈導管（最常見）
- 先天性心臟病
- 惡性腫瘤
- 遺傳性血栓體質（Factor V Leiden、Protein C/S 缺乏、Antithrombin 缺乏）
- 口服避孕藥

### B. 治療

| 病情 | 治療 |
|------|------|
| **靜脈血栓（淺層）** | <span style="color:#fb923c">**LMWH（Enoxaparin）**</span> 1 mg/kg SC q12h |
| **靜脈血栓（深層）** | <span style="color:#fb923c">**LMWH**</span> 或 <span style="color:#fb923c">**Warfarin**</span> |
| **肺栓塞** | <span style="color:#fb923c">**LMWH 或 UFH + Warfarin**</span>（重疊期後維持）|

### C. 遺傳性血栓體質

| 疾病 | 實驗室發現 |
|------|-----------|
| **Factor V Leiden** | APC resistance；Factor V 基因突變 |
| **Protein C 缺乏** | Protein C 活性 ↓ |
| **Protein S 缺乏** | Protein S 抗原或活性 ↓ |
| **Antithrombin 缺乏** | Antithrombin 活性 ↓ |

## VII. 新生兒血液學

### A. 生理性貧血（Physiologic Anemia of Infancy）

| 時機 | 說明 |
|------|------|
| **足月兒** | Hb 在 8-12 週時降至最低（~10-11 g/dL）；是正常現象 |
| **早產兒** | 下降更明顯（6-8 週可達 7-9 g/dL）；與 EPO 產生延遲有關 |

### B. 母胎嵌合（Maternal-Fetal Transfusion）

| 類型 | 說明 |
|------|------|
| **慢性** | 微量（< 30 mL）；影響小 |
| **急性大量** | 突然大量傳输（> 30 mL）；可致胎兒嚴重貧血或死亡 |

### C. 新生兒免疫性血小板減少（NAIT）

- 母體抗 HPA-1a 或其他血小板抗原抗體穿過胎盤
- 血小板嚴重減少（< 30k）- 腦室內出血風險高
- <span style="color:#fb923c">**IVIG + 血小板輸注**</span>（母親或隨機捐獻者）

## VIII. 化療原則（化療毒性）

### A. 骨髓抑制（Marrow Suppression）

| 毒性 | 說明 |
|------|------|
| **貧血** | Hb 下降；可能需要輸血（Hb < 7-8 g/dL）|
| **血小板減少** | 血小板 < 20k 或有出血 → <span style="color:#fb923c">**Platelet transfusion**</span> |
| **中性球減少** | 發燒時立即住院 + 廣效抗生素（< 500 ANC）|

### B. 化療常见急性毒性

| 毒性 | 常見化療藥 |
|------|-----------|
| **禿髮** | 所有靜脈化療 |
| **口腔炎** | Methotrexate、5-FU、Cyclophosphamide |
| **腹瀉** | 5-FU、Irinotecan |
| **心臟毒性** | Anthracyclines（Doxorubicin）|
| **腎臟毒性** | Cisplatin（順鉑）、Methotrexate（高劑量）|
| **肺毒性** | Bleomycin、Busulfan |
| **神經毒性** | Vincristine（末梢神經病變）、Cisplatin（聽神經）|
| **出血性膀胱炎** | Cyclophosphamide、Ifosfamide（需要 Mesna）|

## IX. 造血系統癌症

### A. 急性淋巴性白血病（ALL）

| 項目 | 內容 |
|------|------|
| **分類** | B-ALL（85%）、T-ALL（15%）|
| **表現** | 骨痛、蒼白、發燒、出血、淋巴結/肝脾腫大 |
| **實驗室** | Anemia、thrombocytopenia、high WBC（有時）、骨髓內 >25% blasts |
| **治療** | 化療（Vincristine、Dexamethasone、L-Asparaginase、Anthracycline）；CNS 預防（MTX）；幹細胞移植（高風險）|

### B. 急性骨髓性白血病（AML）

| 項目 | 內容 |
|------|------|
| **表現** | 發燒、出血、骨痛、淋巴結腫大（比 ALL 少）|
| **APL（急性前骨髓性白血病）** | ATRA + Arsenic trioxide（全反式維 A 酸）|
| **治療** | 化療（Cytarabine + Anthracycline）；APL 特殊方案 |

### C. 淋巴瘤（Lymphoma）

| 類型 | 表現 | 治療 |
|------|------|------|
| **Hodgkin Lymphoma** | 無痛性淋巴結腫大、發燒、夜間盜汗 | ABVD 化療（Adriamycin、Bleomycin、Vinblastine、Dacarbazine）|
| **Non-Hodgkin Lymphoma** | Burkitt（腹部腫塊、WW芽）、淋巴結或骨髓 | 化療（CO프）|

## X. 鐵過載（Iron Overload）

### A. 原因

- 依賴輸血的慢性貧血（海洋性貧血、鐮刀型、BMA）
- 腸道吸收過多（原發性血色沉著症）

### B. 治療

<span style="color:#fb923c">**Deferasirox**</span> 或 <span style="color:#fb923c">**Deferoxamine**</span>（整合治療）

目標：Ferritin 維持 500-1000 ng/mL
