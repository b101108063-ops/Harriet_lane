> **章節導讀摘要**
> 本章節為 Harriet Lane Handbook 的藥物劑量專章，提供兒科用藥的核心參考資訊。重點包含：美國聯合委員會（The Joint Commission）禁止使用的處方縮寫清單，以減少給藥錯誤；藥物妊娠與哺乳安全性分類系統；體表面積（BSA）計算圖表與 Mosteller 公式；CYP450 酶系統的誘導劑與抑制劑表格；以及常見藥物的詳細劑量、禁忌、副作用與藥物交互作用資訊。由於兒科劑量資料往往不完整，使用前務必查閱最新仿單與相關文獻。

## I. 給讀者的重要說明

作者已竭盡所能確認劑量與醫療內容之準確性。然而，由於兒科劑量資料的不完整性，許多藥物劑量在本書出版後可能有所修正。建議讀者在使用前查閱產品資訊及已發表的文獻，特別是較新藥物的劑量異動資訊。

**FDA 兒科藥物資訊來源：**

- New Pediatric Labeling Information：<https://www.fda.gov/science-research/pediatrics/pediatric-labeling-changes>
- Drug Safety Report Updates：<https://www.fda.gov/advisory-committees/pediatric-advisory-committee/pediatric-advisory-recommendations-and-updates>
- Ongoing and completed clinical research study information：<https://www.clinicaltrials.gov/>

## II. 美國聯合委員會「禁止使用」縮寫清單

為防止處方錯誤，以下縮寫應避免使用：

| 禁止使用 | 潛在問題 | 建議替代 |
|----------|----------|----------|
| <span style="color:#f87171">U（unit）</span> | 易與數字「0」、「4」或「cc」混淆 | 寫「unit」 |
| <span style="color:#f87171">IU（International Unit）</span> | 易與 IV（靜脈注射）或數字「10」混淆 | 寫「International Unit」 |
| <span style="color:#f87171">Q.D., QD, q.d., qd</span> | Q 後的句點易被誤認為「I」，O 被誤認為「I」 | 寫「daily」 |
| <span style="color:#f87171">Q.O.D., QOD, q.o.d, qod</span> | 與 Q.D. 相互混淆 | 寫「every other day」 |
| <span style="color:#f87171">Trailing zero（X.0 mg）</span> | 小數點遺漏 | 寫「X mg」 |
| <span style="color:#f87171">(.X mg)</span> | 缺少前導零，小數點遺漏 | 寫「0.X mg」 |
| <span style="color:#f87171">MS</span> | 可指 morphine sulfate 或 magnesium sulfate | 寫「morphine sulfate」 |
| <span style="color:#f87171">MSO4</span> | 與 MgSO4 混淆 | 寫「magnesium sulfate」 |
| <span style="color:#f87171">Mg</span> | 易誤認為 mg（毫克），導致千倍劑量錯誤 | 寫「mCg」或「micrograms」 |

**額外建議避免之縮寫：**

| 禁止使用 | 潛在問題 | 建議替代 |
|----------|----------|----------|
| <span style="color:#f87171">>（大於）</span> | 易被誤讀為數字「7」或字母「L」 | 寫「greater than」 |
| <span style="color:#f87171"><（小於）</span> | 與大於符號混淆 | 寫「less than」 |
| 藥物縮寫 | 多種藥物有相似縮寫，易生誤解 | 寫出藥物全名 |
| Apothecary units | 許多從業人員不熟悉 | 使用公制單位 |
| <span style="color:#f87171">@</span> | 易被誤認為數字「2」 | 寫「at」 |
| <span style="color:#f87171">cc</span> | 易與 U（units）混淆（書寫不良時） | 寫「mL」 |

## III. 藥物條目範例說明

以下以 <span style="color:#fb923c">Allopurinol</span> 說明藥物條目之組成部分：

**特殊標註說明：**

- **Pharmacogenomics**：表示需評估患者基因型或遺傳多態性對劑量、藥物選擇或藥理效果的影響
- **Liver**：肝功能不全時需謹慎或調整劑量
- **Kidney**：腎功能不全時需謹慎或調整劑量（見第31章）
- **Breast**：哺乳分類（見說明）
- **Pregnancy**：妊娠分類（見說明）

**ALLOPURINOL 範例**

<span style="color:#fb923c">Allopurinol</span>（Zyloprim, Aloprim）

<span style="color:#60a5fa">分類：尿酸降低劑、黃嘌呤氧化酶抑制劑</span>

**劑型：**
- 口服錠：<span style="color:#34d399">100, 300 mg</span>
- 口服懸浮液：<span style="color:#34d399">20 mg/mL</span>
- 注射劑：<span style="color:#34d399">500 mg</span>

**劑量（兒童）：**
- 口服：<span style="color:#34d399">10 mg/kg/24 hr PO ÷ BID–QID</span>；最大劑量：<span style="color:#34d399">800 mg/24 hr</span>
- 注射：<span style="color:#34d399">200 mg/m²/24 hr IV ÷ Q6–12 hr</span>；最大劑量：<span style="color:#34d399">600 mg/24 hr</span>

**劑量（成人）：**
- 口服：<span style="color:#34d399">200–800 mg/24 hr PO ÷ BID–TID</span>
- 注射：<span style="color:#34d399">200–400 mg/m²/24 hr IV ÷ Q6–12 hr</span>；最大劑量：<span style="color:#34d399">600 mg/24 hr</span>

<span style="color:#f87171">**禁忌與警告：**</span>

- <span style="color:#f87171">出現皮疹或過敏反應跡象時應立即停藥</span>
- <span style="color:#f87171">HLA-B*58:01 基因型患者應避免使用</span>，因此類患者發生嚴重皮膚不良反應（如 Stevens-Johnson 症候群、TEN）的風險顯著
- <span style="color:#f87171">禁止與 didanosine 合併使用</span>，會增加 didanosine 毒性風險

**副作用：** 皮疹、神經炎、肝毒性、腎功能損害、胃腸障礙、骨髓抑制、嗜睡

**特殊考量：** 腎功能不全時需調整劑量；須維持足夠尿量並保持尿液鹼性

## V. 妊娠安全性分類

| 分類 | 說明 |
|------|------|
| <span style="color:#34d399">A</span> | 對孕婦進行的充分研究未顯示對胎兒有風險 |
| <span style="color:#34d399">B</span> | 動物研究未顯示胎兒風險，但人體研究不足；或動物研究顯示不良影響，但人體研究未顯示風險 |
| <span style="color:#fb923c">C</span> | 動物研究顯示對胎兒有不良影響，但人體研究不足；或無動物或人體研究資料 |
| <span style="color:#f87171">D</span> | 有人體胎兒風險的證據，但孕婦使用之潛在效益可能可接受 |
| <span style="color:#f87171">X</span> | 動物或人體研究顯示胎兒異常或不良反應；風險明顯大於任何可能的效益 |

## VII. CYP450 酶系統——誘導劑與抑制劑

**TABLE 30.1 CYP450 系統誘導劑與抑制劑範例**

| 異構酶 | 受質（以此酶代謝之藥物） | 抑制劑 | 誘導劑 |
|--------|------------------------|--------|--------|
| <span style="color:#60a5fa">CYP1A2</span> | Caffeine, theophylline, estradiol, propranolol | Cimetidine, quinolones, fluvoxamine, ketoconazole | Carbamazepine, smoking, phenobarbital, rifampin |
| <span style="color:#60a5fa">CYP2B6</span> | Cyclophosphamide, efavirenz, propofol | Paroxetine, sertraline | Carbamazepine, (fos)phenytoin, phenobarbital, rifampin |
| <span style="color:#60a5fa">CYP2C9/10</span> | Warfarin, phenytoin, tolbutamide, fluoxetine | Amiodarone, fluconazole, ibuprofen, nicardipine | Carbamazepine, (fos)phenytoin, rifampin |
| <span style="color:#60a5fa">CYP2C19</span> | Diazepam, PPIs, phenytoin, sertraline | Cimetidine, fluvoxamine, fluconazole, isoniazid, PPIs | Carbamazepine, (fos)phenytoin, rifampin |
| <span style="color:#60a5fa">CYP2D6</span> | Codeine, haloperidol, dextromethorphan, tricyclic antidepressants, metoprolol | Chlorpromazine, quinidine, ritonavir, fluoxetine, amiodarone | Carbamazepine, (fos)phenytoin |
| <span style="color:#60a5fa">CYP3A4</span> | Amlodipine, aripiprazole, fentanyl, nifedipine, cyclosporine, carbamazepine, midazolam, ritonavir | Erythromycin, cimetidine, clarithromycin, ketoconazole, ritonavir | Rifampin, (fos)phenytoin, carbamazepine, dexamethasone |

**重要提醒：** 當某異構酶的抑制劑存在時，以此酶代謝的藥物血清濃度會**增加**；當誘導劑存在時，血清濃度會**降低**。

## VIII. 常見藥物劑量要點

### <span style="color:#fb923c">Acetaminophen</span>（Tylenol, Tempra）

<span style="color:#60a5fa">分類：止痛、退燒藥</span>

**口服/肛門給藥（24小時內不超過5次）：**
- 新生兒：<span style="color:#34d399">10-15 mg/kg/dose PO/PR Q4-6 hr</span>；最大：<span style="color:#34d399">75 mg/kg/24 hr</span>
- 兒童：<span style="color:#34d399">10-15 mg/kg/dose PO/PR Q4-6 hr</span>；最大：<span style="color:#34d399">75 mg/kg/24 hr 或 4 g/24 hr</span>
- 成人：<span style="color:#34d399">325-650 mg/dose</span>；最大：<span style="color:#34d399">4 g/24 hr</span>

**靜脈注射：**
- 新生兒（≥32週胎齡）：<span style="color:#34d399">12.5 mg/kg/dose Q6 hr IV</span>；最大：<span style="color:#34d399">50 mg/kg/24 hr</span>
- 嬰兒（≥29天至<2歲）：<span style="color:#34d399">15 mg/kg/dose Q6 hr IV</span>；最大：<span style="color:#34d399">60 mg/kg/24 hr</span>
- 兒童（≥2-12歲）及青少年/成人：<span style="color:#34d399">15 mg/kg/dose Q6 hr IV</span> 或 <span style="color:#34d399">12.5 mg/kg/dose Q4 hr IV</span>

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">不具抗發炎活性</span>
- <span style="color:#f87171">G6PD 缺乏症患者應謹慎使用</span>
- <span style="color:#f87171">24小時內不超過5次給藥</span>
- 嚴重皮膚反應（如 SJS、TEN）罕見報告

### <span style="color:#fb923c">Acetazolamide</span>（Diamox）

<span style="color:#60a5fa">分類：碳酸酐酶抑制劑、利尿劑</span>

**劑型：** 錠劑 <span style="color:#34d399">125, 250 mg</span>；膠囊 <span style="color:#34d399">500 mg</span>

**劑量：**
- 利尿：<span style="color:#34d399">5 mg/kg/dose PO 每天一次或隔天一次</span>
- 青光眼（兒童）：<span style="color:#34d399">8-30 mg/kg/24 hr ÷ Q6-8 hr PO</span>；最大：<span style="color:#34d399">1000 mg/24 hr</span>
- 癲癇：<span style="color:#34d399">8-30 mg/kg/24 hr ÷ Q6-12 hr PO</span>；最大：<span style="color:#34d399">1 g/24 hr</span>

<span style="color:#f87171">**禁忌：**</span>
- <span style="color:#f87171">肝功能衰竭</span>
- <span style="color:#f87171">嚴重腎功能衰竭（GFR <10 mL/min）</span>
- <span style="color:#f87171">對磺胺類過敏</span>

### <span style="color:#fb923c">Acetylcysteine</span>（Acetadote, Mucomyst）

<span style="color:#60a5fa">分類：黏液溶解劑、acetaminophen 中毒解毒劑</span>

**Acetaminophen 中毒：**
- 口服：<span style="color:#34d399">140 mg/kg（最大 15 g/dose）</span> 首次給予，之後 <span style="color:#34d399">70 mg/kg/dose（最大 7.5 g/dose）Q4 hr</span>，共 17 次
- 靜脈：<span style="color:#34d399">150 mg/kg（最大 15 g）</span> 稀釋於 D5W 滴注 60 分鐘，續以 <span style="color:#34d399">50 mg/kg（最大 5 g）</span> 滴注 4 小時，再以 <span style="color:#34d399">100 mg/kg（最大 10 g）</span> 滴注 16 小時

**霧化吸入：**
- 嬰兒：<span style="color:#34d399">1-2 mL 20% 溶液</span> 或 <span style="color:#34d399">2-4 mL 10% 溶液</span>；TID-QID
- 兒童：<span style="color:#34d399">3-5 mL 20% 溶液</span> 或 <span style="color:#34d399">6-10 mL 10% 溶液</span>；TID-QID

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">氣喘患者應謹慎使用</span>，可能誘發支氣管痙攣
- 兒童靜脈注射曾有嚴重過敏反應報告

### <span style="color:#fb923c">Acyclovir</span>（Zovirax）

<span style="color:#60a5fa">分類：抗病毒藥</span>

**新生兒（出生至3個月）HSV 與 HSV 腦炎：**
- <34週胎齡：<span style="color:#34d399">40 mg/kg/24 hr ÷ Q12 hr IV</span>
- ≥34週胎齡：<span style="color:#34d399">60 mg/kg/24 hr ÷ Q8 hr IV</span>

**HSV 腦炎（3個月至12歲）：**
- <span style="color:#34d399">60 mg/kg/24 hr ÷ Q8 hr IV</span>

**免疫功能正常之帶狀皰疹（所有年齡）：**
- 靜脈：<span style="color:#34d399">30 mg/kg/24 hr 或 1500 mg/m²/24 hr ÷ Q8 hr IV</span>

**水痘（≥2歲）：**
- 口服：<span style="color:#34d399">80 mg/kg/24 hr ÷ QID × 5天</span>；最大：<span style="color:#34d399">3200 mg/24 hr</span>

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">腎功能或脫水患者應謹慎使用</span>
- <span style="color:#f87171">須緩慢滴注（1小時）並補充水分</span>，以防止腎小管結晶
- 口服吸收率不佳（15-30%），可考慮使用 valacyclovir 或 famciclovir

### <span style="color:#fb923c">Adenosine</span>（Adenocard）

<span style="color:#60a5fa">分類：抗心律不整藥</span>

**陣發性室上心搏過速（SVT）：**
- 新生兒：<span style="color:#34d399">0.05-0.1 mg/kg rapid IV push</span>；最大單次：<span style="color:#34d399">0.3 mg/kg</span>
- 兒童：<span style="color:#34d399">0.1 mg/kg（初始最大 6 mg）</span> rapid IV/IO push；必要時每2分鐘增加 <span style="color:#34d399">0.2 mg/kg</span>
- 青少年及成人≥50kg：<span style="color:#34d399">6 mg rapid IV push</span>；必要時 <span style="color:#34d399">12 mg</span>

<span style="color:#f87171">**禁忌：**</span>
- <span style="color:#f87171">第二度或第三度房室傳導阻滯</span>
- <span style="color:#f87171">病竇症候群（無放置節律器者）</span>

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">氣喘患者可能誘發支氣管收縮</span>
- 半衰期 <10 秒

### <span style="color:#fb923c">Albuterol</span>（ProAir, Ventolin）

<span style="color:#60a5fa">分類：β2 腎上腺素受體激動劑</span>

**霧化給藥：**
- <1歲：<span style="color:#34d399">0.05-0.15 mg/kg/dose Q4-6 hr</span>
- 1-5歲：<span style="color:#34d399">1.25-2.5 mg/dose Q4-6 hr</span>
- 5-12歲：<span style="color:#34d399">2.5 mg/dose Q4-6 hr</span>
- >12歲：<span style="color:#34d399">2.5-5 mg/dose Q4-8 hr</span>

**定量吸入器（HFA）：**
- <span style="color:#34d399">2 puffs（90 mcg/puff）Q4-6 hr PRN</span>

**運動誘發性支氣管痙攣：**
- 吸入前15-30分鐘給予：<span style="color:#34d399">2 puffs</span>

<span style="color:#fb923c">**口服制劑不建議使用**，因副作用增加且療效較吸入制劑差</span>

### <span style="color:#fb923c">Amoxicillin</span>

<span style="color:#60a5fa">分類：青黴素類抗生素</span>

**常見劑量：**
- <span style="color:#34d399">20-40 mg/kg/24 hr ÷ TID</span>；最大：<span style="color:#34d399">2500 mg/24 hr</span>
- 中耳炎：<span style="color:#34d399">80-90 mg/kg/24 hr ÷ BID-TID</span>

**Clavulanate 複方（Augmentin）：**
- <span style="color:#34d399">20-40 mg/kg/24 hr（以 amoxicillin 計）÷ TID</span>

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">青黴素過敏者禁止使用</span>
- <span style="color:#f87171">肝功能異常患者慎用</span>

### <span style="color:#fb923c">Azithromycin</span>（Zithromax）

<span style="color:#60a5fa">分類：大環內酯類抗生素</span>

**常用劑量：**
- <span style="color:#34d399">10 mg/kg PO 第1天（最大 500 mg）</span>，之後 <span style="color:#34d399">5 mg/kg Q24 hr × 4天</span>（最大 250 mg/天）
- 兒童常用：<span style="color:#34d399">10 mg/kg/dose Q24 hr × 3天</span> 或 <span style="color:#34d399">10 mg/kg/dose Q24 hr × 5天</span>

**預防性使用（旅行者腹瀉）：**
- <span style="color:#34d399">10 mg/kg/dose Q24 hr × 3-5天</span>；最大：<span style="color:#34d399">500 mg/天</span>

<span style="color:#fb923c">**注意：**</span> 口服吸收不受食物影響；與 antacid 間隔2小時

### <span style="color:#fb923c">Ciprofloxacin</span>（Cipro）

<span style="color:#60a5fa">分類：fluoroquinolone 抗生素</span>

**常用劑量：**
- <span style="color:#34d399">10-20 mg/kg/24 hr ÷ BID</span>；最大：<span style="color:#34d399">400 mg/24 hr</span>

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">18歲以下兒童僅在無其他替代藥物時使用</span>
- <span style="color:#f87171">可能影響軟骨發育</span>
- <span style="color:#f87171">癲癇患者慎用</span>

### <span style="color:#fb923c">Dexamethasone</span>

<span style="color:#60a5fa">分類：皮質類固醇</span>

**哮吼（Croup）：**
- <span style="color:#34d399">0.6 mg/kg/dose PO/IM（最大 16 mg）</span> 單次給予

**腦水腫：**
- <span style="color:#34d399">0.05-0.1 mg/kg/dose Q6 hr</span>

**眩暈症：**
- <span style="color:#34d399">0.3-0.6 mg/kg/dose Q6 hr</span>

<span style="color:#fb923c">**注意：**</span> 吸入性皮質類固醇為哮喘主要用藥；系統性使用需监测血糖、血壓

### <span style="color:#fb923c">Diazepam</span>（Valium）

<span style="color:#60a5fa">分類：苯二氮平類鎮靜劑</span>

**癲癇重積狀態：**
- 兒童：<span style="color:#34d399">0.1-0.3 mg/kg/dose IV</span>；最大：<span style="color:#34d399">10 mg/dose</span>
- 成人：<span style="color:#34d399">5-10 mg/dose IV</span>

**肌肉痙攣：**
- <span style="color:#34d399">0.04-0.2 mg/kg/dose Q2-4 hr IV/IM</span>

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">靜脈注射須緩慢（1-2 mg/min）</span>
- <span style="color:#f87171">早產兒、新生兒禁止靜脈快速注射</span>

### <span style="color:#fb923c">Epinephrine</span>（Adrenaline）

<span style="color:#60a5fa">分類：腎上腺素、受體激動劑</span>

**過敏性休克：**
- <span style="color:#34d399">0.01 mg/kg IM（最大劑量 0.3-0.5 mg）</span>
- 必要時每5-15分鐘重複

**心肺復甦：**
- <span style="color:#34d399">0.01 mg/kg IV/IO</span>；最大：<span style="color:#34d399">1 mg/dose</span>

<span style="color:#fb923c">**注意：**</span> EpiPen 劑量為 <span style="color:#34d399">0.3 mg IM</span>（≥30kg）或 <span style="color:#34d399">0.15 mg IM</span>（15-30kg）

### <span style="color:#fb923c">Ibuprofen</span>（Advil, Motrin）

<span style="color:#60a5fa">分類：NSAID、退燒止痛藥</span>

**退燒、止痛：**
- <span style="color:#34d399">5-10 mg/kg/dose Q6-8 hr PO</span>；最大：<span style="color:#34d399">40 mg/kg/24 hr</span>

**關節炎：**
- <span style="color:#34d399">30-40 mg/kg/24 hr ÷ TID-QID PO</span>；最大：<span style="color:#34d399">2400 mg/24 hr</span>

<span style="color:#f87171">**禁忌：**</span>
- <span style="color:#f87171">活動性胃腸道出血</span>
- <span style="color:#f87171">對 NSAID 過敏</span>
- <span style="color:#f87171">腎功能不全</span>

### <span style="color:#fb923c">Prednisone / Prednisolone</span>

<span style="color:#60a5fa">分類：皮質類固醇</span>

**哮喘急性發作：**
- <span style="color:#34d399">1-2 mg/kg/24 hr ÷ BID PO</span>；最大：<span style="color:#34d399">60 mg/24 hr</span>

**腎病症候群：**
- <span style="color:#34d399">2 mg/kg/24 hr ÷ BID PO</span>；最大：<span style="color:#34d399">60 mg/24 hr</span>

**急性發作劑量：**
- <span style="color:#34d399">1-2 mg/kg/dose</span>；最大：<span style="color:#34d399">60-80 mg/dose</span>

<span style="color:#fb923c">**注意：**</span> 長期使用需逐漸減量；监测血糖、血壓、骨密度

### <span style="color:#fb923c">Vancomycin</span>

<span style="color:#60a5fa">分類：糖肽類抗生素</span>

**劑量（需進行血中濃度監測）：**
- <span style="color:#34d399">15 mg/kg/dose Q6 hr IV</span>（目標 trough 15-20 mcg/mL）
- 嚴重感染：<span style="color:#34d399">20 mg/kg/dose Q8-12 hr IV</span>

<span style="color:#f87171">**警告：**</span>
- <span style="color:#f87171">須監測血中濃度（trough & peak）</span>
- <span style="color:#f87171">Red man syndrome**：輸注速率過快可引起組胺釋放</span>
- <span style="color:#f87171">腎毒性與耳毒性</span>
- 滴注速率不超過 <span style="color:#34d399">10 mg/min</span>
