## 導讀摘要

本章節涵蓋創傷評估與處理的核心原則：

- <span style="color:#60a5fa">**創傷初步評估 ABCDE**</span>：Airway、Breathing、Circulation、Disability、Exposure
- <span style="color:#60a5fa">**創傷嚴重程度評估**</span>：GCS 分數、意識狀態、瞳孔變化
- <span style="color:#60a5fa">**特殊創傷管理**</span>：頭部創傷、頸椎影像、子宮外孕、骨盆骨折
- <span style="color:#60a5fa">**牙科創傷處理**</span>：牙齒脫落的緊急處理、再植步驟
- <span style="color:#60a5fa">**咬傷與燒傷**</span>：動物咬傷感染預防、燒傷面積計算、液體復甦

> ⚠️ <span style="color:#f87171">**Clinical Warning**</span>：兒童頭部創傷 GCS ≦ 14 或有任何意識狀態改變時需要考慮 CT 影像。

---

## I. 創傷評估組成部分

### A. 初步評估（Primary Survey）

創傷初步評估包含 **ABCDE**：<span style="color:#60a5fa">**Airway、Breathing、Circulation、Disability、Exposure**</span>

#### 1. 氣道評估（Airway）

- 患者能否自行維持氣道？需考慮神經狀態
- 氣道是否通暢？是否有上呼吸道阻塞或 stridor？
- 是否有頭/頸部損傷使氣管插管困難？
- 確保評估和管理氣道時維持頸椎穩定
- 困難氣道需有備援：呼叫麻醉科或重症監護醫師

#### 2. 呼吸評估（Breathing）

- 是否有可介入的影響氧合/通氣過程（如出血性、阻塞性、壓迫性）
- 是否有張力性氣胸或大量血胸
- 患者如果無法自主呼吸，是否優化了甪-閥-面罩通氣技術？
- 確認良好的面罩密封、正確的患者姿勢、適當的呼吸率和容量、對稱胸部起伏、End-tidal CO₂ 監測

#### 3. 循環評估（Circulation）

- 患者是否有活動性出血？快速識別和控制外部出血
- 是否有心包填塞徵象（頸靜脈怒張、心音偏遠、脈壓降低）？
- 評估休克：<span style="color:#f87171">**低血壓、tachycardia、意識改變、尿量減少**</span>
- <span style="color:#f87171">**Tachycardia 可能是早期休克的唯一異常生命徵象**</span>
- 需要大容量復甦時，考慮早期啟動大量輸血方案
- 大量液體復甦不能替代對受傷患者外部出血的快速控制

#### 4. 神經狀態評估（Disability）

- 評估瞳孔大小、對稱性、反應性
- 計算 <span style="color:#60a5fa">**Glasgow Coma Scale（見 CH01）**</span>："插管當 GCS < 8"
- 創傷機轉（如高速車禍伴隨創傷性腦損傷、重大燒傷）
- 是否需要快速止痛和/或鎮靜？

#### 5. 暴露（Exposure）

- 完全暴露皮膚進行徹底評估
- 清除有害碎屑和衣物
- 是否可能有相關的藥物過量或藥物中毒？

> 📌 <span style="color:#60a5fa">**Note**</span>：美國外科學院發展的高級創傷生命支持（ATLS）算法支持優先快速評估和治療氣道及呼吸問題。美國心臟協會兒科高級生命支持算法使用 CAB 順序（見 CH01）。

### B. 次級評估（Secondary Survey）

創傷次級評估包括全身詳細檢查：

| 區域 | 檢查重點 |
|------|---------|
| **頭部** | 头皮裂傷、血腫、腫脹；顱骨凹陷/變形；熊貓眼（眼眶底骨折）；面部/鼻骨變形；GCS 評估 |
| **眼睛** | 瞳孔大小、對稱性、反應性；眼球破裂、眼前房出血 |
| **耳朵** | 血鼓室、CSF 漏；Battle's sign（巖骨骨折） |
| **胸部** | 鎖骨變形；不對稱呼吸音；連枷胸；肋骨骨折/變形 |
| **腹部/骨盆** | 壓痛、膨隆、瘀傷（安全帶徵）；骶髂疼痛；骨盆不穩定 |
| **頸部** | 頸椎壓痛或變形；氣管偏移；頸靜脈怒張；捻髮音 |
| **背部** | 穩定頸椎並 log-roll 翻身檢查；椎骨台階；直腸張力 |
| **四肢** | 變形、開放/閉合骨折、脫臼；血管神經評估；骨筋膜室症候群評估 |

### C. 緊急實驗室檢查

| 檢查項目 | 臨床意義 |
|---------|---------|
| <span style="color:#60a5fa">**血紅蛋白、血氣、乳酸、血糖、電解質**</span> | Critical care labs |
| <span style="color:#60a5fa">**凝血功能（PT、aPTT、INR、纖維蛋白原）**</span> | 手術規劃 |
| <span style="color:#60a5fa">**血型及交叉配對**</span> | 預期的手術干預 |
| <span style="color:#60a5fa">**乳酸**</span> | 升高提示組織灌註不良、器官/血管損傷、內部出血 |
| <span style="color:#60a5fa">**尿液分析**</span> | 血尿可能提示腎臟、泌尿系統或骨盆損傷 |
| <span style="color:#60a5fa">**肌酐、BUN、肝轉氨酶、胰澱粉酶**</span> | 評估腎/肝/胰損傷 |
| <span style="color:#60a5fa">**CBC**</span> | 急性出血時血紅蛋白可能正常 |
| <span style="color:#60a5fa">**懷孕測試**</span> | 所有生育年齡女性都需進行 |

## II. 頭部與頸部創傷

### A. 頭部影像

#### 1. PECARN 算法（兒科急診照護應用研究網絡）

- <span style="color:#60a5fa">**經過驗證的兒科臨床決策工具**</span>，通過評估風險因素預測頭部 CT 影像需求
- 可識別臨床重要創傷性腦損傷（ciTBI）風險非常低的兒科患者
- CT 影像有已知風險：兒童輻射誘發惡性腫瘤風險高於成人
- <span style="color:#f87171">**僅適用於 GCS ≧ 14 的兒童**</span>

**CT 影像決策（< 2歲）**

| 條件 | ciTBI 風險 |
|------|-----------|
| GCS ≦ 14 或意識狀態改變（激動、嗜睡、反覆提問、緩慢回應）**或**可觸及的顱骨骨折 | <span style="color:#f87171">**4.4%**</span> → 考慮 CT |
| 頭頂部血腫（排除額部）**或**失去意識 ≧ 5秒**或**嚴重創傷機轉 | <span style="color:#34d399">**< 0.02%**</span> → 觀察 |

**CT 影像決策（≧ 2歲）**

| 條件 | ciTBI 風險 |
|------|-----------|
| GCS ≦ 14 或顱底骨折跡象**或**意識狀態改變 | <span style="color:#f87171">**4.3%**</span> → 考慮 CT |
| 嘔吐、失去意識、嚴重頭痛、嚴重創傷機轉 | <span style="color:#34d399">**< 0.05%**</span> → 觀察 |

#### 2. 如果 CT 上有創傷性腦損傷跡象，考慮諮詢兒科重症、神經外科和/或創傷外科

### B. 頸椎和頸部影像

#### 1. 目前沒有統一的兒科頸椎清除方案

#### 2. PECARN C-spine 標準：考慮影像如果存在

- 意識狀態改變
- 局灶性神經缺陷
- 頸部疼痛投訴
- 斜頸
- 軀幹重大損傷
- 易感性條件
- 高速車禍
- 跳水事故

#### 3. NEXUS 標準（未經驗證用於 ≦ 8歲兒童）

<span style="color:#f87171">**影像適應症**</span>：頸椎正中線壓痛、意識警覺度改變、中毒證據、神經缺陷、疼痛分散性損傷

#### 4. 影像方式選擇

| 方式 | 適用情況 |
|------|---------|
| <span style="color:#60a5fa">**X-ray（至少兩視圖）**</span> | 識別頸椎骨損傷，敏感度 90% |
| <span style="color:#60a5fa">**CT scan**</span> | 高度懷疑頸椎骨折但平片 inconclusive |
| <span style="color:#60a5fa">**MRI scan**</span> | 韌帶和頸椎脊髓損傷進一步評估 |

> 📌 <span style="color:#60a5fa">**SCIWORA**</span>：30-40% 創傷性脊髓病變兒童有「影像學正常但有脊髓損傷」——臨床症狀但無影像學骨折或 instability 跡象。建議 MRI。

## III. 腦震盪（Concussion）

### A. 腦震盪評估

#### 1. 定義
創傷性頭部損傷後的一系列症狀，被認為是神經代謝功能障礙而非結構損傷，通常伴隨正常結構神經影像。大部分腦震盪症狀在 1-3 週內臨床緩解。

#### 2. 症狀分類

| 類別 | 症狀 |
|------|------|
| <span style="color:#60a5fa">**身體症狀**</span> | 頭痛 |
| <span style="color:#60a5fa">**認知症狀**</span> | 感覺迷糊、疲勞、困惑、專注困難 |
| <span style="color:#60a5fa">**感官症狀**</span> | 畏光、畏聲 |
| <span style="color:#60a5fa">**情緒/記憶**</span> | 健忘、噁心 ± 嘔吐 |

#### 3. 症狀持續 > 3 週或有多次腦震盄史者需要更詳細評估

#### 4. 返回學校與返回運動指南

| 階段 | 內容 |
|------|------|
| <span style="color:#34d399">**步驟 1**</span> | 恢復日常活動（如學校） |
| <span style="color:#34d399">**步驟 2**</span> | 輕度有氧活動（5-10 分鐘步行、輕慢跑） |
| <span style="color:#34d399">**步驟 3**</span> | 中度活動（慢跑、固定自行車） |
| <span style="color:#34d399">**步驟 4**</span> | 重度非接觸活動（短跑、跑步） |
| <span style="color:#34d399">**步驟 5**</span> | 受控環境中的全面接觸訓練 |
| <span style="color:#34d399">**步驟 6**</span> | 全面接觸比賽/遊戲 |

> 📌 <span style="color:#60a5fa">**Clinical Pearl**</span>：每個階段需要數天或數週，只有在無新症狀或惡化時才能進入下一階段。返回學校領先於返回運動。

## IV. 胸腔、腹腔和骨盆創傷

### A. 評估和管理要點

#### 1. 張力性氣胸或大量血胸

| 項目 | 內容 |
|------|------|
| **症狀** | 呼吸窘迫、不對稱/異常呼吸音、低血壓、tachycardia、意識改變 |
| **創傷原因** | 穿透性或鈍性創傷、肋骨骨折 |
| **緊急治療** | 即刻 needle decompression（氣胸）、chest tube（氣胸、血胸）、容量復甦/輸血 |

#### 2. 心包填塞

| 項目 | 內容 |
|------|------|
| **症狀** | 胸痛、呼吸困難、心音偏遠/悶、血壓過低、意識改變、心電圖 electrical alternans |
| **緊急治療** | 心包穿刺放液、容量復甦 |

#### 3. 主動脈夾層

| 項目 | 內容 |
|------|------|
| **症狀** | 嚴重胸/腹痛、呼吸困難、意識喪失、中風症狀、脈搏差異 |
| **穩定患者** | β-受體阻斷劑減少心輸出 + 血管內修復 |
| **不穩定患者** | 送手術室進行剖腹/胸切開術 |

#### 4. 肋骨骨折和連枷胸

- 多發急性肋骨骨折通常需要入住兒科創傷中心
- 疼痛控制以改善呼吸功能
- 物理治療以預防肺不張
- <span style="color:#f87171">**< 3 歲有肋骨骨折且無重大創傷史的兒童需要評估是否為兒虐**</span>
- 連枷胸患者有呼吸窘迫或衰竭應插管並給予正壓通氣

#### 5. 腹部創傷

**PECARN 腹部創傷規則**

<span style="color:#60a5fa">**非常低風險（敏感度 99%）**：滿足以下所有條件：

- 無腹部創傷跡象或安全帶徵
- GCS > 13
- 無腹部壓痛
- 無胸部創傷跡象
- 無腹痛投訴
- 無呼吸音減少
- 無嘔吐

> ⚠️ <span style="color:#f87171">**Clinical Warning**</span>：「安全帶徵」（安全帶約束分布區域的瘀傷/可見損傷）是鈍性腹部創傷手術損傷的重要預測因素（敏感度 70.6%，特異度 82.4%）

### B. 影像檢查

#### 1. 超音波 FAST 檢查

- 可早期識別自由液體
- 穩定兒科創傷中 pooled sensitivity 35%，specificity 96%
- 結果陽性需考慮 CT；結果陰性不能排除進一步診斷

#### 2. X 光

- 胸部 X 光：評估肋骨骨折、氣胸/血胸、肺挫傷、氣縱隔
- 腹部和骨盆 X 光：評估自由氣體、液體、骨盆骨折

#### 3. 腹部/骨盆 CT（含靜脈對比）

- <span style="color:#60a5fa">**CT 是診斷腹內損傷的金標準**</span>
- 穩定創傷患者通常不需要常規口服對比

## V. 四肢和長骨創傷

### A. 評估和管理要點

#### 1. 神經血管評估

- 選擇易於快速執行的運動/感覺測試
- 使用都卜勒協助識別脈搏和監測骨筋膜室症候群

#### 2. 出血

- 如果無脈搏和涼爽四肢伴出血：考慮动脉出血
- 如果持續脈搏伴出血：考慮靜脈出血

#### 3. 骨筋膜室症候群

| 5P 症狀 | 說明 |
|---------|------|
| <span style="color:#f87171">**Pain**</span> | 與明顯損傷不成比例的疼痛，被動伸展時疼痛 |
| <span style="color:#f87171">**Pallor**</span> | 蒼白 |
| <span style="color:#f87171">**Paresthesia**</span> | 感覺異常 |
| <span style="color:#f87171">**Paralysis**</span> | 麻痺（晚期） |
| <span name="pulse"></span> | 脈搏消失（晚期） |

> ⚠️ <span style="color:#f87171">**Clinical Warning**</span>：如果出現骨筋膜室症候群或骨折跡象，立即諮詢骨科醫師

### B. 創傷性骨折類型

| 骨折類型 | 特點 |
|---------|------|
| <span style="color:#60a5fa">**Salter-Harris 骨折**</span> | 涉及生長板的骨折 |
| <span style="color:#60a5fa">**Torus/Buckle 骨折**</span> | 壓縮損傷，皮質皺褶 |
| <span style="color:#60a5fa">**Greenstick 骨折**</span> | 一側骨折，另一側皮質完整 |
| <span style="color:#60a5fa">**Avulsion 骨折**</span> | 肌腱或韌帶撕脫骨碎片，常見於運動青少年 |

### C. 需要緊急骨科會診的情況

- 開放性骨折
- 不可接受移位的骨折
- 伴隨神經血管損傷的骨折
- 重大生長板或關節損傷
- 長骨完全或移位骨折
- 骨盆骨折
- 脊柱骨折
- 主要關節脫臼

## VI. 牙科創傷

### A. 牙齒脫落（Avulsion）

> ⚠️ <span style="color:#f87171">**Dental Emergency - 永久齒**</span>：如果可能，應在 60 分鐘內立即再植以最大化牙齒和牙周膜存活

**處理步驟**：

1. 拿起脫落牙齒時<span style="color:#60a5fa">**只觸碰牙冠，避免觸摸牙根**</span>
2. 用生理鹽水沖洗牙齒和牙槽窩，必要時去除血塊
3. 必要時施用局部麻醉（不含血管收縮劑）
4. 將牙根凹面朝舌側插入牙槽窩，輕輕手壓
5. 讓患者咬住紗布或布固定位置
6. 緊急就診於牙醫進行夾板固定和隨訪

**保存介質**（按優先順序）：<span style="color:#60a5fa">**牛奶 > Hank's 平衡鹽溶液 > 唾液 > 生理鹽水**</span>

### B. 牙齒骨折分類與隨訪

| 骨折類型 | 建議 |
|---------|------|
| 琺瑯質骨折 | 門診牙科評估，修復牙齒碎片 |
| 琺瑯質-牙本質骨折 | 48-72 小時內牙科評估，放置氫氧化鈣覆蓋 |
| 琺瑯質-牙本質-牙髓骨折 | 48 小時內緊急牙科評估 |
| 齒槽脊骨折 | 緊急牙科評估 |

## VII. 眼科創傷

### A. 化學損傷

> ⚠️ <span style="color:#f87171">**緊急處理**</span>：立即並持續用清水、等滲鹽水或乳酸林格氏液沖洗眼睛

1. 確定物質是酸還是鹼（<span style="color:#f87171">**鹼性溶液通常更具破壞性**</span>）
2. 測量基準 pH：接觸結膜上的石蕊試紙
3. 繼續沖洗至少 20 分鐘或直到 2 升液體用完
4. 每 15-30 分鐘重新測量 pH 直到中性（7.0-7.4）

### B. 眼球破裂（Ruptured Globe）

| 項目 | 內容 |
|------|------|
| **物理檢查重點** | 淚滴狀瞳孔（指向穿孔）、眼前房出血（hyphema）、結膜下出血 |
| **緊急處理** | 停止檢查，放置硬性眼罩；**不要**使用眼藥水；頭部抬高 |
| **用藥** | 適當抗生素 |

### C. 角膜擦傷（Corneal Abrasion）

| 症狀 | 處理 |
|------|------|
| 紅眼、流淚、劇烈疼痛、睜眼困難、畏光、異物感 | <span style="color:#fb923c">**人工淚液、潤滑劑**</span>、<span style="color:#fb923c">**局部抗生素眼藥膏**</span>、<span style="color:#fb923c">**口服止痛藥**</span> |

## VIII. 動物咬傷

### A. 感染風險與抗生素預防

| 風險因素 | 建議 |
|---------|------|
| 免疫抑制、糖尿病 | 抗生素預防 |
| 手、腳、生殖器、關節表面咬傷 | 抗生素預防 |
| 穿刺傷、擠壓傷 | 抗生素預防 |
| 貓咬傷 | 抗生素預防（深穿刺傷傾向） |
| 人咬傷 | 抗生素預防 |

**抗生素選擇**

| 咬傷類型 | 一線治療 | Penicillin 過敏時 |
|---------|---------|----------------|
| 動物咬傷 | <span style="color:#fb923c">**Amoxicillin/clavulanate**</span> 5 天 | TMP/SMX + Clindamycin |
| 人咬傷 | <span style="color:#fb923c">**Amoxicillin/clavulanate**</span> 5 天 | Clindamycin + Ciprofloxacin |

> 📌 <span style="color:#60a5fa">**Clinical Pearl**</span>：狗咬傷後出現症狀的中位時間約 24 小時；貓咬傷通常較短（約 12 小時）

## IX. 燒傷

### A. 燒傷評估

#### 1. 燒傷面積計算（Lund-Browder 圖）

- <span style="color:#60a5fa">**燒傷的手掌（手掌 + 內收五指）約佔體表面積 1%**</span>
- 只計算部分厚度和全層燒傷

#### 2. 燒傷深度分類

| 深度 | 層次 | 臨床發現 |
|------|------|---------|
| <span style="color:#34d399">**表層**</span> | 表皮 | 乾燥、疼痛、紅斑（像曬傷） |
| <span style="color:#60a5fa">**部分厚度**</span> | 真皮 | 濕潤、疼痛、紅斑、起皰、變白 |
| <span style="color:#f87171">**全層**</span> | 皮下組織、筋膜、肌肉、骨 | 蒼白、炭化、皮革樣、無感覺、無出血 |

#### 3. 液體復甦（Parkland 公式）

<span style="color:#60a5fa">**4 mL × 體重(kg) × 燒傷面積(%TBSA)**</span>

- 前 8 小時給予一半
- 後 16 小時給予另一半
- <span style="color:#34d399">**尿液輸出目標：0.5-1 mL/kg/hr**</span>

> ⚠️ <span style="color:#f87171">**Clinical Warning**</span>：大面積燒傷（嬰兒 ≧ 15% TBSA，青少年 ≧ 20% TBSA）常發生全身炎症反應和心肌抑制

### B. 燒傷住院標準

- 部分厚度燒傷 ≧ 10% TBSA
- 臉部、手、腳、生殖器、會陰、主要關節的燒傷
- 全層燒傷
- 電燒傷、化學燒傷、吸入性損傷
- 合併創傷的燒傷

### C. 轉往燒傷中心標準

> 📌 <span style="color:#60a5fa">**Chemical/Electrical Burns**</span> 需要特殊考量

- 電燒傷：考虑心律監測 48 小時（心律不整風險）
- 化學燒傷：立即大量沖水

## X. 非意外創傷（兒虐）

### A. 身體虐待識別

#### 1. 病史紅旗

- 病史與損傷年齡、模式或嚴重程度不符
- 病史與兒童身體或發育能力不符
- 解釋不一致/不完整/模糊/變化
- 表現延遲

#### 2. 身體檢查紅旗

| 損傷類型 | 紅旗特徵 |
|---------|---------|
| <span style="color:#f87171">**瘀傷**</span> | 胸部、腹部、背部、臀部；多發；不同癒合階段；不符合發育階段；不常見位置（耳後、頸部、上臂內側）；與手或捏傷形狀一致 |
| <span style="color:#f87171">**燒傷**</span> | 鋒利邊緣的燙傷；物體形狀；香煙燒傷；會陰部「浸入」模式；多處燒傷；襪/手套分布 |
| <span style="color:#f87171">**其他**</span> | 舌繫帶撕裂；繩索/電纜痕跡；咬痕 |

#### 3. 影像學指南

| 檢查 | 適用年齡 |
|------|---------|
| <span style="color:#60a5fa">**骨骼調查**</span> | < 2 歲 |
| 目標性影像 | > 5 歲 |

<span style="color:#f87171">**與兒虐相關的骨折**</span>：後肋骨骨折、骨骺/干骺端角落骨折、脊柱和肩胛骨骨折、顱骨骨折

#### 4. 疑似兒虐處理

- 醫療穩定是立即目標；預防進一步損傷是長期目標
- 所有醫療提供者都有法律義務報告疑似兒童虐待
- 考慮諮詢當地兒童傷害/虐待專家
- 進行檢查以排除損傷的醫學原因（出血性疾病、骨發育不全）

> ⚠️ <span style="color:#f87171">**Clinical Warning**</span>：照護者否認或解釋與損傷不符、延遲就診、多處不同癒合階段的損傷都是兒虐的重要信號

---

### B. 性虐待評估

#### 1. 評估時機

- 疑似虐待發生在 72-96 小時內
- 有需要治療的生殖器或肛門損傷
- 衣物或身體上有明顯法醫證據
- 有繼續虐待或報復危險

#### 2. 性傳染病（STI）檢測

| 情況 | 建議 |
|------|------|
| 青少年 | 所有疑似性虐待患者 |
| 青春期前兒童 | 如果有陰道/肛門穿透、陌生人侵犯、高風險行為者 |

#### 3. STI 檢測包括

- 血清：HIV、梅毒
- 培養：淋病/披衣菌/滴蟲（可從陰莖、陰道、肛門、喉嚨採集）
