> **章節導讀摘要**
> 本章涵蓋小兒腎臟科的核心議題，包括尿液分析判讀、腎絲球濾過率（GFR）評估與估算公式、高血壓的診斷與治療、泌尿道感染的處理、蛋白尿與血尿的鑑別診斷、急性腎損傷的分類與治療，以及腎病症候群的診療原則。內容強調數值標準、疾病分類與臨床決策 cutoffs，適用於門診與住院照護情境。

## I. 尿液分析（Urinalysis）

### A. 適應症
<span style="color:#f87171">泌尿道感染（UTI）</span>、<span style="color:#f87171">腎炎</span>、創傷、<span style="color:#f87171">糖尿病</span>、<span style="color:#f87171">橫紋肌溶解症</span>、水腫、生長遲緩。

### B. 採檢注意事項
尿液應於排尿後 **1 小時內** 送驗，否則需冷藏於 <span style="color:#34d399">4°C</span>。美國兒科醫學會（AAP）不建議常規年度篩檢，除非為慢性腎病高風險族群。

### C. 尿液分析項目

| 項目 | 正常值 | 異常意義 |
|---|---|---|
| 外觀 | 無色至琥珀色 | 雲濁可能正常（尿酸結晶、磷酸鹽結晶、感染物質） |
| 比重 | <span style="color:#34d399">1.003–1.030</span> | 等張尿（1.010）＝水分調節異常 |
| pH 值 | <span style="color:#34d399">4.5–8.0</span>（平均 5–6） | 檸檬酸尿見於 UTI（尿素分解菌）或結石 |
| 蛋白 | 陰性 | 1+ ≈ <span style="color:#34d399">30 mg/dL</span>；4+ > <span style="color:#34d399">1000 mg/dL</span> |
| 葡萄糖 | 陰性 | 血糖 > <span style="color:#34d399">160–180 mg/dL</span> 時出現 |
| 酮體 | 陰性至些許 | 可見於<span style="color:#f87171">糖尿病酮酸血症</span>或飢餓 |
| 亞硝酸鹽 | 陰性 | 對 <span style="color:#c084fc">革蘭氏陰性菌</span>（如 <span style="color:#c084fc">大腸桿菌</span>、<span style="color:#c084fc">克雷伯氏菌</span>、<span style="color:#c084fc">變形菌</span>）特異性 <span style="color:#34d399">90–100%</span>，敏感性 <span style="color:#34d399">15–82%</span> |
| 白血球酯酶 | 陰性 | 對 UTI 敏感性 <span style="color:#34d399">67–84%</span>，特異性 <span style="color:#34d399">64–92%</span> |
| 血紅素 | 陰性 | 陽性可能為<span style="color:#f87171">血尿</span>或<span style="color:#f87171">肌球蛋白尿</span>（擠壓傷） |
| 紅血球 | <span style="color:#34d399"><5 RBCs/hpf</span>（離心尿） | 變形紅血球暗示<span style="color:#f87171">腎絲球源</span>；正常型態暗示下泌尿路 |
| 白血球 | <span style="color:#34d399"><5 WBCs/hpf</span>（離心尿） | >5 見於 UTI、<span style="color:#f87171">無菌性膿尿</span>（如<span style="color:#f87171">川崎氏病</span>） |

## II. 腎功能測試

### A. 腎絲球功能測試

#### 1. 腎絲球發育
<span style="color:#60a5fa">腎絲球發育</span>於妊娠 <span style="color:#34d399">36 週</span>完成。GFR 在出生後前 2 年隨腎絲球成熟而增加。

#### 2. 正常 GFR 值（以菊粉清除率為黃金標準）

| 年齡 | 平均 GFR ± SD（mL/min/1.73 m²） |
|---|---|
| 1 週（M 和 F） | <span style="color:#34d399">41 ± 15</span> |
| 2–8 週（M 和 F） | <span style="color:#34d399">66 ± 25</span> |
| >8 週（M 和 F） | <span style="color:#34d399">96 ± 22</span> |
| 2–12 歲（M 和 F） | <span style="color:#34d399">133 ± 27</span> |
| 13–21 歲（男性） | <span style="color:#34d399">140 ± 30</span> |
| 13–21 歲（女性） | <span style="color:#34d399">126 ± 22</span> |

#### 3. 肌酸酐清除率（CCr）
$$CCr = [U \times (V/P)] \times (1.73/BSA)$$

- U = 尿肌酸酐（mg/dL）
- V = 分鐘尿量（mL/min，24 小時 = 1440 分鐘）
- P = 血漿肌酸酐（mg/dL）
- BSA = 體表面積（m²）

> 當 GFR 偏低時，CCr 會高估真實 GFR。

#### 4. 估算 GFR（eGFR）公式

**a. CKiD 公式（1–16 歲，適用酵素法）**
$$eGFR = 0.413 \times (L / Pcr)$$
- L = 身高（cm），Pcr = 血漿肌酸酐（mg/dL）
- eGFR ≥ <span style="color:#34d399">75 mL/min/1.73 m²</span> 為正常

**b. Schwartz 公式（歷史公式）**
$$eGFR = k \times (L / Pcr)$$

| 年齡 | k 值 |
|---|---|
| 出生體重低（第一年） | <span style="color:#34d399">0.33</span> |
| 足月適於胎齡兒（第一年） | <span style="color:#34d399">0.45</span> |
| 兒童及青少年（女性） | <span style="color:#34d399">0.55</span> |
| 青少年（男性） | <span style="color:#34d399">0.70</span> |

> 使用<span style="color:#fb923c">酵素法肌酸酐</span>搭配 Schwartz 公式會高估 GFR。

**c. MDRD / CKD-EPI**：用於 >18 歲，2021 年更新移除種族因子。

#### 5. 其他 GFR 測定
<span style="color:#60a5fa">碘西酮</span>、<span style="color:#60a5fa">DTPA</span>、<span style="color:#60a5fa">Iohexol</span>可用於化療劑量精確調整。<span style="color:#60a5fa">胱抑素 C（Cystatin C）</span>較肌酸酐更準確，適用於肌肉質量異常病患。

### B. 腎小管功能測試

#### 1. 近端腎小管：溶質處理

**a. 腎小管回收率（Tx）**
$$Tx = [1 - (Ux/Px) / (UCr/PCr)] \times 100$$

常用於計算<span style="color:#60a5fa">磷酸鹽回收率（TRP）</span>。低磷酸血症且近端腎小管功能正常時，TRP 應接近 **100%**。

**b. 鈉排泄分率（FENa）**
$$FENa = [(UNa/PNa) / (UCr/PCr)] \times 100$$

| 臨床情境 | FENa |
|---|---|
| <span style="color:#f87171">腎前性氮質血症</span>或<span style="color:#f87171">腎絲球腎炎</span> | <span style="color:#34d399"><1%</span> |
| <span style="color:#f87171">急性腎小管壞死（ATN）</span>或腎後性氮質血症 | <span style="color:#34d399">>1%（通常 >3%）</span> |
| 脫水嬰兒 | <span style="color:#34d399"><3%</span> |

> FENa 使用利尿劑時可能不準。

**c. 尿素排泄分率（FEurea）**：適用於服用利尿劑病患
- 腎前性：<span style="color:#34d399"><35%</span>
- ATN：<span style="color:#34d399">>50%</span>

**d. 碳酸氫鹽排泄分率（FEHCO3）**
$$FeHCO3 = [(UHCO3/PHCO3) / (UCr/PCr)] \times 100$$

- 正常：<span style="color:#34d399"><5%</span>
- <span style="color:#f87171">遠端 RTA</span>：通常 <5%
- <span style="color:#f87171">近端 RTA（第二型）</span>：>15%

#### 2. 遠端腎小管：酸鹼平衡

**a. 尿陰離子間隙（UAG）**
$$UAG = UNa + UK - UCl$$

- UAG 正值（通常 >20）：暗示<span style="color:#f87171">遠端 RTA</span>
- UAG 負值（通常 <-20）：暗示高尿銨（如<span style="color:#f87171">腹瀉</span>）

**b. 尿 pH 值**：隨機尿 pH >6 且合併中度代謝性酸中毒時，懷疑<span style="color:#f87171">遠端 RTA</span>。

**c. 尿滲透壓**：理想為**早晨第一泡尿**。滲透壓 > <span style="color:#34d399">600 mOsm/L</span> 時，腎小管功能障礙可能性低。

**d. 尿鈣**：高尿鈣見於<span style="color:#f87171">遠端 RTA</span>、<span style="color:#f87171">維生素 D 中毒</span>、<span style="color:#f87171">高血鈣</span>、固定不動、<span style="color:#fb923c">類固醇</span>或<span style="color:#fb923c">Loop 利尿劑</span>使用。

| 診斷方式 | 正常值 |
|---|---|
| 24 小時尿鈣 | <span style="color:#34d399"><4 mg/kg/24 小時</span>（黃金標準） |
| 隨機尿鈣/肌酸酐比 | 依年齡調整（見 Table 19.4） |

## III. 血壓與慢性高血壓

### A. 定義
- <13 歲：收縮壓或舒張壓 **≥95 百分位** 為高血壓
- ≥13 歲：**≥130/80 mmHg** 為高血壓
- 血壓 >90 百分位或 ≥120/80 應於門診重新測量

### B. 測量規範
1. **≥3 歲**：每年測量一次；有高風險者（肥胖、服用升高血壓藥物、腎病、<span style="color:#f87171">主動脈窄縮</span>、糖尿病）每次就診測量。
2. **<3 歲** 有風險因子者（早產 <32 週、小於胎齡、先天性心臟病、腎病家族史、復發性 UTI、惡性腫瘤、移植、使用升高血壓藥物、顱內壓升高）應測量。
3. 測量姿勢：坐姿、上臂置於心臟水平，休息 **5 分鐘**後測量；氣囊寬度至少為上臂圍的 **40%**。

### C. 各年齡層高血壓病因（Table 19.7）

| 年齡 | 最常見原因 |
|---|---|
| 新生兒/嬰兒 | <span style="color:#f87171">臍动脉導管術後腎动脉血栓</span>、<span style="color:#f87171">主動脈窄縮</span>、<span style="color:#f87171">腎动脉狹窄</span>、<span style="color:#f87171">支氣管肺發育不良</span> |
| 1–10 歲 | <span style="color:#f87171">腎實質疾病</span>、<span style="color:#f87171">主動脈窄縮</span>、<span style="color:#f87171"> essential hypertension（原發性）</span> |
| 11 歲至青少年 | <span style="color:#f87171">essential hypertension</span>（原發性）、<span style="color:#f87171">腎實質疾病</span>、<span style="color:#f87171">主動脈窄縮</span> |

**引起高血壓的藥物**：<span style="color:#fb923c">皮質類固醇</span>、<span style="color:#fb923c">Calcineurin 抑制劑</span>（<span style="color:#fb923c">環孢靈</span>、<span style="color:#fb923c">他克莫司</span>）、<span style="color:#fb923c"> Methylphenidate</span>、<span style="color:#fb923c">NSAIDs</span>、<span style="color:#fb923c"> Erythropoietin</span>、古柯鹼、安非他命。

### D. 慢性高血壓評估

**實驗室檢查（所有病患）**：UA、電解質、肌酸酐、BUN、血脂
**肥胖病患**：HbA1c、AST/ALT
**影像**：腎臟超聲（<6 歲或 UA/腎功能異常）、心臟超聲評估左心室肥大
**確診建議**：24 小時<span style="color:#60a5fa"> ABPM</span>（動態血壓監測）為確認高血壓的標準

### E. 高血壓分類與治療（Table 19.8）

| 分類 | <13 歲 | ≥13 歲 | 管理 |
|---|---|---|---|
| 正常血壓 | <90 百分位 | <120/<80 | 每年追蹤 |
| 血壓升高 | 90–<95 百分位 或 120/<80 至 129/<80 | 120–<130/<80 | 6 個月後重新測量 |
| 第一期 | 95 百分位至 95 百分位 +12 mmHg 或 130/80–139/89 | 130/80–139/89 | 1–2 週後重新測量 |
| 第二期 | ≥95 百分位 +12 mmHg 或 ≥140/90 | ≥140/90 | 1 週內評估並治療 |

**治療目標**：血壓降至 <90 百分位且 <130/80（青少年）；慢性腎病（CKD）病患目標 <50 百分位。

**非藥物治療**：有氧運動、鈉限制、戒菸、減重

**藥物治療一線選擇**：
- <span style="color:#fb923c">ACE 抑制劑</span>（Benazepril、Enalapril、Lisinopril）
- <span style="color:#fb923c">ARB</span>（Losartan、Candesartan、Valsartan）
- <span style="color:#fb923c">Thiazide 利尿劑</span>（Hydrochlorothiazide）
- <span style="color:#fb923c">長效鈣離子通道阻斷劑</span>（Amlodipine、Isradipine）

> <span style="color:#fb923c">ACE 抑制劑</span>和<span style="color:#fb923c">ARB</span>禁用於<span style="color:#f87171">懷孕</span>或<span style="color:#f87171">雙側腎动脉狹窄</span>。

## IV. 泌尿道感染（Urinary Tract Infections）

### A. 風險因子
- 女性風險高於男性
- 未割包皮的男性風險較高
- 發燒 ≥<span style="color:#34d399">39°C</span> 且持續 >1–2 天

### B. 尿液收集方式
| 年齡/情況 | 收集方式 |
|---|---|
| 2 個月至 2 歲，發燒且病得很重 | 經尿道導尿或恥骨上穿刺 |
| 2 個月至 2 歲，發燒但病得輕 | 導尿最方便；收集袋陽性率 >75%，不應送培養 |
| >2 歲且已訓練如廁 | 中段清潔尿 |

### C. 診斷標準

| 收集方式 | 診斷閾值 |
|---|---|
| 導尿或恥骨上穿刺 | ><span style="color:#34d399">50,000 CFU/mL</span> |
| 中段清潔尿 | ><span style="color:#34d399">100,000 CFU/mL</span> |
| 膿尿定義 | ≥<span style="color:#34d399">5 WBCs/hpf</span> |

### D. 常見致病菌
- <span style="color:#c084fc">大腸桿菌（E. coli）</span>為最常見
- <span style="color:#c084fc">克雷伯氏菌</span>、<span style="color:#c084fc">變形菌</span>、<span style="color:#c084fc">腐生葡萄球菌（S. saprophyticus）</span>
- 新生兒：<span style="color:#c084fc">B 群鏈球菌</span>
- 異常宿主：<span style="color:#c084fc">腸球菌</span>、<span style="color:#c084fc">綠膿桿菌</span>

### E. 腎盂腎炎 vs. 膀胱炎
<span style="color:#f87171">腎盂腎炎</span>（上泌尿路感染）特點：
- 發燒 ≥<span style="color:#34d399">38.5°C</span>（尤其抗生素治療 48 小時後仍持續）
- 全身症狀、肋椎角壓痛
- CRP 升高、白血球增多

### F. 影像適應症
**腎膀胱超聲（RBUS）**：2–24 個月有第一線發燒性 UTI、復發性或非典型 UTI、治療 48 小時內無改善
**排尿膀胱尿道攝影（VCUG）**：RBUS 異常（<span style="color:#f87171">水腎</span>、疤痕）或復雜性/復發性腎盂腎炎；最佳時機為感染後 2–6 週

### G. 治療
- **療程**：無併發症 3–5 天；<span style="color:#f87171">腎盂腎炎</span>或中毒病患 7–14 天
- **路徑**：中毒、脫水或無法口服者給予靜脈抗生素
- **治療失敗**：需考慮<span style="color:#f87171">腎膿瘍</span>或<span style="color:#f87171">泌尿路阻塞</span>

### H. 膀胱輸尿管逆流（VUR）分級

| 分級 | 描述 |
|---|---|
| 第一級 | 僅輸尿管逆流 |
| 第二級 | 輸尿管、腎盂、腎盞；無擴張，正常腎盞 |
| 第三級 | 輕度至中度輸尿管擴張/彎曲；輕度腎盂/腎盞擴張，腎盞銳角消失 |
| 第四級 | 中度輸尿管擴張/彎曲；中度腎盂/腎盞擴張，主腎盞乳頭可見 |
| 第五級 | 輸尿管嚴重擴張/彎曲；腎盂/腎盞嚴重擴張，乳頭壓跡不可見 |

**VUR 處理**：
- <span style="color:#fb923c">Trimethoprim-sulfamethoxazole</span> 預防性抗生素可降低 UTI 復發風險約 50%，但對腎疤痕無顯著差異
- 高分級 VUR 持續者可能需手術治療

### I. 無症狀菌尿
定義：顯微鏡下可見細菌但無發燒、無症狀、無膿尿。若排尿習慣和泌尿系統正常，不需抗生素治療。

## V. 蛋白尿（Proteinuria）

### A. 定義

| 類型 | 定義 |
|---|---|
| <span style="color:#60a5fa">姿勢性蛋白尿</span> | 直立時出現大量蛋白，躺下消失；兒童青少年常見，為良性 |
| <span style="color:#60a5fa">固定性蛋白尿</span> | 連續數日早晨第一泡尿均有蛋白；暗示腎病 |
| <span style="color:#60a5fa">微量白蛋白尿</span> | 白蛋白低於試紙可測範圍；成人定義 30–300 mg/g creatinine |
| <span style="color:#60a5fa">顯著性蛋白尿</span> | UPr:UCr 比值 0.2–2.0 mg/mg 或 24 小時 collection > <span style="color:#34d399">4–40 mg/m²/hr</span> |
| <span style="color:#60a5fa">腎病範圍蛋白尿</span> | UPr:UCr 比值 >2 mg/mg 或 24 小時 > <span style="color:#34d399">40 mg/m²/hr</span> |
| <span style="color:#60a5fa">腎病症候群</span> | 腎病範圍蛋白尿 + 低白蛋白血症 + 水腫 + 高血脂（膽固醇 > <span style="color:#34d399">200 mg/dL</span>） |

### B. 偵測方法

**早晨第一泡尿蛋白/肌酸酐比值（UPr:UCr）**：
- <2 歲：正常 <span style="color:#34d399"><0.5 mg/mg</span>
- >2 歲：正常 <span style="color:#34d399"><0.2 mg/mg</span>

> 收集方式：睡前排空膀胱，起床後第一泡尿立刻收集。

### C. 病因（Box 19.1）

**暫時性蛋白尿**：發燒、運動、脫水、<span style="color:#f87171">充血性心臟衰竭</span>、癲癇、壓力、腎上腺素使用後

**腎絲球疾病**：
- <span style="color:#f87171">最小變化腎病症候群（MCD）</span>、<span style="color:#f87171">局部節段性腎絲球硬化（FSGS）</span>、<span style="color:#f87171">膜性腎病</span>、<span style="color:#f87171">膜增生性腎絲球腎炎</span>
- <span style="color:#f87171">IgA 腎病</span>、<span style="color:#f87171">紫癜性腎炎（HSP）</span>、<span style="color:#f87171">狼瘡腎炎</span>、<span style="color:#f87171">Alport 症候群</span>

**腎小管疾病**：<span style="color:#f87171">Fanconi 症候群</span>、<span style="color:#f87171">Wilson 病</span>、<span style="color:#f87171">Lowe 症候群</span>、<span style="color:#f87171">Dent 病</span>、藥物（<span style="color:#fb923c">氨基糖苷類</span>、<span style="color:#fb923c">順鉑</span>、<span style="color:#fb923c">NSAIDs</span>、<span style="color:#fb923c">環孢靈</span>）

---

## VI. 腎病症候群（Nephrotic Syndrome）

### A. 盛行率與病理
<span style="color:#f87171">特發性腎病症候群</span>為兒童最常見形式，約占 1–10 歲病例的 **90%**。<span style="color:#f87171">最小變化疾病（MCD）</span>為此年齡層最常見的腎病理學發現。

### B. 臨床表現
低白蛋白血症導致血漿滲透壓下降，引起全身性水腫。初期水腫常見於顏面（尤其是眼眶周圍）與小腿前側。

### C. 病因（Table 19.10）

| 原發性（90%） | 繼發性（10%） |
|---|---|
| <span style="color:#f87171">MCD</span>：占特發性兒童病因 85% | <span style="color:#c084fc">愛滋病毒</span>、<span style="color:#c084fc">B 型肝炎</span>、<span style="color:#c084fc">C 型肝炎</span> |
| <span style="color:#f87171">FSGS</span> | <span style="color:#f87171">系統性紅斑狼瘡</span> |
| <span style="color:#f87171">膜性腎病</span> | <span style="color:#f87171">糖尿病</span> |
| <span style="color:#f87171">IgA 腎病</span> | <span style="color:#fb923c">藥物</span> |
| 裂隙膜遺傳疾病 | <span style="color:#f87171">惡性腫瘤</span>（白血病、淋巴瘤） |

### D. 類固醇反應分類

| 類型 | 定義 |
|---|---|
| **類固醇敏感型** | 開始prednisone治療後 4–8 週內緩解；MCD 約 95%，FSGS 約 20% |
| **頻繁復發型** | 6 個月內復發 ≥2 次，或 12 個月內復發 ≥4 次 |
| **類固醇依賴型** | 類固醇減量或停藥後 14 天內連續復發 2 次 |
| **類固醇抵抗型** | 8 週類固醇治療後仍未緩解 |

### E. 治療

**類固醇敏感性**：
- Prednisone <span style="color:#34d399">60 mg/m²/天</span> 或 <span style="color:#34d399">2 mg/kg/天</span>（最大 60 mg/天）× 6 週
- 續以 <span style="color:#34d399">40 mg/m²</span> 或 <span style="color:#34d399">1.5 mg/kg</span> 隔日 × 6 週
- 復發：<span style="color:#fb923c">Prednisone</span> <span style="color:#34d399">60 mg/m²/天</span> 或 <span style="color:#34d399">2 mg/kg/天</span> 直至尿蛋白連續 3 天陰性，續以隔日 <span style="color:#34d399">40 mg/m²</span> × 4 週

**二線藥物**（頻繁復發/類固醇依賴）：<span style="color:#fb923c">Cyclophosphamide</span>、<span style="color:#fb923c">Mycophenolate mofetil（MMF）</span>、<span style="color:#fb923c">Calcineurin 抑制劑</span>、<span style="color:#fb923c">Levamisole</span>、<span style="color:#fb923c">Rituximab</span>

### F. 非 MCD 警訊徵象
- 年齡 <1 歲或 >10 歲
- 腎病家族史
- 腎外疾病（關節炎、皮疹）
- 全身性或症候群性疾病
- 高血壓、肺水腫（血管內容量擴張）
- 腎衰竭
- 活動性尿沉渣（紅血球圓柱）

### G. 併發症
<span style="color:#f87171">急性腎損傷</span>、血栓栓塞疾病、危及生命的感染。慢性類固醇副作用：庫欣樣皮膚變化、白內障、加速動脈硬化、骨質疏鬆、胃潰瘂、情緒波動、失眠、胰島素阻抗。

## VII. 血尿（Hematuria）

### A. 定義

| 類型 | 定義 |
|---|---|
| <span style="color:#60a5fa">顯微血尿</span> | 離心尿 > <span style="color:#34d399">5 RBCs/hpf</span>；肉眼不可見 |
| <span style="color:#60a5fa">巨觀（肉眼）血尿</span> | 尿液可見血液 |
| <span style="color:#60a5fa">急性腎炎症候群</span> | 茶色或可樂色尿液、顏面/全身水腫、高血壓、寡尿 |

### B. 病因（Table 19.11）

| 來源 | 病因 |
|---|---|
| 上泌尿路疾病 | <span style="color:#f87171">IgA 腎病</span>、<span style="color:#f87171">Alport 症候群</span>、<span style="color:#f87171">薄腎絲球基底膜病</span>、<span style="color:#f87171">鏈球菌感染後腎絲球腎炎（PSGN）</span>、<span style="color:#f87171">膜性腎病</span>、<span style="color:#f87171">MPGN</span>、<span style="color:#f87171">RPGN</span> |
| 多系統疾病 | <span style="color:#f87171">狼瘡腎炎</span>、<span style="color:#f87171">過敏性紫癜腎炎</span>、<span style="color:#f87171">ANCA相關血管炎</span>、<span style="color:#f87171">結節性多發性动脉炎</span>、<span style="color:#f87171">Goodpasture 症候群</span>、<span style="color:#f87171">溶血性尿毒症候群</span> |
| 腎小管間質疾病 | <span style="color:#f87171">腎盂腎炎</span>、<span style="color:#f87171">間質性腎炎</span>、乳頭壞死、<span style="color:#f87171">ATN</span> |
| 血管疾病 | 動靜脈血栓、<span style="color:#f87171">鐮刀型紅血球疾病</span>、 crystalluria（結晶尿） |
| 先天性構造異常 | <span style="color:#f87171">水腎</span>、<span style="color:#f87171">多囊腎</span>、<span style="color:#f87171">威爾姆氏腫瘤</span>、創傷 |
| 下泌尿路疾病 | <span style="color:#f87171">膀胱炎</span>、<span style="color:#f87171">尿道炎</span>、<span style="color:#f87171">尿路結石</span>、創傷 |

### C. 評估：腎絲球 vs. 腎絲球外血尿

| 特點 | 腎絲球性 | 腎絲球外 |
|---|---|---|
| 血壓 | 通常高血壓 | 通常正常 |
| 解尿困難 | 通常無 | 常有 |
| 水腫 | 可能 | 可能無 |
| 尿沉渣 | 變形 RBC、RBC 圓柱、蛋白 >1+ | 正常型態 RBC，無圓柱 |

**腎絲球性血尿實驗室檢查**：CBC、電解質（含鈣）、BUN/Cr、白蛋白、ANA、C3/C4、B 型肝炎、C 型肝炎、愛滋病毒、聽力篩檢（如懷疑 Alport）

**腎絲球外血尿**：尿培養、淋病/披衣菌、子宮頸抹片（如有性行為）、考慮腹部/骨盆影像

## VIII. 急性腎損傷（Acute Kidney Injury, AKI）

### A. 定義
腎功能急劇下降，臨床表現為肌酸酐上升，伴或不伴尿量變化。

### B. 病因（Table 19.12）

| 分類 | 病因 |
|---|---|
| **腎前性**（最常見） | 出血、體液不足、敗血症、燒傷、<span style="color:#f87171">充血性心臟衰竭</span>、<span style="color:#fb923c">NSAIDs</span>、<span style="color:#fb923c">ACE 抑制劑</span> |
| **腎性** | <span style="color:#f87171">急性腎小管壞死（ATN）</span>（缺氧/缺血、藥物：<span style="color:#fb923c">氨基糖苷類</span>、<span style="color:#fb923c">兩性黴素 B</span>、<span style="color:#fb923c">化療藥物</span>）、<span style="color:#f87171">間質性腎炎</span>（<span style="color:#fb923c">β-內醯胺</span>、<span style="color:#fb923c">NSAIDs</span>、<span style="color:#fb923c">磺胺類</span>、<span style="color:#fb923c">PPI</span>）、<span style="color:#f87171">腎絲球腎炎</span>（RPGN）、<span style="color:#f87171">溶血性尿毒症候群</span>、<span style="color:#f87171">尿酸腎病</span>（腫瘤溶解症候群） |
| **腎後性** | 雙側輸尿管阻塞、尿道阻塞、膀胱功能障礙 |

### C. 臨床表現
蒼白、尿量減少、全身及肺水腫、高血壓、嘔吐、嗜睡。早期腎衰竭的特徵常為<span style="color:#60a5fa">寡尿</span>。

**BUN/Cr 比值（兩者均以 mg/dL 為單位）**：
- <span style="color:#34d399">10–20</span>（正常比）：腎性 AKI
- <span style="color:#34d399">>20</span>：體液不足、腎前性氮質血症、胃腸道出血
- <span style="color:#34d399"><5</span>：肝病、飢餓、先天代謝異常

### D. 急性腎小管壞死（ATN）三期

| 期別 | 特點 |
|---|---|
| **寡尿期** | 嚴重寡尿持續數天；若寡尿/無尿 >3–6 週，恢復可能性低 |
| **高尿量期** | 尿量增加，通過大量等張尿，含鈉 <span style="color:#34d399">80–150 mEq/L</span> |
| **恢復期** | 症狀通常快速緩解，但多尿可能持續數天至數週 |

### E. 治療原則
- 嚴格監測體液狀態（每日體重、精確輸入輸出）
- 考慮放置導尿管監測尿量
- 敗血症相關：早期目標導向治療
- AKI 處置見 Chapter 16（重症醫學）

## IX. 腎小管酸中毒（Renal Tubular Acidosis, RTA）

| 類型 | 缺陷位置 | 特色 |
|---|---|---|
| **第一型（遠端）** | 遠端腎小管氫離子分泌 | 尿 pH >5.5（鹼血症時）、低血鉀、骨質軟化、生長遲緩 |
| **第二型（近端）** | 近端碳酸氫鹽回收減少 | 血碳酸氫鹽通常 12–20 mEq/L；可能合併 Fanconi 症候群 |
| **第四型** | 醛固酮減少或腎小管對醛固酮抵抗 | 高血鉀為特色 |

## X. 慢性腎病（Chronic Kidney Disease, CKD）與腎衰竭

### A. 分期（以 GFR 為準）

| 分期 | GFR（mL/min/1.73 m²） | 描述 |
|---|---|---|
| G1 | ≥90（伴有腎損傷） | 腎損傷但功能正常 |
| G2 | 60–89 | 輕度下降 |
| G3a | 45–59 | 輕至中度下降 |
| G3b | 30–44 | 中至重度下降 |
| G4 | 15–29 | 重度下降 |
| G5 | <15 或透析 | 腎衰竭 |

### B. 併發症
<span style="color:#f87171">高血壓</span>、<span style="color:#f87171">液體過剩</span>、<span style="color:#f87171">尿毒症</span>、<span style="color:#f87171">貧血</span>（EPO 缺乏）、<span style="color:#f87171">骨質病變（CKD-MBD）</span>、<span style="color:#f87171">高血鉀</span>、<span style="color:#f87171">酸中毒</span>、<span style="color:#f87171">生長遲緩</span>

### C. 透析與腎移植
- 透析適應症：尿毒症症狀、體液過剩無法用藥物控制、嚴重高血鉀、難治性酸中毒、進行性尿毒症
- 腎移植為末期腎病之最佳治療選項

## XI. 腎臟緊急情況

### A. 惡性高血壓
定義：嚴重血壓升高伴急性器官損傷（視網膜、出血、滲出、乳頭水腫）。需靜脈抗高血壓藥物治療。

### B. 血栓性微血管病（TTP/HUS）
<span style="color:#f87171">溶血性尿毒症候群（HUS）</span>：微血管病性溶血性貧血、血小板減少、急性腎損傷。三聯徵。典型與 <span style="color:#c084fc">大腸桿菌 O157:H7</span> 感染相關。

### C. 急進型腎絲球腎炎（RPGN）
快速進展為腎衰竭（數天至數週）。症狀：<span style="color:#60a5fa">腎炎症候群</span>（血尿、蛋白尿、水腫、高血壓）+ 快速功能衰退。常見原因：<span style="color:#f87171">抗 GBM 病</span>、<span style="color:#f87171">ANCA 相關血管炎</span>、<span style="color:#f87171">狼瘡腎炎</span>、<span style="color:#f87171">IgA 腎病</span>。
